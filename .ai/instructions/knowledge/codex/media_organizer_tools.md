# Инструменты Media Organizer для ИИ-ассистентов

**Дата создания**: 2026-07-20  
**Назначение**: Описание доступных Function Calling инструментов для работы с медиатекой

---

## Обзор

Плагин `media_organizer` предоставляет набор инструментов (function declarations), которые AI-ассистент может вызывать автоматически при запросах о фильмах, сериалах или содержимом медиатеки.

**Основной Module**: `plugins/media_organizer/core/media_tools.py`

---

## Доступные инструменты

### 1. `search_media`

**Назначение**: Поиск медиа по названию во всей БД (частичное совпадение).

**Когда использовать**:
- Пользователь спрашивает о фильме/сериале по неполным данным
- Нужно найти тайтлы, содержащие определённое слово

**Аргументы**:
- `query` (string, **обязательный**): название или часть названия
- `media_type` (string, опциональный): фильтр по типу — `"movie"`, `"series"` или `""` (оба типа)

**Examples вызова**:
```python
search_media("Титаник")
search_media("Breaking", "series")
search_media("комедия")
```

---

### 2. `get_disk_contents`

**Назначение**: Получение всех записей медиатеки с конкретного диска.

**Когда использовать**:
- Пользователь спрашивает "что на диске 2?"
- Нужно показать весь list тайтлов с указанного диска

**Аргументы**:
- `disk_name` (string, **обязательный**): имя диска, например `"ДИСК 1"`, `"ДИСК 3"`
- `media_type` (string, опциональный): фильтр по типу — `"movie"`, `"series"` или `""`

**Examples вызова**:
```python
get_disk_contents("ДИСК 1")
get_disk_contents("ДИСК 2", "movie")
```

---

### 3. `get_media_card`

**Назначение**: Получение полной карточки (метаданных) конкретного медиа по точному названию.

**Когда использовать**:
- Пользователь просит "карточку Титаника"
- Нужны полные сведения: жанр, актёры, сюжет, рейтинги

**Аргументы**:
- `title` (string, **обязательный**): точное название (включая год, если есть)
- `disk_name` (string, опциональный): уточнение диска для дублирующихся названий

**Examples вызова**:
```python
get_media_card("Титаник (Titanic, 1997)")
get_media_card("Фауда", "ДИСК 1")
```

---

### 4. `rag_search`

**Назначение**: Семантический поиск по всей медиатеке через естественный запрос.

**Когда использовать**:
- Пользователь описывает настроение или атмосферу: "что-то весёлое для вечера"
- Нужно найти по описанию сюжета: "фильм про любовь на корабле"
- Пользователь не помнит точное название

**Аргументы**:
- `query` (string, **обязательный**): естественный запрос (описание настроения, жанра, атмосферы)
- `top_k` (integer, опциональный): количество результатов (по умолчанию 5)

**Examples вызова**:
```python
rag_search("что-то тёплое и жизнеутверждающее")
rag_search("тёмный детективный сериал", top_k=3)
rag_search("комедия про семью", top_k=10)
```

## Инструкция для ИИ-ассистента

### Порядок действий при запросах о медиа

1. **Определите цель запроса**:
   - Запрос о конкретном названии → `get_media_card` или `search_media`
   - Запрос "что на диске N?" → `get_disk_contents`
   - Запрос по описанию/настроению → `rag_search`

2. **Выберите инструмент**:
   - Точное название → `get_media_card` (предпочтительно) или `search_media`
   - Неполное название → `search_media`
   - Указание диска → `get_disk_contents`
   - Описание настроения → `rag_search`

3. **Вызовите инструмент** через `ask_with_tools()` с соответствующими аргументами.

4. **Обработайте результат**:
   - Если найдено несколько записей — уточните у пользователя
   - Если запись найдена — сформируйте понятный ответ на основе JSON-данных
   - Если ничего не найдено — скажите об этом честно

### Правила работы с инструментами

- ✅ **Всегда** проверяйте, есть ли у пользователя доступ к медиатеке (БД существует)
- ✅ **Всегда** уточняйте диск, если название встречается несколько раз
- ✅ Для длинных описаний (сюжет, отзывы) используйте многострочный формат
- ❌ **Не выдумывайте** данные — если инструмент вернул empty результат, сообщите об этом
- ❌ **Не вызывайте** `rag_search` для точных названий — используйте `search_media` или `get_media_card`

## Examples интеграции

### Пример 1: Запрос о конкретном фильме
```
Пользователь: Покажи карточку Титаника
ИИ: Вызываю get_media_card с параметром title="Титаник"
Результат: JSON с полными данными о фильме
ИИ: Формирует красивый ответ на основе JSON
```

### Пример 2: Запрос по настроению
```
Пользователь: Что-то весёлое посмотреть
ИИ: Вызываю rag_search с параметром query="весёлое", top_k=3
Результат: List комедий
ИИ: Рекомендует 1-3 тайтла с кратким описанием
```

### Пример 3: Содержимое диска
```
Пользователь: Что на диске 2?
ИИ: Вызываю get_disk_contents("ДИСК 2")
Результат: JSON со всеми записями диска
ИИ: Формирует list: "На диске 2 находится 15 фильмов и 3 сериала..."
```

## Технические детали

**Модул��**: `plugins.media_organizer.core.media_tools`

**Экспорт инструментов**:
```python
from plugins.media_organizer.core.media_tools import MEDIA_TOOLS, dispatch_tool_call

# Использование с ai_model
answer = await ai_model.ask_with_tools(question, [MEDIA_TOOLS], dispatch_tool_call)
```

**Function диспетчера**:
```python
from plugins.media_organizer.core.media_tools import dispatch_tool_call

result = dispatch_tool_call("search_media", {"query": "Титаник"})
```

**Структура инструментов** (Google Gemini types):
```python
from google.genai import types

MEDIA_TOOLS = types.Tool(
    function_declarations=[
        types.FunctionDeclaration(...),
        # 4 функции: search_media, get_disk_contents, get_media_card, rag_search
    ]
)
```
