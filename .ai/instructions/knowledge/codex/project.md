# Карта проекта

## Назначение

`ai-assistant` — FastAPI-приложение с веб-чатом на Gemini, локальным медиаплеером, медиатекой SQLite/RAG, плагинами и интеграцией qBittorrent. Основной запуск: `python main.py`.

## Запуск и Configuration

- `main.py` loads `.env` и `core/fastapi/config.json`, creates `FastAPI`, подключает CORS и отдаёт `webinterface/` как `/webinterface`.
- Сервер подключает маршруты чата, qBittorrent, медиатеки и OAuth-авторизации. Страницы: `/`, `/user`, `/tgmini`, `/admin`, `/rc`, `/tv`, `/user_tts`.
- В `main.py` системная инструкция чата загружается из `.ai_instructions/prompts/chat/system_instruction.md`.
- `GoogleGenerativeAI` receives имена ключей из `GEMINI_API_KEY_NAMES` (переменная окружения), а фактические ключи — через `core.secrets.api_key_state`.

## Поток чата

```text
webinterface/user/main.js
  -> POST /api/chat {message}
  -> core/fastapi/router_chat.py
  -> plugins.get('rag').handle() для медиа-запросов (определяется через _is_media_query)
  -> ИЛИ прямой вызов model.chat() / model.chat_stream() для обычных запросов
  -> GoogleGenerativeAI.chat(message) / chat_stream()
  -> {response} в UI через SSE (Server-Sent Events)
```

`BasePlugin.handle()` перехватывает исключения, writes ошибку через `core.logger.logger` и Returns пустую строку. RAG-плагин имеет приоритет для медиа-запросов.

## Loading плагинов

- `plugins/__init__.py` содержит функцию `load_plugins(ai_model)`, которая динамически обходит подкаталоги `plugins/`, импортирует `plugins.<name>` и Raises экспортируемый `plugin(ai_model)`.
- Плагины регистрируются в словаре `{name: instance}` и передаются в `init_chat_router(model, plugins)`.
- Плагины можно отключить через переменную окружения `DISABLED_PLUGINS` (через запятую).
- `plugins/media_organizer/__init__.py` экспортирует функции БД и RAG через `media_organizer_core`.
- `plugins/media_organizer/core/media_organizer.py` содержит отдельный `MediaOrganizerPlugin` для сканирования, классификации и отчётов.
- Также присутствуют `telegram_bot`, `qbittorrent`, `rag` и `media_layer`.

## HTTP API (проверенные группы)

| Группа | Module | Назначение |
| --- | --- | --- |
| `/api/chat` | `core/fastapi/router_chat.py` | Сообщение чата и ответ модели/плагина. |
| `/api/media` | `core/fastapi/router_media.py` | Сканирование, аудит, пересборка БД/RAG, поиск, файлы и поток воспроизведения. |
| `/api/torrents` | `core/fastapi/router_qbittorrent.py` | Каталоги, list, check, перемещение и категории qBittorrent. |
| `/auth` | `core/fastapi/router_auth.py` | Check сессии и Google OAuth. |

Полезный уже реализованный контракт: `POST /api/media/by-title` принимает `title` и необязательный `type`, ищет `title`, `title_ru` и `title_orig`, фильтруя по `type` если указан, и Returns запись с путём. Он предназначен для связки чатовой рекомендации с плеером.

## Веб-интерфейсы

Проект предоставляет несколько специализированных интерфейсов для разных задач:

### 1. Основной пользовательский интерфейс (`/user`)
- **Файлы:** `webinterface/user/`
- **Description:** Объединённый интерфейс с чатом AI, встроенным медиаплеером, авторизацией и обработкой торрент-ссылок
- **Функции:**
  - AI-чат с Gemini и потоковым RAG-поиском
  - Медиаплеер с поддержкой различных форматов
  - Integration с системой автоматического управления медиа
  - Поддержка голосового ввода (Speech-to-Text)
  - Обработка торрент-ссылок через qBittorrent

### 2. Административный интерфейс (`/admin`)
- **Файлы:** `webinterface/admin/` (основной каркас), `webinterface/admin_tab/` (вкладка управления)
- **Защита:** Парольная защита (пароль: `onela`)
- **Вкладки:**
  - **💬 Чат** — административный AI-чат
  - **🧲 Торренты** — управление qBittorrent
  - **🎬 Медиатека** — управление медиатекой и сканирование
  - **⚙️ Управление** — системные настройки и инструменты
  - **📚 Справочник** — документация и справка
- **Функции:**
  - Полный контроль над системой управления медиа
  - Мониторинг состояния агентов предзагрузки и очистки
  - Управление дисковыми квотами
  - Настройка RAG-индексов
  - Администрирование пользователей

### 3. Пульт дистанционного управления (`/rc`)
- **Файлы:** `webinterface/rc/`
- **Description:** Упрощённый интерфейс для голосового управления
- **Функции:**
  - Голосовой ввод через Web Speech API
  - Text-to-Speech озвучивание ответов
  - Быстрый доступ к медиаплееру
  - Управление воспроизведением голосом

### 4. Telegram Mini App (`/tgmini`)
- **Файлы:** `webinterface/tgmini/`
- **Description:** Интерфейс для интеграции с Telegram
- **Функции:**
  - Удалённое управление медиаплеером
  - Получение уведомлений о состоянии системы
  - Быстрый доступ к основным функциям

### 5. Телевизионный интерфейс (`/tv`)
- **Файлы:** `webinterface/tv/`
- **Description:** Упрощённый интерфейс для телевизоров и больших экранов
- **Функции:**
  - Крупные элементы управления
  - Простая навигация
  - Оптимизация для TV-пультов

### 6. TTS-интерфейс (`/user_tts`)
- **Файлы:** `webinterface/user_tts/`
- **Description:** Специализированный интерфейс для работы с Text-to-Speech
- **Функции:**
  - Тестирование TTS функций
  - Настройка голосового синтеза
  - Предпросмотр аудио-ответов

### Moduleные вкладки

Интерфейсы используют Moduleную систему вкладок:
- `webinterface/chat/` — компоненты чата
- `webinterface/media/` — компоненты управления медиатекой
- `webinterface/torrents/` — компоненты управления торрентами
- `webinterface/help/` — справочные материалы

### Поддержка локализации

- **Файлы:** `webinterface/locales/`
- **Поддерживаемые языки:** Русский, Английский
- **Система:** i18next для динамической смены языка

### Технические детали

- **Статика:** `main.py` монтирует `webinterface/` как `/webinterface`
- **Роутинг:** Некоторые интерфейсы используют пути `/html/...` через перенаправление
- **Безопасность:** Admin-интерфейс защищён паролем
- **Moduleность:** Компоненты переиспользуются между интерфейсами


## Системы автоматического управления медиа (новые)

Проект расширен системой интеллектуального управления медиа-ресурсами, включающей следующие компоненты:

### 1. Агент фоновой предзагрузки сериалов (`torrent_prefetch_agent.py`)
- Автоматически возобновляет скачивание следующих сезонов для активно просматриваемых сериалов
- Соблюдает квоту активных закачек (25% свободного пространства)
- Определяет активные сериалы через анализ профилей пользователей
- Интегрирован с qBittorrent для управления Loadingми

### 2. Интерактивный агент очистки медиатеки (`interactive_retention_agent.py`)
- Анализирует профили пользователей и находит кандидатов на очистку
- Определяет полностью просмотренные (completed) сериалы и фильмы
- Находит контент, не просматривавшийся более 30 дней
- Предоставляет интерактивные функции для удаления с сохранением метаданных
- Изменяет status торрентов в qBittorrent на "Do Not Download"

### 3. Менеджер квот дискового пространства (`disk_quota_manager.py`)
- Анализирует свободное и занятое пространство на дисках медиатеки
- Рассчитывает квоты: 70% для постоянного хранилища, 25% для буфера закачек, 5% НЗ
- Мониторит использование дискового пространства
- Предоставляет рекомендации по управлению медиа-контентом

### 4. Детектор активности просмотра (`watch_activity_detector.py`)
- Анализирует RAG-профили пользователей для определения активно просматриваемого контента
- Определяет законченные сериалы и фильмы
- Мониторит активность пользователей для оптимизации управления контентом

### Архитектура взаимодействия

```text
Пользовательские RAG-профили
        ↓
WatchActivityDetector → активно просматриваемые сериалы
        ↓
TorrentPrefetchAgent → автоматическая предLoading следующих сезонов
        ↓
DiskQuotaManager → управление квотами дискового пространства
        ↓
InteractiveRetentionAgent → рекомендации по очистке медиатеки
        ↓
Integration с qBittorrent → управление Loadingми и статусами
```

### Использование и мониторинг

Система работает в фоновом режиме и интегрирована с существующей архитектурой плагинов. Для ручного запуска доступны скрипты в корневой директории проекта. Все компоненты используют единую базу данных медиатеки и настроены на совместную работу для оптимизации медиа-ресурсов.
