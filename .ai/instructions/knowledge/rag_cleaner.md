# RAG Document Cleaner Plugin Guide (`rag_cleaner.md`)

## 📋 Overview

The `rag-cleaner` plugin is an ingestion, sanitization, and semantic chunking tool designed to prepare heterogeneous user documents (archives, Word documents, PDFs, web pages, tables, JSON, and text) for high-quality Retrieval-Augmented Generation (RAG).

It cleans up noise, normalizes text representations, removes broken formatting, and produces structured Markdown chunks ready for embedding and vector database ingestion.

---

## 🎯 Supported File Formats

| Category | File Extensions | Processing Method |
|---|---|---|
| **Archives** | `.zip`, `.tar`, `.gz`, `.tgz`, `.bz2` | Safe recursive extraction, junk/system file filtering (`__MACOSX`, `.DS_Store`, `~$*`) |
| **Word Documents** | `.docx` | Pure Python XML extraction converting headers to Markdown (`#`, `##`) and tables to Markdown syntax |
| **PDF Documents** | `.pdf` | Multi-engine text extraction with page separation and fallback heuristics |
| **Web & HTML** | `.html`, `.htm` | HTML-to-Markdown conversion preserving structure via `src.utils.convertors.html2text` |
| **Tabular Data** | `.csv` | Parsed via `src.utils.csv` and serialized to per-row JSON/Markdown objects |
| **Structured JSON** | `.json` | Safe loading and indent formatting via `src.utils.jjson` |
| **Plain Text / Markdown** | `.txt`, `.md`, `.rst`, `.log` | Loaded via `src.utils.file` and sanitized |

---

## 🞩 Sanitization Features

The cleaner pipeline automatically executes:
1. **Unicode Sequence Repair:** Decodes `\uXXXX` escape sequences into human-readable text via `src.utils.convertors.unicode`.
2. **Line Break & Hyphenation Normalization:** Converts CRLF/CR to LF and repairs broken word hyphens (`docu-\nment` -> `document`).
3. **Control Character Removal:** Strips unprintable binary artifacts (`\x00-\x08`, `\x0B-\x0C`, `\x0E-\x1F`, `\x7F`).
4. **Blank Line Compression:** Replaces multiple blank lines (`\n{3,}`) with clean Markdown paragraph breaks (`\n\n`).
5. **Semantic Chunking:** Splits Markdown text on section boundaries (`#`, `##`, `###`) and paragraphs while respecting configurable min/max chunk lengths.

## 🚀 How to Run the Plugin

### 1. Command Line Interface (CLI)

#### Process a Single File or Archive and Preview Chunks:
```powershell
python .agents/skills/rag-cleaner/scripts/rag_cleaner.py --input "path/to/document.pdf"
```

#### Process an Entire Directory or Archive to a JSONL Output:
```powershell
python .agents/skills/rag-cleaner/scripts/rag_cleaner.py --input "path/to/archive_or_folder" --output "cleaned_rag_chunks.jsonl"
```

#### CLI Options:
* `--input`, `-i` *(required)*: Path to the file, archive (`.zip`/`.tar`), or directory.
* `--output`, `-o` *(optional)*: Path to output `.jsonl` file containing structured chunks.

---

### 2. Python API Integration

You can integrate `RAGDocumentCleaner` directly into your pipelines:

```python
from pathlib import Path
from agents.skills.rag_cleaner.scripts.rag_cleaner import RAGDocumentCleaner

# Initialize cleaner with custom chunk bounds
cleaner = RAGDocumentCleaner(min_chunk_len=50, max_chunk_len=1500)

# Process a specific file (or extracted archive member)
chunks = list(cleaner.process_file(Path("user_data.docx")))

for chunk in chunks:
    print(f"Source: {chunk['source']}")
    print(f"Doc Type: {chunk['doc_type']}")
    print(f"Content:\n{chunk['content']}\n")

# Or process a whole folder recursively:
all_chunks = cleaner.process_target(Path("data/raw_docs/"))
print(f"Total chunks ready for vector DB: {len(all_chunks)}")
```

```json

  "content": "# Document Section Title\n\nCleaned and normalized text content...",
  "source": "C:\\Users\\onela\\AppData\\Local\\AI-Breadboard\\data\\sample.docx",
  "length": 142,
  "doc_type": "docx"
}
```
