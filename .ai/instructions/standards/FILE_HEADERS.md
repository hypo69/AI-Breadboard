# Шаблон заголовка файла проекта

## Общие требования
- **Все заголовки** должны быть на русском языке.
- Должен присутствовать блок `Description`, `Location in project tree`, `Dependencies`, `Usage example` и мета‑информация (author, copyright, encoding).
- Формат заголовка должен соответствовать стилю, используемому в `ENGINEERING.md` и `GEMINI.md`.

---

```python
"""
# -*- coding: utf-8 -*-
# =============================================================================
# Process Name: <Краткое название процесса>
# =============================================================================
# Description:
#   Краткое описание того, что делает модуль, какие задачи решает.
#   • <Первый пункт>
#   • <Второй пункт>
#   • …
#
# Location in project tree:
#   <директория>/<файл>.py   # укажите точный путь относительно корня проекта
#
# Dependencies:
#   • <модуль/пакет> – краткое пояснение, зачем нужен.
#   • <модуль/пакет> – …
#   • Стандартная библиотека: <list of stdlib modules>
#
# Usage example:
#   >>> from <module> import <object>
#   >>> <object>(...)  # пример типичного вызова
#
# File: <имя файла>
# Project: AI‑Breadboard
# Package: <пакет/директория>
# Author: <ваше имя>
# Copyright: © <год> <ваше имя>
# =============================================================================
"""
```

---

### Как использовать шаблон
1. Скопируйте блок кода выше в начало нового `.py`‑файла.
2. Заполните placeholder‑значения (Process Name, Description, Location, Dependencies, Usage example, File, Package, Author).
3. Сохраните файл – проверка будет проходить автоматически в линтере CI.

### Пример готового заголовка
```python
"""
# -*- coding: utf-8 -*-
# =============================================================================
# Process Name: Проверка версии и автоматическое обновление приложения
# =============================================================================
# Description:
#   Модуль отвечает за:
#   • получение текущей локальной версии (из `setup.cfg`);
#   • запрос последней версии из GitHub;
#   • сравнение версий согласно SemVer;
#   • интерактивный запрос у пользователя (или авто‑обновление при `AUTO_UPDATE=1`);
#   • выполнение `git fetch` + `git merge --ff-only`.
#
# Location in project tree:
#   src/app/versioning.py               # часть приложенческого слоя
#
# Dependencies:
#   • logger – централизованный логгер (`src/logger/logger.py`);
#   • src.utils.versioning – функции `compare_versions` и `choose_best_tag`;
#   • stdlib: configparser, json, os, re, subprocess, sys, urllib.request, pathlib.
#
# Usage example:
#   >>> from src.app.versioning import prompt_and_perform_update
#   >>> prompt_and_perform_update()
#
# File: versioning.py
# Project: AI‑Breadboard
# Package: src.app
# Author: hypo69
# Copyright: © 2026 hypo69
# =============================================================================
"""
```

---

### Примечание
Этот файл (`FILE_HEADERS.md`) считается **частью системных инструкций** проекта. При добавлении новых файлов разработчики должны ориентироваться именно на данный шаблон, что гарантирует единообразие и упрощает автоматическую проверку.
