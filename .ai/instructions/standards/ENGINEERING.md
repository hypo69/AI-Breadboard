## 1. RFC 2119 ключевые слова

Требования к реализации используют стандарт RFC 2119:

- **MUST (ОБЯЗАТЕЛЬНО)** — Абсолютное требование. Нарушение делает код неприемлемым.
- **MUST NOT (ЗАПРЕЩЕНО)** — Абсолютный запрет. Использование **категорически недопустимо**.
- **SHOULD (РЕКОМЕНДУЕТСЯ)** — Следует при отсутствии веских причин для отклонения.
- **MAY (ДОПУСКАЕТСЯ)** — Полностью опциональное действие.

## 2. Фундаментальные архитектурные принципы

### 2.1 Читаемость важнее краткости (Readability Over Cleverness)
Код пишется для людей. **MUST NOT** использовать скрытые трюки синтаксиса, ухудшающие читаемость.

### 2.2 Принцип единственной ответственности (Single Responsibility)
Каждый модуль, класс и функция **MUST** решать **только одну** логическую задачу.

### 2.3 Явное лучше неявного (Explicit is Better than Implicit)
- Зависимости **MUST** передаваться явно (Dependency Injection).
- Глобальное состояние **MUST NOT** использоваться; все параметры **MUST** передаваться через конфигурацию.

### 2.4 Ранний возврат и отказоустойчивость (Early Return & Fail-Fast)
Функции **MUST** завершать выполнение сразу при обнаружении невалидных входных данных:

```python
# ✅ Правильно: Ранний возврат
def process_data(data: dict) -> bool:
    if not data:
        return False
    # Основная логика
    return True

# ❌ Неправильно: Глубокая вложенность
def process_data(data: dict) -> bool:
    if data:
        # Основная логика
        return True
    return False
```

### 2.5 Конфигурация вместо жесткого кодирования (Configuration Over Hardcode)
Все параметры (порты, URL, таймауты, пути) **MUST NOT** быть жестко закодированы. **MUST** считываться из конфига или переменных окружения:

```python
# ✅ Правильно
port = config.port

# ❌ Неправильно
port = 8000
```

### 2.6 Категорический запрет `None` (No None Rule)

**КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** использовать и ссылаться на `None` в исходном коде.

#### 2.6.1 Сигнатуры функций

```python
# ❌ ЗАПРЕЩЕНО
def execute(timeout: Optional[int] = None, text: Optional[str] = None) -> None:
    pass

# ✅ ОБЯЗАТЕЛЬНО
def execute(timeout: Optional[int] = 0, text: Optional[str] = '') -> Self:
    pass
```

#### 2.6.2 Инициализация переменных

```python
# ❌ ЗАПРЕЩЕНО
result = None
data = None

# ✅ ОБЯЗАТЕЛЬНО
result = False
data = {}
```

#### 2.6.3 Операторы сравнения

```python
# ❌ ЗАПРЕЩЕНО
if value is None:
    pass

# ✅ ОБЯЗАТЕЛЬНО
if not value:
    pass
```

#### 2.6.4 Возвращаемые значения

```python
# ❌ ЗАПРЕЩЕНО
def fetch_data():
    if error:
        return None  # или пустой return
    return data

# ✅ ОБЯЗАТЕЛЬНО
def fetch_data():
    if error:
        return False  # или другое значение по умолчанию
    return data
```

## 3. Правила проектирования и устранение Code Smells

### 3.1 Ограничение вложенности (Nesting Limit ≤ 3)
Глубина вложенности циклов и условий **SHOULD NOT** превышать **3 уровней**. Если больше — разбейте на отдельные функции.

### 3.2 DRY: Поиск существующего кода (Prior Art Audit)
**ПЕРЕД** разработкой новой функциональности **MUST** выполнить поиск в кодовой базе:
- Ищите похожие функции, компоненты, утилиты.
- Если существует рабочая реализация на 80%+ — **переиспользуйте или расширьте**, не дублируйте.
- Смотрите [`standards/REUSE.md`](REUSE.md) для полного протокола.

### 3.3 Мертвый код (Dead Code)
Неиспользуемые переменные, импорты, функции **MUST** удаляться сразу. Закомментированный код **MUST NOT** оставляться.

### 3.4 Размер функций и файлов (≤ 500 строк)
Любая функция или модуль **MUST NOT** превышать **500 строк кода** (без комментариев и docstrings).
Если превышает — декомпозируйте на несколько функций меньшего размера.

### 3.5 Запрет на незаконченный код
Генерация TODO/FIXME комментариев, заглушек `...` вместо логики **MUST NOT** допускаться:

```python
# ❌ ЗАПРЕЩЕНО
def process():
    # TODO: реализовать позже
    pass

# ✅ ОБЯЗАТЕЛЬНО: Либо реализуйте полностью, либо не коммитьте
def process():
    # Полная реализация
    pass
```

## 4. Языковые стандарты

### 4.1 Python (v3.12+)

**Обязательный заголовок файла:**

```python
# -*- coding: utf-8 -*-
# =============================================================================
# Process Name: Интеграция с локальным сервером Foundry
# =============================================================================
# Description:
#   Организация взаимодействия с API Foundry через HTTP-протокол.
#   Выполнение проверок доступности портов и управление процессами.
#
# Examples:
#   >>> from src.ai.providers.foundry import FoundryConnector
#   >>> connector = FoundryConnector(port=config.port)
#   >>> connector.verify_status()
#
# File: foundry_connector.py
# Project: AI Breadboard
# Module: src.ai.providers.foundry
# Class: FoundryConnector
# Author: hypo69
# Copyright: © 2026 hypo69
# =============================================================================
```

**Правила:**
- Импорты разделяются на 3 блока: stdlib → third-party → project imports.
- Все импорты **MUST** быть отсортированы по алфавиту.
- Type hints **MUST** использоваться везде.
- Используйте `Self`, `Optional`, `Protocol` из `typing`.

**Пример класса:**

```python
from typing import Self, Optional

class FoundryConnector:
    """Обеспечение соединения с API Foundry.
    
    Управление локальными процессами и мониторинг состояния портов.
    
    Attributes:
        port (int): Номер сетевого порта сервера.
        status (str): Текущее состояние подключения.
    """

    def __init__(self, port: int) -> None:
        """Инициализация объекта подключения.
        
        Args:
            port (int): Номер порта сервера.
        """
        self.port = port
        self.status: str = "disconnected"

    def execute_connection(self, timeout: Optional[int] = 0) -> Self:
        """Запуск процесса подключения к серверу.
        
        Args:
            timeout (Optional[int]): Максимальное время ожидания в секундах.
                                     Значение по умолчанию: 0.
        
        Returns:
            Self: Текущий экземпляр объекта для цепочки вызовов.
        
        Exceptions:
            ConnectionError: При недоступности порта.
        
        Examples:
            >>> connector = FoundryConnector(port=8000)
            >>> result = connector.execute_connection(timeout=10)
            >>> print(result.status)
            connected
        """
        if self.port <= 0:
            raise ConnectionError("Неверный номер порта")
        
        self.status = "connected"
        return self
```

## 7. AI провайдеры и системные правила

### 7.1 UnifiedChatModel архитектура
- Все операции с AI моделями **MUST** выполняться через `UnifiedChatModel`.
- Прямые вызовы провайдеров **MUST NOT** использоваться.
- Поддержка автоматического переключения между провайдерами.

### 7.2 FastAPI роутеры
- Каждый роутер **MUST** иметь функцию `init_router()`.
- Префиксы **MUST** начинаться с `/api/`.
- Все исключения **MUST** обрабатываться с корректными HTTP статусами.

### 7.3 Система плагинов
- Все плагины **MUST** наследоваться от `BasePlugin`.
- Плагины **MUST** реализовывать async метод `handle(message: str, **kwargs)`.
- Поддержка потокового вывода через `yield` **MUST** быть реализована.

Смотрите [`workflows/INTEGRATION.md`](../workflows/INTEGRATION.md) для полного 6-этапного протокола добавления нового приложения.
