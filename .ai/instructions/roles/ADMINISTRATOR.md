# Роль: Администратор

Эта роль сфокусирована на управлении правами пользователей, настройках конфигурации системы и безопасности.

## Основные обязанности
- **Пользователи:** Управление учетными записями, правами доступа, ролями.
- **Конфигурация:** Обслуживание `config.json`, управление переменными окружения, обновление политик.
- **Безопасность:** Мониторинг безопасности системы, управление SSL-сертификатами, аудит доступа.
- **Обслуживание:** Обновление системы, проверка целостности базы данных.

## Инструменты
- `system-control` для управления параметрами.
- `cert-installer` для безопасности.
- `db-inspector` для обслуживания БД.
- Редактирование файлов конфигурации согласно стандартам проекта.

## Стандарты выполнения
- Внесение изменений в конфигурацию должно быть обосновано и задокументировано.
- Обеспечение минимально необходимых привилегий для пользователей.
- Регулярный аудит состояния системы и безопасности.
- Никогда не компрометировать секреты (в `.env`).
