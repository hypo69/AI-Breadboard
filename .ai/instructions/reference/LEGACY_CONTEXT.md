## 1. История проекта

### Генезис

AI Breadboard начался как простой wrapper вокруг Google Gemini API. Со временем эволюционировал в полнофункциональный developer workbench для AI экспериментирования и маршрутизации.

### Основные вехи

- **v0.1** (2023) — Простой Gemini client
- **v0.5** (2024) — Добавлена поддержка нескольких провайдеров
- **v1.0** (2024) — FastAPI веб-интерфейс
- **v2.0** (2025) — MCP поддержка, плагины, RAG
- **v3.0** (2026) — Полная переархитектура, унификация

## 2. Архитектурные решения

### Почему UnifiedChatModel?

Вместо того чтобы давать разработчикам прямой доступ к каждому провайдеру, мы создали `UnifiedChatModel` чтобы:
- Скрывать различия между API-шками
- Обеспечить единообразный интерфейс
- Упростить переключение между провайдерами
- Добавлять кросс-провайдерные функции (RAG, streaming и т.д.)

### Почему FastAPI?

FastAPI выбран потому что:
- Быстрый (асинхронный)
- Автоматическая генерация Swagger docs
- Встроенная валидация данных (Pydantic)
- Отличная поддержка WebSocket'ов
- Растущее сообщество

### Почему файловая структура `src/ai/providers/`?

Модульная структура позволяет:
- Добавлять новых провайдеров без изменения основного кода
- Изолировать логику каждого провайдера
- Тестировать провайдеры независимо
- Отключать провайдеров через конфиг

## 3. Known Issues & Technical Debt

### Известные проблемы

1. **Ray tracing на GPU** — ONNX иногда неправильно обрабатывает complex моделей
2. **Windows AI API delays** — Первый вызов может быть медленным
3. **RAG embedding latency** — Для больших документов требуется оптимизация

### Технический долг

- Миграция с SQLite на PostgreSQL (планируется v3.5)
- Переписать старый WebSocket код (в процессе)
- Покрытие тестами недостаточно в некоторых модулях
