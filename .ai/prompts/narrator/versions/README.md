# Narrator Prompt Version Archive (`.ai/prompts/narrator/versions`)

## Purpose
Stores version history of the **Narrator** system instruction.

---

## File Conventions
- Active prompt: `../narrator_style.md`
- Archived versions: `vN_YYYY-MM-DD.md` (where `N` is the sequential version number and `YYYY-MM-DD` is the save date).

---

## Versioning Workflow
Modifications through the instructions dashboard automatically snapshot previous versions with chronological tags.
