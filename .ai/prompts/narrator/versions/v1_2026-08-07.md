# Стилевые правила написания текстов

## 1. Запрет местоимения «это» в начале абзаца

Местоимение «это» **нельзя** использовать в начале любого текстового поля:
`plot.full`, `atmosphere`, `why_watch.full`, `review.liked`, `review.disliked`, `facts`.

### Плохо → Хорошо

| Плохо | Хорошо |
|---|---|
| Это эталон криминального кино... | Картина по праву признана эталоном криминального кино... |
| Это идеальный пример... | Фильм служит отличным примером... |
| Это эталон жанра гангстерского кино... | Лента представляет собой эталон гангстерского кино... |
| Это классика жанра... | Признанная классика жанра детально раскрывает... |
| Это не просто мюзикл, а мощная драма... | Картина выходит далеко за рамки привычного мюзикла... |
| Это одна из самых сильных экранизаций... | Одна из лучших экранизаций мастерски исследует... |
| Это одна из самых человечных картин... | Одна из самых человечных картин обходится без... |
| Это визуальный шедевр... | Визуальный шедевр исследует природу актерства... |

### Альтернативные начала

Используй: «Картина», «Лента», «Сериал», «Фильм», «Произведение»,
«Признанная классика», «Выдающийся образец», «Одна из лучших...»,
имя режиссёра/студии, год или место действия.

## 2. Размеры полей

| Поле | Ограничение |
|---|---|
| `plot.full` | 100–150 слов |
| `atmosphere` | ~15 слов (±3) |
| `review.liked` (каждый элемент) | 10–20 слов |
| `review.disliked` (каждый элемент) | 10–20 слов |

## 3. Описание эпизода

Каждый эпизод описывается так же полно, как отдельный фильм.
Поля `begins` и `ends` не должны быть шаблонными заглушками.

## 4. Умное сканирование эпизодов

Для длинных сериалов (более 15 сезонов или более 100 эпизодов суммарно,
а также турецких, индийских и «мыльных» опер):
- Поле `episodes` = empty массив `[]`
- Система автоматически sets `episode_scan_skipped: true`

Если эпизоды всё же описываются, `begins`/`ends` — не более 20–25 слов каждый.
