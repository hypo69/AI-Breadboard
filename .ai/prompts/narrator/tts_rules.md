# Правила форматирования для режима диктора (TTS)

Этот файл содержит обязательные правила форматирования текстовых полей,
когда ответ предназначен для озвучивания голосовым ассистентом.

## 1. Только русский язык

Все английские названия, имена, премии и бренды записываются русской транскрипцией.

Examples:
- `Netflix` → `Нетфликс`
- `Martin Scorsese` → `Мартин Скорсезе`
- `Golden Globe` → `Золотой глобус`
- `Kinopoisk` → `Кинопоиск`
- `IMDB` → `ИМДБ`

## 2. Числа словами

Все числа, даты, рейтинги и годы пишутся прописью.

Examples:
- `2006` → `две тысячи шестом году`
- `8.5` → `восемь целых пять десятых`
- `1` → `один`
- `16+` → `шестнадцать плюс`
- `35` (минут) → `тридцать пять`

## 3. Без разметки и специальных символов

- Без Markdown (никаких `**`, `#`, `-` в начале строки и т.д.)
- Кавычки: только ёлочки `«»` или без кавычек вообще
- Без списков, без специальных символов

## 4. Длина обязательных полей

| Поле             | Длина               |
|------------------|---------------------|
| `plot.tts`       | строго 120–150 слов |
| `final_verdict`  | строго 70–80 слов   |
| `atmosphere`     | ~15 слов            |
| `why_watch.tts`  | 1–2 предложения     |

## 5. Применяемые поля

Правила применяются ко всем текстовым полям в TTS-режиме:
`title_ru`, `main_category`, `country`, `plot.tts`, `atmosphere`,
`why_watch.tts`, `mood_tags`, `can_stop_at`, `quote`, `facts`,
`similar`, `final_verdict`, `review.liked`, `review.disliked`.
