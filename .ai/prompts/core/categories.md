# Разрешённые категории медиа

Каждый фильм или сериал должен быть отнесён к одной и только одной категории из списка ниже.

## List категорий

- Боевики
- Триллеры
- Военные
- Аферы
- Приключения
- Семейные
- Исторические/Костюмированные
- Расследования
- Деньги / Корпорации / Deep State
- Шпионы
- Мюзиклы

## Правила выбора

- Если медиа подходит под несколько категорий, выбирается та, которая наиболее точно
  отражает главную тему.
- Категория записывается в поле `main_category` без изменений (точно как в списке выше).
