# Chat Prompt Version Archive (`.ai/prompts/chat/versions`)

## Purpose
Stores version history of the primary **Chat** system instruction.

---

## File Conventions
- Active prompt: `../system_instruction.md`
- Archived versions: `vN_YYYY-MM-DD.md` (where `N` is the sequential version number and `YYYY-MM-DD` is the save date).

---

## Versioning Workflow
Saving changes via the web interface (`webinterface/instructions_tab`) automatically archives the previous prompt with an incremented version number before writing the new active prompt.
