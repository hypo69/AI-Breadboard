# AI Agent Utilities (`.ai/tools/ai`)

## Purpose
Scripts designed for direct execution by AI coding agents and automated maintenance workers.

---

## Tools

| Script | Purpose | Command |
|---|---|---|
| `rebuild_dev_rag.py` | Rebuilds the technical vector RAG index over codebase files. | `python .ai/tools/ai/rebuild_dev_rag.py` |
| `search_code.py` | Semantic search over project source code and docstrings. | `python .ai/tools/ai/search_code.py --query "UnifiedChatModel"` |
