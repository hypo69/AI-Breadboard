# Codebase Setup & Audit Tools (`.ai/tools/setup`)

## Purpose
Tooling for static codebase analysis, dependency tree verification, and structural refactoring audits.

---

## Tools

| Script | Purpose | Command |
|---|---|---|
| `analyze_dependencies.py` | Validates installed packages against requirement files. | `python .ai/tools/setup/analyze_dependencies.py` |
| `scan_headers.py` | Verifies docblock compliance and module headers. | `python .ai/tools/setup/scan_headers.py` |
