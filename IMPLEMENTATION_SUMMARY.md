### Задача 3-6: Система управления версиями ✅

**Новый Module: core/version_manager.py**

Реализован полнофункциональный class `VersionManager` с методами:

1. **check_updates()** - Check доступности обновлений
   - Receives текущую версию из git тегов
   - Checks удалённую версию
   - Returns полную информацию о версиях

2. **backup_files()** - Создание резервной копии
   - Creates резервную копию в systemе temp папке
   - Saves метаинформацию в .backup_info.json
   - Гарантирует целостность данных

3. **restore_from_backup()** - Восстановление из резервной копии
   - Восстанавливает файлы из резервной копии
   - Полностью откатывает приложение при ошибке

4. **fetch_updates()** - Скачивание обновлений
   - Performs git fetch из удалённого репозитория
   - Безопасное скачивание без применения изменений

5. **merge_updates()** - Объединение обновлений
   - Применяет обновления через git merge
   - Обнаруживает и processes конфликты слияния

6. **update_application()** - Полное update с резервным копированием
   - Checks обновления
   - Creates резервную копию
   - Downloads и применяет обновления
   - Восстанавливает при ошибке

7. **cleanup_old_backups()** - Очистка старых резервных копий
   - Deletes старые резервные копии
   - Оставляет последние N копий

## 🔄 Процесс обновления (пошагово)

```
1. Check наличия обновлений
   ↓
2. Создание резервной копии в temp
   ↓
3. Скачивание обновлений (git fetch)
   ↓
4. Применение обновлений (git merge)
   ↓
5. Check успеха
   ├─ Success → Очистка старых копий → Shutdown
   └─ Error → Восстановление из резервной копии → Сообщение об ошибке
```
