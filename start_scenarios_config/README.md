# Конфигурация сценариев запуска (`config/`)

Директория содержит публичные JSON-конфигурации сценариев запуска платформы **AI Breadboard**.

Каждый файл соответствует конкретному сценарию (PowerShell-скрипту) и определяет параметры его окружения:
хост и порт сервера, активные AI-провайдеры, список разрешенных приложений (`apps.enabled`), флаги авторизации (OAuth) и интеграции с системным треем.

## 🔒 Основные правила

1. **Безопасность**: Секреты (API-ключи, токены, пароли) — **только в `.env`**, не в JSON-конфигурациях.
2. **Изоляция приложений**: Каждое приложение хранит свои локальные настройки в `apps/<name>/config.json`.
3. **Расширяемость**: Добавление нового сценария требует создания файла `config/<name>.json`, лончера `Run-<Name>.ps1` и регистрации эндпоинта в `src/app/pages/__init__.py`.
