# Skill Factory

Этот навык автоматизирует создание и упаковку других навыков Gemini CLI.

## 🚀 Основные возможности

1. **Инициализация:** Создание структуры нового навыка.
2. **Упаковка:** Автоматическая сборка навыка в файл `.skill` с помощью `package_skill.py`.

## 🛠️ Как использовать

### Упаковка навыка
Для упаковки навыка выполните команду, указав путь к папке навыка:

```bash
python .gemini\skills\skill-factory\scripts\pack.py <путь_к_папке_навыка>
```

Скрипт автоматически создаст директорию `dist` внутри папки навыка и упакует его в `.skill`.

## ⚙️ Структура

- `scripts/pack.py` - основной скрипт для упаковки.
- `scripts/init.py` - скрипт для создания структуры (будет добавлен позже).
