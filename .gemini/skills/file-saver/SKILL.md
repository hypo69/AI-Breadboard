# File Saver

## 🚀 Быстрый старт

Используйте этот навык для сохранения файлов.

- **Сохранение текстового файла:**
  `python save_file.py --path <путь> --content "<текст>"`

## 📂 Структура

- `scripts/` - скрипты для сохранения файлов.
- `references/` - руководства по работе с файловой системой.
