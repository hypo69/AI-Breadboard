# Медиа-менеджер

## 🚀 Быстрый старт

Используйте этот навык для выполнения операций с медиатекой через командную строку.

- **Запуск полного сканирования:**
  `python run_media_organizer.py`
- **Запуск аудита конкретного диска:**
  `python audit_media.py --disk ДИСК_N`
- **Классификация отдельного медиа:**
  `python run_media_organizer.py --title "Название"`
