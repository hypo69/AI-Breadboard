# Storage Tool

## 🚀 Быстрый старт

Используйте этот навык для управления и мониторинга хранилища.

- **Аудит физического наличия файлов:**
  `python audit_disk.py`
- **Обновление статистики размеров файлов в БД:**
  `python update_media_sizes.py`
- **Просмотр статистики по дискам:**
  `python view_storage.py`
- **Обновление размеров для специфических дисков:**
  `python update_specific_drives_sizes.py`
