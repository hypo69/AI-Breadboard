# Torrent Controller

## 🚀 Быстрый старт

Используйте этот навык для управления интеграцией с qBittorrent.

- **Назначение ID и категорий:**
  `python assign_torrents_ids.py`
- **Синхронизация путей:**
  `python update_torrents_path.py`
- **Проверка целостности (recheck):**
  `python update_torrent_state.py`
- **Очистка метаданных:**
  `python clear_torrents_meta.py`
