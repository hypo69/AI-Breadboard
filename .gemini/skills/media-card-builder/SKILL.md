# Media Card Builder (Составитель карточек медиа)

Этот навык содержит стандарты и шаблоны для создания карточек фильмов и сериалов. Карточки должны быть увлекательными, информативными и иметь четкую структуру без избыточных сухих маркеров.

## 📋 Общие требования к контенту

1. **Общее описание (сюжет):** Должно быть в пределах 150–200 слов (не менее 100 слов).
2. **Атмосфера:** Краткая емкая формулировка (~15 слов), передающая настроение и стиль релиза.
3. **Описания эпизодов:**
   - Каждое описание должно быть оформлено как единый связный абзац в пределах **50–60 слов**.
   - **Запрещено использовать сухие маркеры** вида «С чего начинается» / «Чем заканчивается». Текст должен быть плавным и интересным, описывая ключевую завязку, конфликт и развязку серии.
4. **Финал сезона:** Краткое резюме итогов сезона в 1–2 предложениях.

---

## 📐 Шаблон карточки (Markdown)

```markdown
# Название (Оригинальное название) (Год выпуска / 1–N сезоны)

**Тип медиа** (Фильм / Сериал)  
**Основной жанр** + Другие жанры  
**Категория в фильмотеке:** [Категории через запятую]  

**Страна производства:** ...  
**Жанр:** ...  
**Режиссеры:** *Имя Фамилия, ...*  
**В главных ролях:** *Имя Фамилия, ...*  

**Сюжет:**  
[Связанный текст сюжета: 150–200 слов]  

**Атмосфера:** [Описание атмосферы: ~15 слов]  

---

## Сезон N (Год)
[Краткое описание сезона]

*   **Серия N.1:** [Описание серии в один абзац: 50–60 слов]

*   **Серия N.2:** [Описание серии в один абзац: 50–60 слов]

**Финал сезона:** [Резюме финала сезона]
```

## 🚀 Как использовать
При получении запроса на составление карточки медиа, примените этот шаблон, соберите информацию по эпизодам (через веб-поиск) и сгенерируйте Markdown-файл с расширением `.md`.
