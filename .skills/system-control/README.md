# System Control Skill

This skill provides an interface to control the `system_control_center` application within the AI Breadboard ecosystem.

## Features
- Post-installation setup wizard profiles.
- Baseline snapshot capture and drift comparison.
- System maintenance tasks (DISM, SFC, cleanup).
- Windows security settings management (Defender, Firewall).

## Requirements
- `system_control_center` must be running (usually on port 8109).
- Administrator privileges required for system management tasks.
