# Навык: Assistant Manager

## 🎯 Назначение
Навык `assistant-manager` обеспечивает взаимодействие с приложением персонального помощника (`apps/user_assistant`). Позволяет ИИ управлять ежедневным расписанием, проверять почту, планировать встречи в Google Calendar и искать информацию в личных документах (RAG).

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на планирование, анализ почты или поиск информации в документах.
2. **Взаимодействие**: Навык использует API помощника (по умолчанию `http://localhost:8105/api/v1/assistant/*`).
3. **Безопасность**: Доступ к почте и календарю требует предварительной авторизации.

## 🛠️ Основные команды
- `get_agenda`: Получение списка задач и встреч на день.
- `search_mail`: Поиск и фильтрация входящей почты.
- `schedule_meeting`: Создание события в Google Calendar.
- `search_docs`: Поиск по локальным документам через RAG.

## ⚠️ Важное замечание
Навык требует настроенных учетных записей Google и доступа к API в конфигурации приложения.
