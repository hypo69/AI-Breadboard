# Навык: Trading Controller

## 🎯 Назначение
Навык `trading-controller` предназначен для взаимодействия с торговым терминалом (`apps/trading_terminal`). Он позволяет агентам ИИ запрашивать биржевые данные, отслеживать позиции, PnL и управлять ордерами через API торгового терминала.

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах, связанных с анализом биржевых данных, мониторингом позиций или исполнением ордеров.
2. **Взаимодействие**: Навык использует API конечных точек терминала (по умолчанию `http://localhost:8103/api/v1/trading/*`).
3. **Безопасность**: Все операции по управлению ордерами (исполнение, отмена) требуют предварительного подтверждения пользователя.

## 🛠️ Основные команды
- `get_market_data`: Получение котировок в реальном времени.
- `get_positions`: Получение списка открытых позиций и текущего PnL.
- `execute_order`: Создание нового торгового ордера (требует подтверждения).
- `kill_switch`: Экстренная отмена всех активных ордеров.

## ⚠️ Важное замечание
Навык предназначен для использования внутри контролируемой среды AI Breadboard. Убедитесь, что `trading_terminal` запущен перед использованием навыка.
