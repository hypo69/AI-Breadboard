# IFTTT Smart Home Controller Skill

This skill integrates AI Breadboard with the IFTTT Webhook Maker service to control smart home devices, IoT hardware, and custom automation applets.

## Features
- Controls lights, climate, robot vacuums, and power outlets.
- Dispatches notifications, SMS, or Telegram alerts through IFTTT.
- Receives inbound sensor events (motion, doors, temperature) via `/api/ifttt/webhook/{event_name}`.
