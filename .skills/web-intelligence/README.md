# Web Intelligence Skill

This skill provides an interface to control the `website_monitor` application within the AI Breadboard ecosystem.

## Features
- Real-time GA4 traffic analysis.
- GSC SEO metrics monitoring.
- Technical availability and latency probing.
- AI-driven root-cause diagnostics.

## Requirements
- `website_monitor` must be running (usually on port 8107).
- Valid Google API credentials (GA4, GSC).
