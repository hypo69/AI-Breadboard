# 📚 Практический учебник: Интерактивная макетная плата ИИ (AI Breadboard)

## 📋 О курсе и учебнике
Данный раздел представляет собой интерактивное пошаговое руководство для начинающих разработчиков и энтузиастов, изучающих и сравнивающих различные модели искусственного интеллекта.

Вместо сложного оверинжиниринга и непрозрачных контейнеров мы используем концепцию **«Макетной платы» (Breadboard)**:
- Мы не «припаиваем» одну модель намертво к проекту.
- Мы создаем единую шину коммутации, куда можно подключать любые чипы (Gemini, Foundry, Ollama, OpenAI, DeepSeek, Groq, локальный ONNX) и переключать их «на лету» прямо через API.

## 💡 Принципы обучения
1. **Прозрачность и наглядность:** Запуск на локальном хосте (PowerShell-скрипты + Python virtualenv).
2. **Единый контракт:** Все модели работают через одинаковые методы `.chat()`, `.ask()`, `.stream_chat()`.
3. **Практика на первом месте:** Каждая глава содержит реальный запускаемый код и лабораторные упражнения.
