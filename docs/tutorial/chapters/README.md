# 📖 Главы учебника aibreadboard

Каталог содержит последовательные модули (главы) практического руководства по исследованию, интеграции и коммутации моделей ИИ.

## Структура глав:
- `01_concept_and_breadboard.md` — Макетная плата ИИ и универсальная коммутация моделей.
- `02_native_host_vs_docker.md` — Философия No-Docker: прозрачность локального хостинга.
- `03_connecting_models.md` — Практикум: подключение провайдеров (Gemini, Foundry, Ollama, OpenAI).
- `04_prompts_over_code.md` — Управление поведением моделей через машинные инструкции.
- `05_hands_on_comparison.md` — Лабораторная: сравнение моделей на одном промпте.
