# Модуль `scripts/dev` — Инструменты разработки и тестирования

## Назначение
Набор служебных утилит для разработчиков проекта:
- `run_tests.py`: запуск тестового набора Pytest с формированием отчетов.
- `generate_coverage_report.py`: построение детального отчета о покрытии кода тестами.
- `analyze_dependencies.py`: проверка и аудит зависимостей проекта.
- `search_code.py`: консольный поиск по кодовой базе и техническому RAG.
- `update_docs.py`, `update_scripts_documentation.py`: автоматическое обновление проектной документации.
- `scan_headers.py`: проверка соответствия заголовков файлов стандартам `hypo69`.
- `bot_runner.py`: автономный запуск Telegram-бота для тестирования.\n
