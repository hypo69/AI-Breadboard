# Модуль `scripts` — Служебные утилиты разработчика

## Назначение
В директории `scripts` собраны **общесистемные инструменты разработчика и сопровождения**:
- `dev/`: инструменты разработки, запуск тестов, анализ зависимостей, генерация документации.
- `maintenance/`: регламентные задачи сопровождения системы, сжатие и анализ логов.

> [!NOTE]
> Доменная бизнес-логика (медиатека, торренты, RAG) инкапсулирована в соответствующих плагинах директории `plugins/`.\n
