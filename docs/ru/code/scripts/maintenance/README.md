# Модуль `scripts/maintenance` — Системное обслуживание

## Назначение
Утилиты для регламентного технического обслуживания системы:
- `analyze_logs.py`: анализ файлов журналов на наличие критических ошибок и предупреждений.
- `compress_logs.py`: архивация и ротация устаревших логов для экономии дискового пространства.
- `rebuild_dev_rag.py`: перестроение технического RAG-индекса кода для ассистента разработчика.\n
