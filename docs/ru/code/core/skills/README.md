# Универсальные навыки

Каталог `core/skills` предоставляет единый реестр навыков для разных моделей и агентов.

## Принцип работы

`SkillRegistry` ищет каталоги навыков в `.gemini/skills`, `.agents/skills`, `.github/skills` и `skills`. Каждый навык должен содержать `SKILL.md` с YAML frontmatter. Необязательный `skill.json` задаёт машинный контракт: провайдеры, capabilities, параметры и другие поля.

Реестр только читает описания и инструкции. Выполнение скриптов навыка остаётся отдельной явно запрошенной операцией, поэтому подключение нового агента не получает скрытый доступ к командам.

## Файлы

- `registry.py` — модель `SkillDefinition`, обнаружение, поиск и JSON-экспорт.
- `__init__.py` — публичный API пакета.
