# Модуль `core.clients` — Внешние API-клиенты

## Назначение
Модуль содержит специализированные клиенты для взаимодействия с внешними API и сервисами:
- `foundry.py`: HTTP-клиент для взаимодействия с сервисами Microsoft AI Foundry.
- `ollama.py`: клиент для отправки запросов к локальному экземпляру Ollama.
- `tg_tts_handler.py`: обработчик голосовых сообщений и синтеза речи для Telegram-интерфейса.\n
