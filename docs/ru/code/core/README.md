# Модуль `core` — Ядро системы (Core Layer)

## Назначение
Директория `core` содержит ключевые сервисные компоненты бэкенда приложения `ai-assistant`:
- Маршрутизация FastAPI и WebSocket (`core.fastapi`)
- Интеграция с моделями искусственного интеллекта (`core.ai`)
- Внешние сервисные клиенты (`core.clients`)
- Подсистема логирования (`core.logger`)
- Управление секретами и API-ключами (`core.secrets`)
- Движки синтеза речи TTS (`core.tts`)
- Управление профилями пользователей (`core.user_manager`)
- Набор вспомогательных утилит и конверторов (`core.utils`)
