# Модуль `core.utils` — Вспомогательные утилиты

## Назначение
Коллекция переиспользуемых модулей и конверторов данных:
- `convertors/`: преобразование форматов (json, dict, html, markdown, xls, csv, base64 и др.).
- `file.py`: безопасное чтение, запись и обход файловой системы.
- `jjson.py`: сериализация и парсинг JSON с поддержкой `SimpleNamespace`.
- `date_time.py`: форматирование и расчет временных меток.
- `get_free_port.py`: динамический поиск свободных сетевых портов.
- `image.py`, `video.py`, `pdf.py`: обработка медиа и документов.
- `versioning.py`: разбор SemVer-строк, сравнение версий и выбор наилучшего тега из списка.
