# Конвертеры данных (core/utils/convertors)

## Описание
Директория содержит набор утилит для преобразования данных между различными форматами (JSON, XML, CSV, MD, dict, SimpleNamespace и др.).

## Обзор файлов
* `dict.py` — Утилиты для манипуляции словарями, включая преобразование в SimpleNamespace.
* `json.py` — Утилиты для работы с JSON.
* `csv.py` — Утилиты для работы с CSV.
* `md.py` — Конвертация данных в Markdown.
* ... и другие специфические конвертеры.

## Связи и зависимости
* Модули используются повсеместно в проекте для нормализации данных перед передачей в модели AI или записью в БД.
* Зависят от стандартных библиотек Python (`json`, `xml`, `types`) и сторонних (`pandas`, `json_repair`).
