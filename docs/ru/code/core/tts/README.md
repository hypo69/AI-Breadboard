# Модуль `core.tts` — Движки синтеза речи (Text-to-Speech)

## Назначение
Пакет предоставляет унифицированный доступ к различным движкам синтеза речи:
- `edge.py`: Microsoft Edge TTS (облачный качественный синтез).
- `gtts.py`: Google Translate TTS.
- `silero.py`: локальный нейросетевой движок Silero TTS для офлайн-синтеза.\n
