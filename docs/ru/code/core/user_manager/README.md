# Модуль `core.user_manager` — Управление пользователями

## Назначение
Модуль обеспечивает управление пользователями, хранение профилей и историю активности:
- `user_profile.py`: модели данных пользователя и пользовательских настроек.
- `__init__.py`: класс `UserManager`, выполняющий операции CRUD с базой данных `users.db`.
- `users.db`: локальная SQLite база данных пользователей.\n
