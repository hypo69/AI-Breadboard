# Единый источник инструкций ИИ

Этот каталог — единственное место хранения общих инструкций, правил, планов и знаний проекта. Каталоги конкретных помощников (`.amazonq`, `.kiro`, `.gemini`, `.chatgpt`) не дублируют их: в них остаются только указатели и служебные файлы самого инструмента.

## Состав

- `rules/CODE_RULES.md` — обязательный инженерный стандарт.
- `knowledge/media_organizer_workflow.md` — процесс работы Media Organizer и схема данных.
- `knowledge/torrent_and_media_principles.md` — процессы сопоставления медиа и торрентов.
- `knowledge/scripts_tools.md` — справочник консольных скриптов проекта и параметров их запуска.
- `knowledge/legacy_project_knowledge.md` — историческая карта архитектуры; перед применением её сведений нужно сверяться с кодом.
- `knowledge/codex/` — рабочая база знаний, собранная при обследовании проекта.
- `prompts/` — системные инструкции, которые исполняемый код передаёт моделям.
- `plans/roadmap.md` — актуальная очередь требований проекта.
- `plans/legacy_amazonq_plan.md` — исторический план завершённых задач.

## Правило использования

Все новые общие инструкции добавляются только сюда. Указатели в каталогах моделей обновляются ссылками на конкретные файлы из этого каталога; копии создавать нельзя.

Служебные конфигурации и автоматизации конкретного инструмента не являются общими инструкциями. Например, `.kiro/hooks/` сохраняется в `.kiro`; каталог `.kiro/spec/` намеренно не используется.
