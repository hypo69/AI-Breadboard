# tools/ — Служебные инструменты проекта

Директория содержит **служебные скрипты** для внутреннего использования: агентами ИИ и разработчиками.

> **Лончеры (`Run-*.ps1`) находятся в корне проекта, НЕ здесь.**  
> Основной CLI для агентов: `py manage_tools.py <группа> <команда>`  
> Полная документация лончеров: `.ai_instructions/knowledge/LAUNCHER_GUIDE.md`

---

## Структура

| Директория | Назначение |
|------------|------------ |
| [`ai/`](./ai/README.md) | Скрипты для агентов ИИ: RAG-индексы, поиск по коду, документация |
| [`setup/`](./setup/README.md) | Инструменты настройки кодовой базы (анализ зависимостей, заголовки) |

---

## Правила добавления нового инструмента

1. **Определи категорию**: `ai/` или `setup/`
2. **Помести файл** в соответствующую поддиректорию
3. **Обнови README.md** своей категории
4. **Никогда не создавай лончеры здесь** — все `Run-*.ps1` идут в корень проекта

---

## Для агентов ИИ

```powershell
# Активация окружения (обязательно)
.\.venv\Scripts\Activate.ps1

# Пересборка RAG-индекса кода
py tools/ai/rebuild_dev_rag.py

# Поиск по кодовой базе
py tools/ai/search_code.py --query "MediaDatabase"

# Обновление документации
py tools/ai/update_docs.py
```
