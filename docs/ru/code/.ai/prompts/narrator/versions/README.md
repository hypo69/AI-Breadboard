# prompts/narrator/versions/

Папка для хранения истории версий системной инструкции **Narrator** модели.

## Структура файлов

- Активная инструкция: `../narrator_style.md`
- Версии: `vN_YYYY-MM-DD.md` (N — порядковый номер, дата — дата сохранения)

## Как работает версионирование

1. При нажатии "Сохранить версию" в редакторе (режим Narrator) → создаётся файл `vN_DATE.md` здесь
2. Активная копия `narrator_style.md` перезаписывается
3. При активации версии через редактор → содержимое выбранного файла копируется в активный

## Правило именования

```
v1_2026-08-07.md
v2_2026-08-08.md
...
```
