# Модуль «Плагины и расширения» (Plugins Tab)

## 📋 Описание
Директория `webinterface/plugins_tab/` содержит интерфейс подключения, каталогизации и динамической настройки плагинов платформы Mediteka.

## ⚙️ Принцип работы
1. **Каталог плагинов:** Запрашивает реестр зарегистрированных плагинов через эндпоинт `/api/admin/plugins`.
2. **Динамические органы настройки:**
   - Для каждого выбранного плагина отображает его метаданные (название, иконку, версию, категорию).
   - Генерирует интерактивные поля формы настроек на основе манифеста плагина (`fields`).
   - Предоставляет кнопки запуска целевых действий (`actions`), таких как сканирование, аудит, пересборка индексов или тестирование соединения.
3. **Управление состоянием:**
   - Быстрый переключатель активности плагина (Вкл / Выкл) с сохранением состояния в `config.json`.
   - Вывод результатов выполнения действий плагина в интерактивный терминал/консоль логов.
