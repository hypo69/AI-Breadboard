# Модуль `webinterface/users_tab` — Управление пользователями

## Назначение
Вкладка панели администратора для управления учетными записями пользователей, ролями, правами доступа, статусом активности и паролями.

## Функциональные возможности
- **Сводная статистика:** отображение общего числа пользователей, активных аккаунтов, администраторов и пользователей с привязкой к Telegram.
- **Поиск и фильтрация:** мгновенный поиск по имени, email и логину Telegram, фильтрация по ролям (`admin`, `user`, `guest`) и статусам (активен/заблокирован).
- **Управление учетными записями (CRUD):**
  - Создание нового пользователя с возможностью сразу задать пароль, роль и статус.
  - Редактирование имени, email, роли (`admin`, `user`, `guest`), флага администратора и подтверждения почты.
  - Быстрое переключение активности (блокировка / разблокировка учетной записи).
  - Смена / сброс пароля со встроенным генератором безопасных паролей.
  - Просмотр подробных настроек профиля (тема, язык, TTS-голос, кастомные системные инструкции, Telegram ID).
  - Безопасное удаление пользователя с защитой от удаления системного администратора (ID 1).

## Архитектура и взаимодействие
- Разметка находится в `index.html`.
- Логика клиента реализована в `main.js` и регистрируется глобально через `window.initUsersTab()`.
- Взаимодействие с бэкендом происходит через REST API `/api/admin/users/*` (`src/fastapi/router_admin.py`).
