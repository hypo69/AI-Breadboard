# Web Interface — ai-assistant

Директория с веб-интерфейсом для взаимодействия с AI-ассистентом, управления системой, дисками и расширениями.

## Структура

```
webinterface/
├── index.html       # Главный веб-интерфейс
├── admin/           # Административный интерфейс
├── admin_tab/       # Центральное управление системой и дисками
├── plugins_tab/     # Подключатель плагинов и модулей
├── chat/            # Веб-чат с AI
├── users_tab/       # Управление пользователями
├── models_tab/      # Модели и API-ключи
├── agents_tab/      # ReAct-агенты ИИ
├── search_tab/      # Настройки веб-поиска
├── tts_tab/         # Настройки синтеза речи (TTS)
├── logs/            # Просмотр системных логов
├── instructions_tab/# Системные инструкции и промпты
├── help/            # Справочная система
├── js/              # Общие JS модули (i18n, chatService, theme)
└── locales/         # Файлы локализации
```

## Пользовательский интерфейс (`/user`)

Минималистичный интерфейс для повседневного использования. Основан на Telegram Mini App.

### Вкладка "Плеер"

**Просмотр и воспроизведение медиафайлов:**

- ✅ Список всех медиафайлов (фильмы, сериалы) из базы данных
- ✅ Видеоплеер с управлением воспроизведением
- ✅ Кнопки "Предыдущий" / "Следующий" для навигации
- ✅ Автоматическое воспроизведение следующего файла при завершении текущего

**Технологии:**
- HTML5 Video элемент
- REST API для получения списка файлов и стриминга

### Вкладка "Чат"

**Общение с AI через Gemini:**

- ✅ Чат с Gemini AI для вопросов о медиатеке
- ✅ Распознавание тегов `<film>название</film>` в ответах бота
- ✅ Автоматический поиск фильма по названию и открытие в плеере
- ✅ История сообщений с сохранением контекста

**Примеры запросов:**
- "Покажи боевики с Кeanu Reeves"
- "Какие фильмы в жанре триллер?"
- "Найди сериалы 2024 года"

## Админский интерфейс (`/admin`)

Полнофункциональный интерфейс для администрирования системы.

### Вкладка "Чат"

**Управление AI чатом:**

- Отправка сообщений Gemini API
- Обработка тегов `<film>` с автоматическим открытием плеера
- Отображение времени отправки сообщений

### Вкладка "Торренты"

**Управление торрентами через qBittorrent:**

**Утерянные файлы:**
- Показ всех торрентов с отсутствующими файлами
- Кнопка обновления списка
- Автопоиск файлов на указанных путях

**Автопоиск:**
- Список сохранённых путей для поиска
- Добавление новых путей
- Пакетное перемещение утерянных файлов
- Recheck после перемещения

**Ручное управление:**
- Выбор торрента из списка
- Указание нового пути к файлам
- Установка пути + Recheck

**Просмотр всех торрентов:**
- Таблица со всеми торрентами
- Фильтрация: Утерянные / Все
- Статус, прогресс, размер

### Вкладка "Медиатека"

**Сканирование и управление медиа:**

**Пути сканирования:**
- Добавление/удаление путей к медиафайлам
- Список сканируемых дисков и директорий

**Сводка по сериалам:**
- Таблица всех сериалов
- Сезоны, эпизоды, размер
- Кнопка обновления данных

**Дубликаты сезонов:**
- Поиск дубликатов в базе данных
- Статистика по найденным дубликатам

**Целостность:**
- Проверка наличия файлов на диске
- Статистика по потерянным/неполным файлам

**RAG Индекс:**
- Статистика: записи в БД, документы в индексе, фильмы, сериалы
- Поиск по RAG-индексу (семантический поиск)
- Фильтрация по категории и типу
- Построение/перестройка индекса

**Отчёты:**
- Генерация отчёта о медиатеке
- Скачивание Markdown отчёта

### Вкладка "Управление"

**Полное администрирование медиатеки:**

**Сканирование:**
- Выбор диска и путей
- Полное сканирование с классификацией через Gemini
- Автоматическое переименование файлов
- Аудит базы данных
- Генерация отчётов о дубликатах и проблемах

**Аудит БД:**
- Сверка таблицы media с файлами на диске
- Обнаружение отсутствующих сезонов
- Проверка количества серий
- Идентификация неполных файлов и метаданных

**Восстановление:**
- Восстановление БД из JSON (после экспортов)
- Консолидация дублей в БД

**RAG:**
- Статус индекса и базы данных
- Поиск по RAG через естественные запросы
- Построение нового индекса

## Загрузка торрентов

Пользовательский интерфейс поддерживает автоматическую загрузку торрентов:

### Как это работает

1. **Отправка ссылки в чат**: Пользователь отправляет magnet-ссылку или URL на .torrent файл в чат с AI
2. **Определение типа**: Система анализирует название и определяет - сериал это или фильм
3. **Создание папки**: Файл загружается в:
   - `01 serials/` — для сериалов
   - `02 films/` — для фильмов
4. **Назначение категории**: В qBittorrent устанавливается категория (serials/films)
5. **Автовоспроизведение**: После завершения загрузки плеер автоматически открывается и начинает воспроизведение

### API Эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/torrents/add` | Добавить торрент на загрузку |
| GET | `/api/torrents/status/{hash}` | Получить статус загрузки |
| POST | `/api/torrents/assign-categories` | Назначить категории на основе БД |

### Определение типа контента

Сериал определяется по паттернам:
- `S01E01`, `S01E02` — сезон/эпизод
- `1x01` — альтернативный формат
- `Season 1`, `Сезон 1`
- `эпизод 5`, `Серия 5`

### Настройки

- Поле ввода директории загрузки в плеере
- Сохранение выбранной директории в localStorage
