# Модуль `webinterface/models_tab` — Вкладка управления моделями и API

## Назначение
Модуль предоставляет полнофункциональный пользовательский веб-интерфейс для настройки нейросетевых провайдеров, выбора активных моделей, управления системными инструкциями и интерактивного тестирования моделей ("Запрос &rarr; Ответ") в панели управления.

## Основные возможности
1. **Выбор активной модели и провайдера:**
   - Выбор провайдера ИИ (Google Gemini, Google Antigravity, Microsoft Foundry, Ollama, Gemini CLI).
   - Динамическая фильтрация и выбор модели по умолчанию для ассистента.
   - Кнопка принудительного обновления доступных моделей с сервера (`/api/chat/models?refresh=true`).

2. **Интерактивный проверочный запрос (Тест связи):**
   - Поле ввода проверочного сообщения с возможностью быстрого тестирования выбранной связки (провайдер + модель).
   - Отправка запроса к эндпоинту `POST /api/chat/test-model`.
   - Индикация статуса HTTP, замер времени генерации (мс) и вывод ответа модели или детального описания ошибки.

3. **Системные инструкции:**
   - Редактирование глобальной системной инструкции ассистента с сохранением в реальном времени.

4. **Настройки провайдеров:**
   - **Google Gemini:** Управление пулом API-ключей, ротация Round-Robin, сброс квот и лимитов.
   - **Google Antigravity (AGY):** Активация провайдера, выбор модели через SDK, настройка персонального API-ключа.
   - **Microsoft Foundry:** Настройка локального URL и ключа доступа.
   - **Ollama:** Настройка подключения к локальному серверу Ollama.

## Архитектура файлов
- `index.html` — Разметка интерфейса вкладки на Bootstrap 5 с темной темой для активных карточек.
- `main.js` — Клиентская логика инициализации, валидации форм, отправки проверочных запросов и асинхронного обновления данных.
