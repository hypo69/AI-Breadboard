# Вкладка управления и создания ИИ-Агентов (`webinterface/agents_tab/`)

## Назначение
Данная директория содержит модуль панели управления для конструирования и тестирования **ИИ-Агентов** платформы AI Breadboard.

## Возможности
1. **Каталог агентов (Agent Registry)**:
   - Отображение системных (`Gemini Grounding`, `Gemini CLI Searcher`, `AGY Searcher`, `Playwright Agent`, `Breadboard Agent`) и пользовательских агентов.
   - Быстрое включение/выключение агентов тумблером в один клик.
   - Фильтрация по статусу (Все, Активные, Системные, Пользовательские).

2. **AI-Конструктор агентов (AI Agent Builder)**:
   - Автоматическая генерация роли, системного промпта, формата ответов и рекомендаций по инструментам через выбранную модель из пула (`Google Gemini SDK`, `Google Gemini CLI`, `Google Antigravity / AGY`, `Microsoft Foundry`, `Ollama`).

3. **Редактор агентов (Agent Editor)**:
   - Настройка параметров: название, ID, модель из пула, температура, таймаут, лимит шагов ReAct (`max_steps`).
   - Матрица чекбоксов подключения инструментов (интернет-поиск, RAG, Python-вычисления, файловые операции, TTS).
   - Вставка готовых шаблонов системных инструкций (ReAct loop, структурированный формат).

4. **Интерактивная песочница (Agent Sandbox)**:
   - Тестирование выполнения агента в реальном времени с логированием цепочки рассуждений (`Thought -> Tool Init -> Action -> Finish`) и замером времени ответа в миллисекундах.

5. **Визуальная архитектура**:
   - Встроенная интерактивная векторная схема [`webinterface/assets/agents_architecture.svg`](../assets/agents_architecture.svg).

## Структура файлов
- `index.html` — верстка вкладки, модальных окон AI Builder, Редактора и Песочницы.
- `main.js` — клиентская логика взаимодействия с REST API `/api/agents`.
- `README.md` — документация модуля на русском языке.
