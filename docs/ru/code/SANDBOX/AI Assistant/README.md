# AI Assistant

## Описание

Каталог для самостоятельных прототипов пользовательских интерфейсов AI Assistant.

## Обзор файлов и модулей

* `Simple Assistant/` — лаконичный веб-интерфейс чата с моделью.

## Связи и зависимости

* Интерфейсы каталога работают поверх FastAPI-приложения проекта.
* Конкретные прототипы не изменяют основные вкладки `webinterface`.
