# Simple Assistant

## Описание

Лаконичный интерфейс для общения с моделью через потоковый FastAPI API проекта.

## Обзор файлов и модулей

* `index.html` — структура страницы чата и доступные пользовательские действия.
* `style.css` — адаптивное оформление светлой поверхности чата.
* `main.js` — отправка сообщений, чтение SSE и управление историей диалога.

## Связи и зависимости

* Страница обслуживается FastAPI по адресу `/simple-assistant/`.
* Сообщения отправляются в существующий endpoint `POST /api/chat`.
* Конфигурация модели и параметры разработчика намеренно отсутствуют в интерфейсе.
