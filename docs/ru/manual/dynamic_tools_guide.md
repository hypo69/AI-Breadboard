# 🪟 Руководство пользователя: Умные динамические инструменты и чат Test Computer (/tc)

Данное руководство описывает работу с интеллектуальной подсистемой динамических инструментов, автономного агентского цикла (**Function Calling / Tool Use**) и веб-интерфейса сценариев **Test Computer (/tc)** в AI Breadboard.

---

## 🌟 Возможности и ключевые особенности

1. **Автономное выполнение запросов (Native Function Calling)**:
   - Модели не требуются жесткие эвристики или ключевые слова.
   - LLM самостоятельно анализирует семантику запроса и выбирает нужный инструмент из реестра ToolRegistry.

2. **Саморасширяемые инструменты (Self-Extending Dynamic Tools)**:
   - Если нужного инструмента нет в системе, модель использует мета-инструмент create_custom_tool.
   - Модель на лету генерирует безопасный PowerShell/WinAPI зонд, регистрирует его в рантайме, выполняет опрос хоста и автоматически сохраняет созданный навык в каталог .skills/ для последующего переиспользования.

3. **Прозрачность и контроль промптов**:
   - В чате /tc в реальном времени отображаются этапы рассуждения (ReAct), выполненные команды и **точный сформированный системный промпт**, отправленный языковой модели.

4. **Безопасность SafeOps**:
   - Все запросы выполняются строго в режиме Read-Only. Деструктивные команды (удаление системных файлов, форматирование, остановка критических служб) блокируются на уровне фильтра безопасности.
   - При обнаружении проблем пользователю предлагаются интерактивные кнопки SafeOps-исправлений.

## 🚀 Начало работы

### 1. Запуск сценария Test Computer

Для запуска платформы в режиме Test Computer выполните команду в терминале PowerShell:

`powershell
.\tc.ps1
`

Или запустите единый сервер:

`powershell
.\run.ps1
`

После запуска перейдите в браузере по адресу:
👉 http://localhost:8000/tc

## 💬 Работа с чатом и сценариями

В поле ввода чата /tc вы можете задавать произвольные вопросы о состоянии компьютера на естественном русском языке.

### Примеры запросов:

- **История оборудования и периферия:**
  - *«Какие мыши были подключены к этому компьютеру?»*
  - *«Покажи все устройства, которые использовали шину USB»*
  - *«Какие мониторы и видеокарты сейчас подключены?»*
  - *«Проверь звуковые устройства и микрофоны»*

- **Сетевой стек и сервисы:**
  - *«Какие порты открыты и прослушиваются?»*
  - *«Покажи список служб Windows, которые отключены»*
  - *«Проверь активные сетевые адаптеры»*

- **Программное обеспечение и фоновые запуски:**
  - *«Какие программы давно не запускались (UserAssist/Prefetch)?»*
  - *«Найди программы без указания издателя»*

## 🔍 Инспекция процесса и этапы выполнения (SSE)

Во время обработки запроса в реальном времени отображаются карточки этапов:

1. 🔌 **Инициализация подсистем** — подключение к WinAPI/WMI и коллекторам.
2. 🧠 **Семантический анализ & ReAct** — подбор существующего инструмента или генерация нового через create_custom_tool.
3. 📋 **План инструмента** — вывод сгенерированного имени, типа зонда и описания.
4. ⚡ **Исполнение зонда** — безопасный опрос хоста Windows.
5. 📡 **Сбор метрик** — структурирование полученных сырых данных.
6. ✍️ **Синтез отчета & Инспекция промпта** — передача контекста в модель и потоковый вывод структурированного Markdown-ответа.

> [!TIP]
> **Просмотр отправленного промпта:** Нажмите на блок *«Сформированный промпт»* в карточке ответа, чтобы увидеть точный контекст и системные инструкции, переданные в нейросеть.

## 🛠️ Архитектура подсистемы инструментов

| Компонент | Расположение | Назначение |
|---|---|---|
| **Реестр инструментов** | pps/windows/core/tools/registry.py | ToolRegistry — хранение, регистрация и OpenAPI-схемы |
| **Базовый класс** | pps/windows/core/tools/base.py | BaseTool & ToolExecutionResult — типизация и контракты |
| **Системные инструменты** | pps/windows/core/tools/system_tools.py | WindowsCollectorTool (15 коллекторов) и SafePowerShellProbeTool |
| **Фабрика динамических инструментов** | pps/windows/core/tools/dynamic_factory.py | CreateCustomToolMetaTool и сохранение в .skills/ |
| **Агентский цикл ReAct** | pps/windows/core/agent_loop.py | WindowsAgentLoop — логика рассуждений и синтез промптов |
| **Оркестратор** | pps/windows/core/dynamic_tool_engine.py | DynamicWindowsToolEngine — фасад для API и WebGUI |

## ⚙️ Безопасность и подтверждение действий (SafeOps)

Если анализ выявил проблему (например, неиспользуемая служба или отключенный аудит), в конце ответа появится карточка действия SafeOps с возможностью безопасного применения с подтверждением пользователя.
