# Руководство по созданию и управлению навыками агентов (Agent Skills)

## Введение

Платформа **AI Breadboard** поддерживает экосистему модульных переиспользуемых навыков для AI-агентов (совместимых с **Gemini CLI** и **Antigravity**). Навыки позволяют расширять возможности агентов специализированными инструкциями, исполняемыми скриптами автоматизации и базами знаний.

Интерфейс управления навыками доступен на вкладке **«⚡ Навыки (Agent Skills)»** веб-интерфейса.

---

## 🚀 Режимы создания навыков

При нажатии на кнопку **«+ Новый навык»** открывается **Мастер создания навыков (Skill Wizard)**, предоставляющий три удобных способа создания:

### 1. 🧙‍♂️ Пошаговый мастер (Step-by-Step Wizard)

Пошаговый мастер разбивает процесс создания на 4 логических этапа:

#### Шаг 1: Основная информация
- **Идентификатор навыка (kebab-case)**: системное имя навыка (латинские буквы, цифры, дефисы).
- **Кнопка автогенерации (🪄)**: автоматически генерирует корректный kebab-case идентификатор на основе введенного описания.
- **Целевой каталог**:
  - .agents/skills — Проектный навык AI Breadboard (рекомендуется).
  - ~/.gemini/skills — Пользовательский глобальный навык для Gemini CLI и Antigravity.
  - ~/.agents/skills — Глобальный пользовательский навык агентов.
  - skills — Локальный каталог.
- **Категория**: выбор категории (Инструменты, API, Анализ данных, Эксперт/Персона, Мониторинг, Генератор отчетов).
- **Описания**:
  - *На русском* — понятное описание для пользователя в интерфейсе.
  - *English Description* — краткое описание на английском языке, используемое агентом для маршрутизации и выбора навыка.

#### Шаг 2: Структура и логика инструкций (SKILL.md)
- **🎯 Цель (Purpose)**: главная цель работы навыка.
- **🚀 Условия запуска (Triggers)**: когда и при каких запросах агент активирует навык.
- **📋 Протокол действий (Execution Protocol)**: пошаговый алгоритм действий агента.
- **⚙️ Правила и ограничения (Rules & Constraints)**: требования к обработке ошибок и форматированию.
- **Кнопка «Заполнить стандартным шаблоном»**: мгновенно заполняет поля типовой структурой.
- **Живой редактор Markdown**: изменения в полях автоматически формируют итоговое тело SKILL.md.

#### Шаг 3: Скрипты, справочники и документация
- **Исполняемый Python-скрипт (scripts/main.py)**: добавление скрипта с автоматической генерацией точки входа main().
- **Справочный документ (
eferences/guide.md)**: добавление файла справочника и спецификаций.
- **Документация README.md**: англоязычное руководство для разработчиков пакета.

#### Шаг 4: Финализация и предпросмотр
- Отображение карточки параметров и бейджей подключенных компонентов (scripts/, 
eferences/).
- Полный Live Preview сгенерированного SKILL.md с YAML frontmatter (
ame, description, description_i18n).
- Кнопка **«🚀 Создать навык»** для сохранения.

### 2. 🤖 AI-Ассистент создания навыков (Natural Language to Skill)

Позволяет создать полный навык, просто описав задачу на естественном языке:

1. Перейдите на вкладку **«🤖 AI-Ассистент генерации»**.
2. Введите описание задачи (например: *«Навык для автоматического анализа логов Nginx, выявления подозрительных IP-адресов и выгрузки отчета в формате CSV»*).
3. Выберите категорию и целевой каталог.
4. Нажмите **«⚡ Сгенерировать навык»**.
5. AI-модель автоматически сформирует:
   - Имя навыка и описания на двух языках (n, 
u).
   - Подробную структуру инструкций SKILL.md.
   - Документацию README.md.
   - Исполняемый код Python-скрипта в scripts/ и справочник в 
eferences/.
6. Выберите **«Настроить в мастере»** (для редактирования) или **«Создать сразу»**.

### 3. 📦 Библиотека готовых шаблонов (Presets)

Готовые шаблоны для типовых сценариев:
- 🛠️ **CLI & Python Tool** — инструмент автоматизации с Python-скриптом.
- 🌐 **REST API Connector** — интеграция со сторонними сервисами и API.
- 📊 **Data Analyzer & Parser** — разбор и агрегация данных (CSV, JSON, логи).
- 🎭 **AI Expert & Persona** — экспертная роль архитектора или ревьюера.
- 🔔 **Monitor & Notifier** — мониторинг сервисов и нотификация об инцидентах.
- 📄 **Report & Doc Generator** — генератор отчетов и проектной документации.

## 🧪 Интерактивная песочница для тестирования (Live Sandbox)

Для любого навыка доступна встроенная песочница:
1. Откройте карточку навыка и нажмите кнопку **«🧪 Тестировать в Sandbox»** (или перейдите на вкладку **«🧪 Тестирование (Sandbox)»** в деталях навыка).
2. Введите тестовый запрос к агенту (например: *«Выполни анализ предоставленного фрагмента логов»*).
3. Нажмите **«Запустить»**.
4. Система отправит запрос модели с контекстом инструкций навыка и отобразит вывод в консоли.

---

## 📦 Сборка и распространение (.skill архивы)

- На карточке навыка или в модальном окне нажмите кнопку **«Собрать .skill»**.
- Система упакует структуру директории в дистрибутивный zip-архив .skill в папку dist/.
- Архив готов для переноса между окружениями или публикации.

## 📁 Стандартная структура каталога навыка

`	ext
.agents/skills/<имя-навыка>/
├── SKILL.md          # Основные инструкции с YAML frontmatter
├── README.md         # Документация пакета (English)
├── scripts/          # Исполняемые утилиты (Python)
│   └── main.py
├── references/       # Справочники и спецификации
│   └── guide.md
├── assets/           # Статические файлы, шаблоны, схемы
└── dist/             # Собранные пакеты .skill
`
