# Руководство по управлению Google аккаунтами и Google Workspace

## Введение

AI Breadboard включает встроенную подсистему работы с сервисами **Google Workspace** (Gmail, Google Drive, Google Sheets, Google Docs). Для обеспечения надежной работы и распределения квот реализован **пул учетных записей Google** с поддержкой нескольких аккаунтов, безопасным хранением токенов и автоматической авторизацией по протоколу OAuth 2.0.

Управление аккаунтами доступно в веб-интерфейсе администратора: **меню «Администрирование» → «Google аккаунты»**.

---

## 🔐 Архитектура хранения учетных данных

В соответствии со стандартами безопасности проекта:
- Конфигурационные файлы клиентов (credentials.json) и токены доступа (	oken.json) хранятся в защищенной директории секретов src/secrets/google/.
- Логика управления состоянием и пулом учетных записей вынесена в модуль src/system/google_accounts_state.py.
- Папка секретов добавлена в .gitignore и никогда не попадает в публичный репозиторий.

## 🚀 Подключение нового Google аккаунта

### Шаг 1: Получение credentials.json в Google Cloud Console
1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (или выберите существующий) и включите необходимые API:
   - **Gmail API**
   - **Google Drive API**
   - **Google Sheets API**
   - **Google Docs API**
3. Настройте **OAuth consent screen** (Экран согласия OAuth) и добавьте тестовых пользователей.
4. В разделе **Credentials (Учетные данные)** создайте учетные данные типа **OAuth client ID** (Desktop application).
5. Скачайте JSON-файл учетных данных.

### Шаг 2: Добавление аккаунта в AI Breadboard
1. Откройте панель администратора: **меню «Администрирование» → «Google аккаунты»**.
2. В блоке добавления нового аккаунта укажите алиас (например: work-email или personal).
3. Загрузите скачанный файл credentials.json (или вставьте его содержимое в текстовое поле).
4. Нажмите **«Добавить аккаунт»**.

### Шаг 3: Авторизация OAuth 2.0
1. На карточке добавленного аккаунта нажмите кнопку **«Авторизовать»**.
2. В браузере откроется стандартное окно входа Google OAuth 2.0.
3. Предоставьте запрашиваемые разрешения.
4. После успешного подтверждения токен доступа автоматически сохранится в src/secrets/google/<account_name>/token.json, а статус аккаунта изменится на **«✅ Авторизован»**.

## ⚙️ Управление пулом аккаунтов

- **Выбор активного аккаунта**: выберите радио-кнопку нужного аккаунта в списке, чтобы сделать его активным по умолчанию для всех навыков агента.
- **Проверка статуса**: отображение времени действия токена и доступных разрешений (Scopes).
- **Обновление токена**: кнопка «Обновить токен» принудительно обновляет сессию через 
efresh_token.
- **Удаление аккаунта**: безопасное удаление учетной записи и ее токенов из системы.

## 🤖 Использование в навыках агентов

Навык **google-workspace** (.agents/skills/google-workspace) автоматически использует активный аккаунт из пула для:
- Чтения, поиска и отправки писем в **Gmail** (scripts/gmail_manager.py).
- Поиска, чтения и синхронизации файлов в **Google Drive** (scripts/gdrive_manager.py).
- Чтения и записи таблиц в **Google Sheets** (scripts/gsheets_manager.py).
- Чтения документов в **Google Docs** (scripts/gdocs_manager.py).
