# Документация AI-Breadboard

## Добро пожаловать

AI-Breadboard — это интерактивный стенд для прототипирования, тестирования и сравнения языковых моделей искусственного интеллекта. Проект предоставляет модульную архитектуру, универсальную систему навыков и интеграцию с множеством моделей ИИ (Gemini, OpenAI, Ollama и другие).
