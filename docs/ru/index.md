# Документация AI-Breadboard

## Добро пожаловать

**AI-Breadboard** — модульная платформа для исследования, прототипирования и сравнения языковых моделей искусственного интеллекта. Разные модели подключаются как сменные компоненты через единую шину `UnifiedChatModel` — без переписывания кода.

Полное описание назначения, возможностей и быстрый старт — в **[README.md](https://github.com/hypo69/AI-Breadboard#readme)** репозитория.
