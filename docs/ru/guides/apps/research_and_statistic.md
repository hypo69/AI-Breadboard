## 📋 Обзор

**Исследования и статистика** — приложение для проведения исследований данных и статистического анализа с элементами ИИ-диагностики.

Приложение позволяет:
- Выполнять базовый статистический анализ данных.
- Автоматически обнаруживать аномалии (выбросы, пропуски) с помощью ИИ.
- Формировать рекомендации на основе анализа.
- Генерировать корреляционные матрицы и визуализацию.
