## 📋 Обзор

**Системный инспектор** — это инструмент для глубокого анализа состояния хост-системы Windows. Он предоставляет информацию об аппаратном обеспечении, запущенных процессах, использовании ресурсов (CPU, RAM, GPU), сетевых соединениях и установленных сервисах.

Приложение предоставляет:
1. **Rich TUI** для быстрого просмотра ресурсов и процессов в терминале.
2. **REST API** для удаленного мониторинга состояния системы другими компонентами Breadboard.

---

## 🚀 Использование CLI

### Запуск интерактивного TUI
```powershell
python -m apps.system_inspector
```

---

## 🔌 Эндпоинты FastAPI REST

Базовый URL: `/api/v1/inspector`

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/v1/inspector/system` | Общая информация о системе (OS, CPU, Memory). |
| `GET` | `/api/v1/inspector/processes` | Список активных процессов с потреблением ресурсов. |
| `GET` | `/api/v1/inspector/gpu` | Информация о GPU и использовании видеопамяти. |
| `GET` | `/api/v1/inspector/network` | Состояние сетевых подключений. |
