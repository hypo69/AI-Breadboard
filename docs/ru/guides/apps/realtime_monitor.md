# Монитор реального времени (Realtime Monitor)

Инструмент для мониторинга различных системных метрик в реальном времени.

## Описание
Модуль для отображения динамически изменяющихся данных о системе.

## Команда запуска
```bash
python -m apps.dashboard
```

## Основные функции
- Визуализация метрик системы (CPU, RAM, Network).
- Отображение текущих алертов.
- Интерактивный дашборд.
