## 📋 Обзор

**Торговый терминал** — это автономное приложение для финансового контроля, предоставляющее мониторинг рыночных данных в реальном времени, визуализацию глубины биржевого стакана (Level 2), отслеживание позиций портфеля и прибыли/убытков (PnL), отправку ордеров и экстренное закрытие всех позиций (kill-switch).

Приложение работает в двух режимах:
1. **Интерактивный TUI** для консоли / Windows Terminal.
2. **FastAPI-микросервис**, монтируемый по пути `/api/v1/trading`, для веб-интерфейсов и внешних алгоритмических торговых ботов.

## 🚀 Использование CLI

### Запуск интерактивного TUI
```powershell
# Терминал для пары BTC/USDT
python -m apps.trading_terminal

# Пользовательская пара и интервал обновления
python -m apps.trading_terminal --symbol ETH/USDT --interval 0.25
```

### Справочник флагов CLI

| Флаг | Тип | По умолчанию | Описание |
|---|---|---|---|
| `--symbol` | `str` | `BTC/USDT` | Торговая пара для мониторинга и торговли. |
| `--interval` | `float` | `0.5` | Интервал обновления экрана в секундах. |
| `--balance` | `float` | `10000.0` | Начальный баланс счета в USD. |

## 🔌 Эндпоинты FastAPI REST и WebSocket

Базовый URL: `/api/v1/trading`

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/v1/trading/status` | Возвращает полное состояние деска (баланс, позиции, капитал, PnL, логи). |
| `GET` | `/api/v1/trading/ticker` | Возвращает последний рыночный тикер, bid, ask и объем за 24ч. |
| `GET` | `/api/v1/trading/orderbook` | Возвращает биржевой стакан L2 (`?depth=5`). |
| `GET` | `/api/v1/trading/orders` | Возвращает список недавно исполненных ордеров. |
| `POST` | `/api/v1/trading/order` | Размещение нового ордера BUY или SELL. |
| `POST` | `/api/v1/trading/kill-switch` | Экстренная ликвидация: закрытие всех открытых позиций по рынку. |
| `WS` | `/api/v1/trading/ws/stream` | WebSocket-поток для получения цен и обновлений состояния в реальном времени. |

### Пример запроса на создание ордера (`POST /api/v1/trading/order`)
```json
{
  "symbol": "BTC/USDT",
  "side": "BUY",
  "amount": 0.05,
  "order_type": "MARKET"
}
```
