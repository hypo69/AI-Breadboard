# Монитор памяти (Memory Monitor)

Инструмент для отслеживания использования оперативной памяти системой.

## Описание
Модуль для сбора и анализа данных об использовании RAM в реальном времени.

## Команда запуска
```bash
python -m apps.windows.telemetry
```

## Основные функции
- Отслеживание потребления памяти процессами.
- Выявление утечек памяти.
- Генерация отчетов о производительности.
