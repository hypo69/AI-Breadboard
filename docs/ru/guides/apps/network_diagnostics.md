# Сетевая диагностика (Network Diagnostics)

Инструмент для глубокого анализа сетевого трафика.

## Описание
Модуль для мониторинга сетевых соединений и анализа пакетов.

## Команда запуска
```bash
python -m apps.network_terminal
```

## Основные функции
- Перехват и анализ сетевых пакетов (live packet capture).
- Распределение протоколов.
- Обнаружение аномалий в сетевом трафике.
