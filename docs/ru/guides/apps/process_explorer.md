# Исследователь процессов (Process Explorer)

Инструмент для глубокого анализа активных процессов в системе Windows.

## Описание
Модуль для исследования и мониторинга процессов, включая проверку их поведения и ресурсов.

## Команда запуска
```bash
python -m apps.windows.process_intelligence
```

## Основные функции
- Список активных процессов.
- Анализ ресурсов (CPU, RAM, I/O).
- Корреляция процессов с системными событиями.
