# Network Terminal

Инструмент для глубокого анализа сетевого трафика и мониторинга пакетов.

---

## 🎯 Назначение

`network_terminal` предоставляет возможности для:
- Анализа сетевого трафика в реальном времени.
- Мониторинга пакетов с поддержкой фильтрации (Wireshark-совместимые фильтры).
- Статистического анализа трафика.
- Обнаружения сетевых аномалий.

---

## 🚀 Основные возможности

- Deep Packet Inspection (DPI).
- Интерактивный TUI для мониторинга потока пакетов.
- Генерация отчётов по статистике протоколов.
- REST API для интеграции с другими компонентами платформы.

---

## 💻 Запуск

### TUI-дашборд
```powershell
python -m apps.network_terminal --interface 1 --filter "tcp port 80"
```

### Сервер API
```powershell
python -m apps.network_terminal --mode server
```
