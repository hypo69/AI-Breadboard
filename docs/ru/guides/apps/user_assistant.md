# Персональный помощник (`apps/user_assistant`)

**Статус:** ✅ Активно  
**Язык:** Русский (документация) / Английский (код)  
**Автор:** hypo69  
**Пакет:** `apps.user_assistant`

---

## 📋 Обзор

**Персональный помощник** — рабочее пространство для управления продуктивностью:
- ✉️ **Почта:** Управление Gmail/IMAP.
- 📅 **Календарь:** Планирование Google Calendar.
- 📁 **Документы:** Работа с локальными файлами и RAG.

---

## 🏛️ Архитектура

- **Engine:** Оркестратор бизнес-логики.
- **Router:** FastAPI эндпоинты (`/api/v1/assistant/*`).
- **TUI:** Консольный дашборд.

---

## 🚀 Запуск

```powershell
python -m apps.user_assistant
```

---

## 🌐 API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/v1/assistant/agenda` | Обзор дня. |
| `GET` | `/api/v1/assistant/mail` | Почта. |
| `GET` | `/api/v1/assistant/calendar` | Календарь. |
| `GET` | `/api/v1/assistant/documents` | Документы. |
