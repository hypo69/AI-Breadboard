# 🎬 Вкладка «Сценарии» (Test Computer Scenarios & AI Skills Assistant)

## 📋 Обзор

Вкладка **«Сценарии»** — это стартовый интерфейс и центральный командный хаб для сценария **Test Computer** (`/tc` и `/apps`). Она предоставляет быстрый доступ к автоматизированным процедурам экспресс-диагностики, аудита системных логов, мониторинга аппаратных ресурсов и интерактивному AI-помощнику с поддержкой генерации новых навыков «на лету».

> [!TIP]
> Вкладка «Сценарии» расположена **на первой позиции** в навигационном меню `/tc` и рекомендуется к запуску сразу после установки или перезапуска хоста.

---

## 🚀 Основные возможности

### 1. ⚡ Быстрая проверка (Smoke Test)
* **Рекомендация:** Рекомендуется после установки или обновления.
* **Что проверяется:**
  - Среда исполнения Python 3.12+ и параметры операционной системы.
  - Наличие и корректность конфигурационных файлов (`config_tc.json`, `config.json`, `.env`).
  - Доступное дисковое пространство рабочей директории.
  - Экспресс-анализ свежих журналов логов на наличие критических ошибок (`ERROR` / `CRITICAL`).
  - Статус зарегистрированных микросервисов Test Computer.
* **Результат:** Сводный отчёт со статусами каждого шага (`OK` / `WARN` / `ERROR`), временем выполнения в миллисекундах и практическими рекомендациями.

### 2. 📜 Аудит и анализ логов
* **Что проверяется:**
  - Инвентаризация файлов в каталоге `/logs` (`info.log`, `errors.log`, `fastapi.log` и др.).
  - Глубокое сканирование последних сотен строк на ошибки и предупреждения с примерами проблемных записей.
  - Сбор событий из журнала событий Windows (*Application EventLog*).
* **Результат:** Интерактивный список ошибок, вывод контекста сбоев и кнопки быстрого перехода к встроенному Анализатору логов.

### 3. 🖥️ Диагностика системы и оборудования
* **Что проверяется:**
  - Нагрузка ядер процессора (CPU) и распределение оперативной памяти (RAM).
  - Выявление Top-5 ресурсоёмких фоновых процессов по потреблению CPU/памяти.
  - Температурные датчики и доступные GPU.

### 4. 🛡️ Аудит автозапуска и служб Windows
* **Что проверяется:**
  - Привилегии текущего процесса (Administrator / Elevated).
  - Записи реестра автозапуска Windows (`HKCU` и `HKLM` ветки `Run` / `RunOnce`).
  - Состояние критически важных системных служб.

### 5. 🌐 Проверка сетевой доступности и портов
* **Что проверяется:**
  - Локальный порт веб-сервера (8000).
  - Разрешение DNS и сетевой шлюз.
  - Доступность внешних AI API (Google Gemini, Cloudflare).

### 6. 🤖 Проверка статуса AI-провайдеров
* **Что проверяется:**
  - Конфигурация локальных и облачных провайдеров (AGY, Gemini, Ollama, Foundry).
  - Замер задержки отклика (Latency).

## 💬 Интеллектуальный Мини-чат и Конструктор навыков

В правой части интерфейса вкладки «Сценарии» встроен специализированный диалоговый ассистент Test Computer.

### Основные возможности мини-чата:
1. **Потоковый вывод в реальном времени (Streaming Chunks):**
   - Ответы генерируются и передаются в браузер по протоколу Server-Sent Events (SSE) в виде потока токенов/чанков.
   - Пользователь видит печать ответа в реальном времени с анимацией курсора и живым рендерингом Markdown.
2. **Многошаговый контекст сессии (Multi-turn Context):**
   - Диалог сохраняет контекст предыдущих реплик в рамках текущей сессии (`conversation_id`).
   - Можно уточнять и дополнять запросы (например: *«Покажи принтеры»* ➔ *«А теперь только сетевые»*).
   - Кнопка **«🔄 Новая сессия»** сбрасывает контекст и начинает новый диалог.
3. **Безопасное зондирование Windows (Fail-Fast Heuristics & WMI/PnP):**
   - Система анализирует запрос пользователя и выполняет безопасные команды PowerShell/WMI (принтеры, мониторы, звуковые устройства, мыши, USB, процессы, службы, логи и т.д.).
4. **Контролируемое сохранение навыков (Human-in-the-Loop):**
   - Автоматическое бесконтрольное создание навыков отключено по умолчанию.
   - После формирования ответа пользователю доступны интерактивные действия:
     - 💾 **«Ответ правильный, запомнить как навык»** — сохраняет проверенный навык в каталог `.skills/<tool-name>/SKILL.md` и `.agents/skills/`.
     - ✏️ **«Скорректировать»** — открывает форму для ручного редактирования названия, русскоязычного описания и команды перед сохранением.
   - Если включен чекбокс *«Авто-навык»*, навык регистрируется автоматически.

## 🔌 API Спецификация (`/api/v1/scenarios`)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/v1/scenarios` | Получение перечня доступных сценариев с метаданными |
| `POST` | `/api/v1/scenarios/run` | Запуск сценария (`quick_check`, `log_audit`, `system_inspector`, `windows_admin`, `network_test`, `ai_providers_check`, `all`) |
| `POST` | `/api/v1/scenarios/chat` | Интеллектуальный чат (синхронный ответ) |
| `POST` | `/api/v1/scenarios/chat/stream` | Потоковый мини-чат с передачей этапов и чанков в реальном времени (SSE) |
| `POST` | `/api/v1/scenarios/chat/clear` | Очистка истории и сброс контекста сессии диалога |
| `POST` | `/api/v1/scenarios/save-skill` | Явное сохранение подтвержденного пользователем или отредактированного навыка |

### Пример потокового запроса (SSE):
```bash
curl -N -X POST http://127.0.0.1:8000/api/v1/scenarios/chat/stream \
  -H "Content-Type: application/json" \
  -d '{"message": "Покажи подключенные принтеры", "conversation_id": "test-session-1"}'
```

### Пример сохранения подтвержденного навыка:
```bash
curl -X POST http://127.0.0.1:8000/api/v1/scenarios/save-skill \
  -H "Content-Type: application/json" \
  -d '{
    "tool_name": "printers-inspector",
    "tool_title": "Аудит и список принтеров",
    "description_ru": "Инспекция принтеров и очередей печати Windows",
    "probe_type": "powershell",
    "probe_script": "Get-CimInstance Win32_Printer | Select-Object Name, DriverName, PortName, Status, Default | ConvertTo-Json"
  }'
```
