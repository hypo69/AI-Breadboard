# Сводная диагностическая панель (Windows Diagnostic Dashboard)

## Назначение
Единый центр управления всеми специализированными инструментами мониторинга и низкоуровневой диагностики системы Windows.

## Структура
```
apps/dashboard/
├── __init__.py                # Пакет
├── __main__.py                # Точка входа для CLI
└── src/                       # Координация модулей
```

## Запуск
```powershell
# Запуск панели управления
python -m apps.dashboard
```

Доступные команды:
- `overview` — Сводка состояния системы
- `modules` — Список диагностических модулей
- `status` — Статус панели
- `processes`, `performance`, `network`, `services` — Запуск соответствующих инструментов
