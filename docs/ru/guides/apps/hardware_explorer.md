# Исследователь оборудования (Hardware Explorer)

Инструмент для диагностики и анализа аппаратного обеспечения хоста.

## Описание
Этот модуль предоставляет интерфейс для взаимодействия с системными датчиками и инструментами диагностики, такими как `smartctl`, `nvidia-smi` и другие, для сбора данных о состоянии оборудования.

## Команда запуска
```bash
python -m apps.windows.hardware
```

## Основные функции
- Диагностика SMART дисков.
- Мониторинг GPU (NVIDIA/AMD).
- Проверка параметров CPU.
- Стресс-тестирование системы.
