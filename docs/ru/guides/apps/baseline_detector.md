# Детектор конфигурационного дрифта (Baseline Detector)

## Назначение
Создание снимков эталонного состояния системы (System Baseline) и выявление конфигурационного дрифта (Drift Detection) в процессах, службах, портах и настройках.

## Структура
```
apps/baseline_detector/
├── README.md                          # Документация приложения
├── __init__.py                        # Пакет
├── __main__.py                        # Точка входа для CLI
└── src/                               # Логика детектора и сравнения
```

## Запуск
```powershell
# Запуск интерактивной консоли детектора
python -m apps.baseline_detector
```

Доступные команды:
- `create` — Создать снимок текущего состояния системы как эталон
- `detect` — Выполнить анализ отклонений текущего состояния от эталона
- `save <путь>` — Сохранить эталон в JSON-файл
- `load <путь>` — Загрузить эталон из JSON-файл
- `exit` — Завершить работу
