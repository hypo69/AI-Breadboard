# Плагин Smart News Feed (news_feed)

## Назначение
Агрегатор новостей с персонализацией, изучением интересов пользователя, ИИ-резюмированием и генерацией дайджестов.

## Структура
- `plugins/user-plugins/news_feed/`

## Запуск
Автоматическое агрегирование по RSS-лентам.

## API
- `get_smart_news`: Получение персонализированных новостей.
- `generate_news_digest`: Генерация дайджеста.
