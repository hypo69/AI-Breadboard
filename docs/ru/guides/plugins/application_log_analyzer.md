# Плагин Application Log Analyzer

## Назначение
Расширяет панель администрирования AI Breadboard инструментами диагностики логов приложения, кластеризации ошибок и ИИ-анализа первопричин с помощью Google Gemini.

## Структура
- `plugins/system-plugins/application_log_analyzer/`

## Запуск
Доступен через панель администрирования в разделе Plugins.

## API
- `Full Analysis`: Сканирование всех событий.
- `Error Filter`: Фильтрация ошибок.
- `AI Diagnostics`: Анализ через Gemini.
- `Rotate & Clean Logs`: Очистка логов.
