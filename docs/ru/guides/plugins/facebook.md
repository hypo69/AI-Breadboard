# Плагин Facebook Publisher (facebook)

## Назначение
Интеграция Facebook Graph API для автоматической публикации текстовых сообщений, ссылок с предпросмотром и фотографий на страницы Facebook или в ленты пользователей.

## Структура
- `plugins/user-plugins/facebook/`

## Запуск
Конфигурация через `.env` (токены) или панель администратора.

## API
- `post_to_facebook`: Публикация поста.
- `get_facebook_page_info`: Информация о странице.
- `get_facebook_accounts`: Список аккаунтов.
