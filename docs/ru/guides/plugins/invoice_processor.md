# Плагин Invoice Processor (invoice_processor)

## Назначение
Модуль для автоматического извлечения структурированных данных из счетов (PDF, изображения) с использованием OCR и моделей ИИ, с синхронизацией в Google Sheets.

## Структура
- `plugins/user-plugins/invoice_processor/`

## Запуск
Автоматическое сканирование или через API.

## API
- `process_invoices_folder`: Инструмент для обработки папки.
- `process_file`: Инструмент для обработки файла.
