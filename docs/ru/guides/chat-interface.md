# Руководство: Интерактивный интерфейс чата (Chat Interface)

## 📋 Обзор

Модуль **Чат** (`src/fastapi/webinterface/chat`) предоставляет современный веб-интерфейс в стиле ChatGPT для диалога с локальными и облачными языковыми моделями (Gemini, Foundry Local, ONNX/DirectML, Ollama, OpenAI-совместимые API и др.) с поддержкой потоковой генерации (SSE), базы знаний (RAG) и синтеза речи (TTS).

---

## 🚀 Ключевые возможности

### 1. Мультисессионная история диалогов (ChatGPT-Style)
- **Боковая панель (Sidebar)**: отображает полный список ваших веток разговоров с количеством диалогов.
- **Кнопка «+ Новый чат»**: мгновенно создаёт новую чистую ветку диалога без потери предыдущих бесед.
- **Быстрое переключение**: клик по любой сессии в сайдбаре загружает её переписку и изолированный контекст LLM (`chatHistory`).
- **Сворачиваемый интерфейс**: кнопка `sidebar toggle` (в шапке чата) позволяет спрятать или развернуть боковую панель.

### 2. Автоматическое именование диалогов (Smart Auto-Titling)
- При отправке первого сообщения в новом диалоге система автоматически формулирует лаконичный и ёмкий заголовок (до 36 символов с обрезкой по словам).
- Вы можете в любой момент изменить название вручную с помощью кнопки карандаша (✏️) в сайдбаре или в заголовке чата.

### 3. Персистентность и надежность (`localStorage`)
- Все сессии, сообщения, временные метки и роли участников сохраняются в локальном хранилище браузера (`breadboard_chat_sessions_v2`).
- При перезагрузке страницы (`F5` / `Ctrl+F5`) или случайном закрытии вкладки данные не теряются.

### 4. Интеграция с базой знаний (RAG)
- **Переключатель RAG**: быстрое включение/отключение семантического поиска по локальной векторной базе знаний.
- **Параметр TOP_K**: количество релевантных фрагментов контекста (от 1 до 50), передаваемых модели.
- **Параметр MIN_SCORE**: минимальный порог сходства (по умолчанию `0.45`), отсекающий шум.

### 5. Режимы вывода и озвучивание (TTS)
- `💬 Только текст`: стандартный вывод ответа модели без синтеза речи.
- `💬+🔊 Текст и голос`: потоковый вывод текста в окно чата с автоматической параллельной озвучкой через TTS (Web Speech API или бэкенд).
- `🔊 Только голос`: голосовой режим с фокусом на аудиовоспроизведение.
- **Кнопка озвучки (🔊)**: позволяет вручную прослушать любой ранее сгенерированный ответ ассистента.

## 🛠️ Управление сессиями диалогов

| Действие | Где находится | Описание |
|---|---|---|
| **Создать новый чат** | Верх сайдбара (`+ Новый чат`) | Начинает чистый диалог с приветственным экраном |
| **Переключить диалог** | Элемент списка в сайдбаре | Активирует сессию, восстанавливает историю сообщений |
| **Переименовать диалог** | Иконка ✏️ в сайдбаре или шапке | Открывает запрос на ввод нового названия |
| **Удалить диалог** | Иконка 🗑️ в сайдбаре | Удаляет конкретный чат с подтверждением |
| **Очистить сообщения** | Кнопка «Очистить» в шапке | Сбрасывает сообщения в текущем активном диалоге |
| **Удалить все диалоги** | Кнопка «Все» внизу сайдбара | Полный сброс всех сохраненных сессий |
| **Свернуть/Развернуть панель** | Кнопка в шапке чата | Скрывает/раскрывает боковую панель сессий |

## 💡 Рекомендации по использованию

> [!TIP]
> **Автоотправка из внешних источников**:
> Интерфейс поддерживает входящие URL-параметры `?prompt=...&autosend=true`, а также интеграцию с браузерным расширением Chrome для мгновенной отправки выделенного на веб-страницах текста в чат.

> [!NOTE]
> **Выбор модели**:
> Переключение активной языковой модели (Gemini Pro, Foundry Llama, ONNX Phi-3 и др.) осуществляется через панель моделей в верхнем навигационном меню и мгновенно применяется ко всем новым сообщениям в чате.
