# Руководства

Практические гайды и примеры для работы с AI Breadboard.

Этот раздел содержит подробные пошаговые руководства по основным компонентам платформы, интеграции и лучшим практикам разработки.

---

## 📚 Доступные гайды

### 1. [Быстрый старт (Quickstart Guide)](quickstart.md)
Первоначальная установка зависимостей, генерация локальных SSL-сертификатов и запуск сервиса.

---

### 2. [Интерактивный интерфейс чата (Chat Interface)](chat-interface.md)
Руководство по веб-интерфейсу чата в стиле ChatGPT: мультисессионная история, автонаименование диалогов, RAG-поиск и режимы озвучки (TTS).

---

### 3. [Настройка Google OAuth 2.0 (Localhost и Cloud)](google-oauth-setup.md)
Пошаговая настройка экрана согласия, авторизованных redirect URI, управление флагом `enable_oauth` и решение ошибок `access_denied`.

---

### 4. [Интеграция Google Workspace (Gmail, Drive, Docs)](google-workspace.md)
Подключение почты, облачных документов и автоматическая синхронизация с локальной базой знаний (RAG).

---

### 5. [Разработка Skills](developing-skills.md) (см. также [Полный раздел Навыков](../skills/index.md))
Полное руководство по созданию собственных Skills для расширения возможностей системы с поддержкой мультиязычности (i18n), фабрики `skill-factory` и каталога навыков.

---

### 6. [Разработка Plugins и Plugin Factory](developing-plugins.md) (см. также [Полный раздел Плагинов](../plugins/index.md))
Архитектура плагинов, жизненный цикл BasePlugin, интеграция с Web UI админки, генератор Plugin Factory, actions, поля конфигурации и мультиязычные метаданные.

---

### 7. [Создание Agents (Главный индекс)](creating-agents.md)
Руководство по проектированию и реализации всех категорий агентов в платформе:
- [Стандартные Python ReAct-агенты](standard-agents.md) — бэкенд-сервисы в `src/ai/agents/`
- [Динамические субагенты](dynamic-subagents.md) — фоновые агенты Antigravity (`define_subagent` / `invoke_subagent`)
- [Разработка Навыков-Агентов](developing-skills.md) — декларативные агенты в `.agents/skills/`

---

### 8. [Перенос базы знаний и сессий Antigravity (AGY Brain Migration)](agy-knowledge-base-migration.md)
Руководство по извлечению планов, артефактов и базы знаний из системного `~/.gemini/antigravity/brain/` внутрь проекта для обеспечения компьютеронезависимости.

---

### 9. [Стратегия тестирования](testing-strategy.md)
Комплексный подход к тестированию компонентов и систем.

---

### 10. [Система имитации (Simulation System)](simulation-system.md)
Руководство по архитектуре синтетической генерации данных, интеграции с Client RAG и обогащению через дефолтную LLM-модель.

---

### 11. [Каталог сценариев симуляции](simulation-scenarios.md)
Готовая матрица бизнес-сценариев для агентств (недвижимость, автотранспорт, готовый бизнес, страхование, счета).

---

### 12. [Защита API и аутентификация](../architecture/api-security.md)
Руководство по модели безопасности платформы, аутентификации эндпоинтов, разграничению прав (RBAC) и настройке CORS.

---
