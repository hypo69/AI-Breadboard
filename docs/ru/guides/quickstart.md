## 1. Системные требования

- **ОС:** Windows 10 / Windows 11 (64-bit)
- **Окружение:** PowerShell 7+ (`pwsh`) или Windows PowerShell 5.1
- **Python:** 3.12+ (рекомендуется устанавливать через python.org)
- **Сеть:** Свободный TCP-порт 8000 (или порт, указанный в `config.json`)

---

## 2. Первоначальная установка

Запустите установочный скрипт в корне репозитория:

```powershell
.\install.ps1
```

Скрипт автоматически:
1. Создаст изолированное виртуальное окружение `venv`.
2. Установит все необходимые зависимости из `requirements.txt`.
3. Сгенерирует локальный доверенный SSL-сертификат для работы по HTTPS (`localhost+2.pem`).
4. Подготовит шаблон переменных окружения `.env`.

---

## 3. Быстрый запуск сервиса

Для старта FastAPI-сервера со всеми сопутствующими сервисами используйте главный лончер:

```powershell
.\run.ps1
```

После завершения инициализации откроется браузер по адресу:  
👉 **https://localhost:8000/**

---

## 4. Конфигурация провайдеров ИИ

Ключи и точки подключения задаются в файле `.env` в корне проекта:

```env
# Google Gemini API
GEMINI_API_KEY=AIzaSy...

# Microsoft AI Foundry (локально или облако)
USE_FOUNDRY=false
FOUNDRY_BASE_URL=http://localhost:54837

# Ollama (локальные модели)
USE_OLLAMA=true
OLLAMA_BASE_URL=http://localhost:11434

# Авторизация Google OAuth (по умолчанию false)
ENABLE_OAUTH=false
```

---

## 5. Полезные сценарии запуска

### Интерактивный запуск (выбор хоста, порта и служб в диалоге):
```powershell
.\run.ps1 -Interactive
```

### Запуск с внешним туннелем Cloudflare (kino.davidka.net):
```powershell
.\run.ps1 -Cloudflared
```

### Запуск с включенной авторизацией Google OAuth:
```powershell
.\run.ps1 -EnableOAuth:$true
```

### Просмотр справки по всем доступным параметрам:
```powershell
.\run.ps1 --help
```
