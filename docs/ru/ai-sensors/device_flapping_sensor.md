# Сенсор телеметрии оборудования и детекции дребезга (Device Flapping Sensor)

## 📋 Обзор

Модуль **`DeviceFlappingSensor`** предназначен для непрерывного мониторинга состояния всего подключенного к компьютеру аппаратного обеспечения и периферии. Он фиксирует подключение и отключение устройств, вычисляет длительность их непрерывной работы, мгновенно выявляет сбои и переход в аварийное состояние (например, ошибки Windows PnP **Code 43**, **Code 10**, **Code 28**), а также обнаруживает циклический «дребезг» контактов (*flapping*).

---

## 🎯 Поддерживаемое оборудование

Сенсор классифицирует и непрерывно отслеживает следующие типы устройств:

| Категория | Примеры устройств | Что отслеживается |
| :--- | :--- | :--- |
| **HID & Периферия** | Клавиатуры, мыши, трекпады, манипуляторы | Подключение/отключение, сброс портов |
| **Wacom / Планшеты** | Графические планшеты Wacom, перья/стилусы (Pen), дигитайзеры | Суб-устройства пера, сенсорные поверхности, ExpressKeys |
| **Дисконкеи / Накопители** | USB-флешки (дисконкеи), внешние HDD/SSD, кардридеры | Физические диски `DiskDrive` и логические тома `Volume` |
| **HDMI / DP / Мониторы** | Мониторы, телевизоры, проекторы | Потеря сигнала Hot Plug Detect (HPD), отключение кабеля |
| **Принтеры** | Локальные USB и сетевые принтеры | Диспетчер печати, доступность интерфейса принтера |
| **Bluetooth** | Наушники, геймпады, адаптеры Bluetooth | Состояние радиомодуля, подключение сопряженных девайсов |
| **Системные шины** | Контроллеры USB, хабы, PCI/PCIe мосты | Сбои питания и сброс корневых концентраторов |

## ⚙️ Принцип работы и алгоритм детекции

1. **Низкоуровневый опрос SetupAPI**:
   Сенсор обращается напрямую к системным библиотекам Windows (`setupapi.dll` и `cfgmgr32.dll`) через Ctypes. Это гарантирует нулевую нагрузку на процессор и мгновенный снимок состояния сотен устройств.
2. **Анализ разницы состояний (Diffing)**:
   При каждом цикле опроса сенсор сравнивает текущее дерево оборудования с предыдущим снимком.
3. **Детекция дребезга (Flapping Alert)**:
   Для каждого устройства ведётся скользящее временное окно (по умолчанию `60.0` сек). Если устройство отключается $\ge N$ раз (по умолчанию `3` раза), сенсор генерирует тревожное событие `FLAPPING_ALERT`.
4. **Контроль ошибок PnP**:
   Сенсор фиксирует изменения флагов `DN_HAS_PROBLEM` и точный код проблемы (например, если флешка или видеокарта перешли в режим ошибки драйвера `Code 43`).

## 📊 Структура событий телеметрии

Все события пишутся в формате JSON-Lines (`logs/telemetry/device_telemetry_events.jsonl`):

```json
{
  "timestamp": "2026-09-23T19:04:53.123456+00:00",
  "event_type": "FLAPPING_ALERT",
  "device_instance_id": "USB\\VID_056A&PID_0357\\6&17A9B3E2&0&2",
  "friendly_name": "Wacom Intuos Pro M",
  "device_class": "HIDClass",
  "category": "Wacom / Графический планшет",
  "has_problem": true,
  "problem_code": 43,
  "status_code": 1024,
  "manufacturer": "Wacom Technology Corp.",
  "flapping_count_in_window": 3,
  "uptime_seconds": 4.5
}
```

### Типы событий (`event_type`):
* `CONNECTED` — Новое устройство подключено к системе.
* `DISCONNECTED` — Устройство извлечено или пропало из шины.
* `ERROR_STATE_CHANGED` — Изменился код ошибки устройства (например, появился сбой питания/драйвера).
* `FLAPPING_ALERT` — Зафиксирован циклический дребезг устройства (частые отключения).

## 🚀 Руководство пользователя / Быстрый старт

### Базовый запуск из Python

```python
import time
from apps.windows.telemetry import DeviceFlappingSensor

# 1. Функция обработки алертов
def alert_handler(event):
    if event.event_type == "FLAPPING_ALERT":
        print(f"🚨 [ВНИМАНИЕ]: Обнаружен дребезг устройства '{event.friendly_name}'! Категория: {event.category}")

# 2. Инициализация сенсора
sensor = DeviceFlappingSensor(
    poll_interval_sec=1.0,     # Частота опроса: 1 секунда
    flapping_window_sec=60.0,  # Окно анализа дребезга: 1 минута
    flapping_threshold=3,      # Порог тревоги: 3 отключения
    on_event_callback=alert_handler
)

# 3. Запуск в фоновом режиме
sensor.start()
print("Сенсор телеметрии оборудования активен...")

try:
    while True:
        time.sleep(5)
        stats = sensor.get_status()
        print(f"Активных устройств: {stats['active_devices_count']}, на контроле дребезга: {stats['flapping_devices_tracked']}")
except KeyboardInterrupt:
    sensor.stop()
    print("Сенсор остановлен.")
```
