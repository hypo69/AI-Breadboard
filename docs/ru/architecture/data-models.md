# Модели данных

Описание основных структур данных, используемых в системе AI-Breadboard.

## Основные модели

### Message (Сообщение)

Представляет одно сообщение в диалоге.

```python
{
    "id": "msg-123",              # Уникальный идентификатор
    "role": "user",               # Роль: "user", "assistant", "system"
    "content": "Привет!",         # Содержимое сообщения
    "timestamp": 1234567890,      # Временная метка (Unix timestamp)
    "model": "gemini-pro",        # Модель, которая обработала сообщение
    "metadata": {                 # Дополнительные данные
        "tokens": 5,
        "processing_time": 0.5
    }
}
```

**Поля:**
- `id` — уникальный идентификатор сообщения
- `role` — роль отправителя (пользователь, ассистент, система)
- `content` — текстовое содержимое сообщения
- `timestamp` — время создания сообщения
- `model` — модель, которая обработала сообщение
- `metadata` — дополнительная информация

### Chat (Диалог)

Представляет полный диалог между пользователем и системой.

```python
{
    "id": "chat-456",             # Уникальный идентификатор диалога
    "user_id": "user-789",        # Идентификатор пользователя
    "title": "Обсуждение API",   # Заголовок диалога
    "messages": [                 # Список сообщений
        {"role": "user", "content": "..."},
        {"role": "assistant", "content": "..."}
    ],
    "created_at": 1234567890,     # Время создания
    "updated_at": 1234567895,     # Время последнего обновления
    "model": "gemini-pro",        # Основная модель
    "settings": {                 # Настройки диалога
        "temperature": 0.7,
        "max_tokens": 1000
    }
}
```

**Поля:**
- `id` — уникальный идентификатор диалога
- `user_id` — идентификатор пользователя
- `title` — название диалога
- `messages` — список сообщений в порядке
- `created_at` — время создания
- `updated_at` — время последнего обновления
- `model` — модель по умолчанию
- `settings` — параметры диалога

### Model (Модель)

Описывает доступную модель с её параметрами.

```python
{
    "id": "gemini-pro",           # Уникальный ID модели
    "name": "Gemini Pro",         # Отображаемое имя
    "provider": "google",         # Провайдер
    "type": "chat",               # Тип: chat, image, speech и т.д.
    "available": True,            # Доступна ли модель
    "context_window": 32000,      # Размер контекста
    "description": "Универсальная модель для чата",
    "capabilities": [             # Возможности
        "text_generation",
        "code_generation",
        "reasoning"
    ],
    "cost": {                      # Стоимость использования
        "input_per_1k_tokens": 0.5,
        "output_per_1k_tokens": 1.5,
        "currency": "USD"
    }
}
```

**Поля:**
- `id` — уникальный идентификатор модели
- `name` — человекочитаемое имя
- `provider` — название провайдера
- `type` — тип модели
- `available` — статус доступности
- `context_window` — размер контекста
- `description` — описание
- `capabilities` — список возможностей
- `cost` — информация о стоимости

### RAGDocument (Документ RAG)

Представляет документ, добавленный в RAG-индекс.

```python
{
    "id": "doc-001",              # Уникальный ID документа
    "title": "API Документация",  # Заголовок
    "content": "...",             # Полный текст
    "chunks": [                   # Разбиение на части
        {
            "id": "chunk-001",
            "text": "...",
            "embedding": [0.1, 0.2, 0.3, ...],  # Vector
            "position": 0
        }
    ],
    "source": "api-docs.md",      # Источник документа
    "created_at": 1234567890,
    "metadata": {                 # Метаданные
        "tags": ["api", "rest"],
        "version": "1.0"
    }
}
```

**Поля:**
- `id` — уникальный идентификатор
- `title` — название документа
- `content` — полный текст
- `chunks` — разбиение на семантические части
- `source` — источник документа
- `created_at` — время добавления
- `metadata` — дополнительная информация

### Skill (Навык)

Описывает доступный навык системы.

```python
{
    "id": "skill-search",         # Уникальный ID
    "name": "Поиск",              # Имя навыка
    "description": "Поиск по документам",
    "version": "1.0.0",
    "author": "AI-Breadboard Team",
    "enabled": True,              # Включен ли навык
    "parameters": [               # Параметры навыка
        {
            "name": "query",
            "type": "string",
            "description": "Поисковый запрос",
            "required": True
        },
        {
            "name": "limit",
            "type": "integer",
            "description": "Количество результатов",
            "default": 5
        }
    ],
    "requires": [],               # Зависимости
    "tags": ["search", "rag"]
}
```

**Поля:**
- `id` — уникальный идентификатор
- `name` — название навыка
- `description` — описание
- `version` — версия
- `author` — автор
- `enabled` — статус включения
- `parameters` — входные параметры
- `requires` — зависимости
- `tags` — теги для категоризации

### APIRequest (Запрос API)

Стандартный формат запроса к API.

```python
{
    "id": "req-123",              # ID запроса
    "model": "gemini-pro",        # Модель
    "messages": [                 # Сообщения
        {"role": "user", "content": "Привет"}
    ],
    "temperature": 0.7,           # Параметры генерации
    "max_tokens": 1000,
    "top_p": 0.9,
    "top_k": 40,
    "system_prompt": "Ты помощник",
    "tools": [],                  # Навыки для использования
    "stream": False,              # Потоковый ответ
    "timeout": 30                 # Таймаут в секундах
}
```

**Поля:**
- `id` — уникальный идентификатор запроса
- `model` — целевая модель
- `messages` — история сообщений
- `temperature` — температура (креативность)
- `max_tokens` — максимум токенов в ответе
- `top_p` — top-p sampling параметр
- `top_k` — top-k sampling параметр
- `system_prompt` — системный промпт
- `tools` — навыки для использования
- `stream` — потоковая обработка
- `timeout` — таймаут

### APIResponse (Ответ API)

Стандартный формат ответа от API.

```python
{
    "id": "resp-123",             # ID ответа
    "request_id": "req-123",      # ID соответствующего запроса
    "model": "gemini-pro",        # Использованная модель
    "status": "success",          # Статус: success, error, timeout
    "message": {                  # Сообщение ответа
        "role": "assistant",
        "content": "Привет! Как дела?"
    },
    "usage": {                    # Использование токенов
        "input_tokens": 10,
        "output_tokens": 15,
        "total_tokens": 25
    },
    "processing_time": 0.5,       # Время обработки (сек)
    "timestamp": 1234567890,      # Временная метка
    "error": None                 # Ошибка (если есть)
}
```

**Поля:**
- `id` — уникальный идентификатор ответа
- `request_id` — ID связанного запроса
- `model` — модель, обработавшая запрос
- `status` — статус выполнения
- `message` — содержимое ответа
- `usage` — информация об использовании токенов
- `processing_time` — время обработки
- `timestamp` — временная метка
- `error` — информация об ошибке

### User (Пользователь)

Представляет профиль пользователя.

```python
{
    "id": "user-789",             # Уникальный ID
    "username": "john_doe",       # Имя пользователя
    "email": "john@example.com",  # Email
    "created_at": 1234567890,     # Дата регистрации
    "last_active": 1234567895,    # Последняя активность
    "preferences": {              # Настройки пользователя
        "default_model": "gemini-pro",
        "theme": "dark",
        "language": "ru"
    },
    "quota": {                    # Квота использования
        "daily_requests": 1000,
        "monthly_requests": 10000,
        "api_calls_today": 150
    },
    "role": "user"                # Роль (user, admin, moderator)
}
```

**Поля:**
- `id` — уникальный идентификатор
- `username` — имя пользователя
- `email` — электронная почта
- `created_at` — дата регистрации
- `last_active` — последняя активность
- `preferences` — настройки
- `quota` — квота использования
- `role` — роль пользователя

## Отношения между моделями

```
┌────────┐
│ User   │ 1──────────── * │ Chat
└────────┘                  └─────────┐
                               │      │
                               │      └─ * Message
                               │
                            uses_model
                               │
                               ▼
                            Model
                               │
                        provided_by
                               │
                               ▼
                            Provider

│ Chat ├─────── * │ Document
                   └─ ├─ RAGDocument
                      └─ Skills
```

## Форматы сериализации

### JSON

Основной формат для API и хранения.

```json
{
    "id": "msg-123",
    "role": "user",
    "content": "Привет!"
}
```

### Protobuf

Для высокопроизводительной сериализации (опционально).

### MessagePack

Для компактной сериализации в очередях (опционально).

## Валидация данных

Все модели проходят валидацию перед использованием:

- Проверка обязательных полей
- Проверка типов данных
- Проверка ограничений длины
- Проверка формата (email, URL и т.д.)
