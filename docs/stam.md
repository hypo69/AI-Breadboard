# Анализ вывески заправки Teboil

## 🔴 Основные косяки дизайна и эргономики

### 1. **Абсурдное ценообразование (главный косяк)**
- **92-й бензин: 106.00**
- **95-й бензин: 90.40**
- **ДТ: 91.90**

Это полная инверсия логики! Топливо с **более высоким октановым числом стоит дешевле** низкооктанового. Либо это ошибка отображения на табло, либо реальные цены (что выглядит как сбой системы).

### 2. **Плохая читаемость цен**
- Цифры **слишком мелкие** для такого большого табло
- Водитель на скорости не успеет считать цены
- Копеечная часть (`.00`, `.40`, `.90`) ещё мельче — практически нечитаема с расстояния

### 3. **Визуальный шум и повторение бренда**
Название **TEBOIL повторяется 3 раза**:
- TEBOIL (красный блок)
- TEBOIL café (синий блок)
- TEBOIL+ (красный блок)

Это создаёт путаницу и размывает фокус внимания.

### 4. **Нарушение иерархии информации**
- **Кафе** занимает огромный синий блок сразу после логотипа — это второстепенная информация, но визуально она кричит о себе
- **Цены** (главная информация для водителя) зажаты в узкий чёрный блок

### 5. **Цветовая чехарда**
Чередование **красный → синий → чёрный → красный → синий** создаёт визуальный хаос. Нет единого ритма.

### 6. **Иконки услуг внизу**
- Слишком мелкие
- Непонятные с расстояния
- Не несут практической пользы для водителя в машине

### 7. **Вертикальная ориентация**
Для автозаправки **горизонтальное табло** было бы эргономичнее — водитель смотрит вперёд/вбок, а не задирает голову вверх.

## ✅ Как сделать правильно

### Структура табло (сверху вниз):

```
─────────────────────────────┐
│  ЛОГОТИП TEBOIL (крупно)    │  ← 1 блок, красный
├─────────────────────────────┤
│  ЦЕНЫ НА ТОПЛИВО (крупно)   │  ← 2 блок, чёрный/тёмный
│  АИ-92 ....... 90.40 ₽/л    │
│  АИ-95 ....... 95.00 ₽/л    │  ← цены должны расти с октаном
│  ДТ .......... 91.90 ₽/л    │
├─────────────────────────────┤
│  TEBOIL+ (доп. услуги)      │  ← 3 блок
├─────────────────────────────┤
│  Кафе / Магазин (мелко)     │  ← 4 блок, второстепенно
└─────────────────────────────┘
```

### Конкретные рекомендации:

| Параметр | Сейчас | Как надо |
|----------|--------|----------|
| Размер цифр цен | ~15 см | **40-60 см** |
| Повторение бренда | 3 раза | **1 раз** (логотип) |
| Порядок цен | 92 > 95 (абсурд) | **92 < 95 < 98** |
| Единица измерения | Отсутствует | **₽/л** обязательно |
| Цветовых блоков | 5 разных | **2-3 максимум** |
| Ориентация | Вертикальная | **Горизонтальная** или комбинированная |

### Эргономика для водителя:
- Табло должно быть видно с **50-100 метров**
- Время считывания — **не более 2 секунд**
- Контрастность: белый/жёлтый текст на тёмном фоне
- Цены — **самый крупный элемент** после логотипа

**Вывод**: текущий дизайн приоритизирует брендинг над функциональностью. Для заправки главное — быстро донести цены до водителя, а не продать кафе.
