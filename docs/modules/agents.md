# 🧩 Архитектура и Управление ИИ-Агентами

## Обзор

Платформа **ai-assistant** предоставляет модульную систему для создания, настройки и исполнения автономных **ИИ-агентов**. 

Агенты могут использовать различные модели из **пула провайдеров** (`Google Gemini`, `Google Antigravity / AGY`, `Microsoft Foundry`, `Ollama`) и подключать любые доступные **инструменты** (поиск торрентов, сбор метаданных TMDb, интернет-поиск Google Grounding / Playwright, RAG, отправку загрузок в qBittorrent, синтез речи TTS).

## 🏗️ Основные компоненты

### 1. Каталог агентов (Agent Registry)
Реестр доступных в системе агентов хранится в файле [`config.json`](file:///c:/ai-assistant/config.json) в секции `agents.items`. 

Каждый агент содержит:
* `id` — уникальный идентификатор агента (например, `media_search`).
* `name` — отображаемое имя агента.
* `description` — назначение и роль агента.
* `is_system` — признак системного агента (системные агенты защищены от удаления).
* `enabled` — флаг активности (агент можно включить/выключить одним кликом).
* `provider` — выбранный провайдер модели (`gemini`, `agy`, `foundry`, `ollama`).
* `model` — идентификатор модели из пула (`gemini-2.5-flash`, `agy-flash`, `qwen2.5:7b`, `foundry:qwen2.5-1.5b-instruct` и др.).
* `temperature` — параметр креативности (от 0.0 до 1.0).
* `max_steps` — максимальное количество шагов рассуждения (ReAct loop).
* `timeout_seconds` — таймаут выполнения запроса.
* `tools` — список идентификаторов подключенных инструментов.
* `system_prompt` — системная инструкция с правилами поведения и форматирования ответа.

---

### 2. AI-Конструктор агентов (Prompt & Agent Architect)
Для создания нового агента пользователю не обязательно вручную формулировать подробные системные инструкции. Достаточно кратко описать задачу, а выбранная модель-архитектор из пула проекта сгенерирует:
1. Оптимальный `system_prompt` с разграничением ролей.
2. Рекомендуемый набор инструментов (capabilities).
3. Правила выбора инструментов и формат ответа.

API-эндпоинт: `POST /api/agents/generate-prompt`

### 3. Каталог инструментов (Tool Registry)

| Инструмент | Идентификатор | Описание |
|---|---|---|
| **🎬 TMDb API** | `get_movie_metadata` | Поиск постеров, описаний, рейтингов и года выхода через TMDb |
| **🧲 Торренты** | `search_torrents` | Поиск раздач на Rutracker и NNMClub через Playwright |
| **🌐 Веб-поиск** | `web_search` | Поиск в интернете (Google Grounding, AGY, DuckDuckGo) |
| **📥 qBittorrent** | `add_torrent_download` | Добавление торрента на скачивание в торрент-клиент |
| **🧠 База знаний RAG** | `rag_search` | Семантический поиск по документам и истории диалогов |
| **📺 Плеер CosmicPlayer**| `build_player_url` | Генерация прямых и embed-ссылок для встроенного видеоплеера |
| **🗣️ Озвучка (TTS)** | `tts_generate` | Синтез речи для голосовых ответов |
| **📁 Медиатека** | `media_scan` | Сканирование файловой структуры дисков и организация файлов |

---

### 4. Интерактивная песочница (Agent Sandbox)
Прямо в панели управления доступна песочница, позволяющая:
* Отправить агенту тестовое сообщение.
* Отследить шаги рассуждения (**Thought**).
* Просмотреть конкретные вызовы инструментов (**Tool Calls**) с аргументами и результатами.
* Замерить время ответа и убедиться в стабильности конфигурации до запуска в боевой режим.

API-эндпоинт: `POST /api/agents/test`

## 📡 REST API эндпоинты (`/api/agents`)

```http
GET    /api/agents                # Список всех агентов
POST   /api/agents                # Создание нового кастомного агента
GET    /api/agents/tools          # Каталог доступных инструментов
GET    /api/agents/providers      # Доступные провайдеры и модели из пула
PUT    /api/agents/{agent_id}     # Обновление настроек / переключение статуса
DELETE /api/agents/{agent_id}     # Удаление кастомного агента
POST   /api/agents/generate-prompt# AI-генератор спецификации агента
POST   /api/agents/test           # Тестовый прогон в песочнице
```
