---

## 💡 بيان «AI Breadboard»

في هندسة الإلكترونيات، تعد **لوحة التجارب (Breadboard)** أداة أساسية تسمح بتركيب الدوائر الإلكترونية واختبار الإشارات وتعديل التوصيلات في ثوانٍ دون الحاجة إلى اللحام.

يقدم مشروع **`aibreadboard`** نفس الرؤية لعالم الذكاء الاصطناعي:
1. **منصة تجارب مفتوحة (Open Breadboard Testbench):** تشغيل أصلي، شفاف ومباشر على النظام المضيف (FastAPI، Python venv، ONNX DirectML) مع وصول مباشر لكل مكوّن.
2. **ناقل نماذج موحد:** إمكانية ربط أي نموذج — من Google Gemini السحابي إلى النماذج المحلية الخفيفة (SLMs) — عبر واجهة موحدة `UnifiedChatModel`.
3. **نقاط فحص مفتوحة:** فحص وتتبع حساب متجهات التضمين (Embeddings)، وتدفق الرموز (Streaming)، ومصفوفات التشابه.
4. **مختبر RAG و Fine-Tuning:** تحسين أداء الرسوم البيانية باستخدام Microsoft Olive، وتصدير النماذج إلى ONNX، وتدريب دقيق عبر LoRA/QLoRA.
5. **نظام المهارات المعياري (Skills):** توسيع إمكانيات الوكلاء الذكيين عند الطلب عبر ملفات `SKILL.md`.
