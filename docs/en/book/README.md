# AI Breadboard Textbook (English)

## Overview
Canonical English edition of the **AI Breadboard Textbook**: A comprehensive guide to AI system architecture, local hardware-accelerated inference, RAG vector indexing, skills management, and model fine-tuning.

## Chapters
- [`index.md`](index.md) - Manifesto, breadboard metaphor, architecture overview, table of contents.
- [`ch01_philosophy.md`](ch01_philosophy.md) - Chapter 1: Breadboard architecture, testbench concept, configs, PowerShell launchers.
- [`ch02_orchestration.md`](ch02_orchestration.md) - Chapter 2: Model orchestrator, `UnifiedChatModel`, `ModelManager`, circuit breaker, API key pooling.
- [`ch03_local_inference.md`](ch03_local_inference.md) - Chapter 3: In-process local inference, Hugging Face Transformers, Microsoft ONNX Runtime, and DirectML GPU acceleration.
- [`ch04_rag_architecture.md`](ch04_rag_architecture.md) - Chapter 4: RAG architecture, vector mathematics, cosine similarity, FAISS index, dev codebase RAG, and Google Colab integration.
- [`ch05_optimization_finetuning.md`](ch05_optimization_finetuning.md) - Chapter 5: Model optimization, graph passes (Microsoft Olive), ONNX export (`gguf_to_onnx.py`), dataset formatting, and LoRA/QLoRA fine-tuning.
- [`ch06_agents_and_mcp.md`](ch06_agents_and_mcp.md) - Chapter 6: ReAct agents (LangChain), Model Context Protocol (MCP), and multimodal voice pipeline.
- [`ch07_skills_management.md`](ch07_skills_management.md) - Chapter 7: Skills architecture, `SKILL.md` manifests, progressive disclosure, `skill-factory`, discovery and lifecycle management.
- [`ch08_laboratory_practicum.md`](ch08_laboratory_practicum.md) - Chapter 8: Laboratory Practicum with 10 hands-on experiments on the breadboard.
