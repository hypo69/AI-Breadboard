# Telegram Mini App

Интеграция с Telegram Mini App позволяет управлять плеером из мессенджера.

## Доступ

Откройте Telegram Mini App через меню бота или по ссылке:

```
https://your-domain.com/tgmini
```

## Интерфейс

```
┌─────────────────────────────────────────┐
│  Telegram  🤖 ai-assistant        │
├─────────────────────────────────────────┤
│  📺 Плеер                               │
│                                         │
│  [Play/Pause]  [Next]  [Previous]      │
│                                         │
│  🎵 Текущий трек: Титаник              │
│                                         │
│  [Плейлист]  [Категории]               │
│                                         │
├─────────────────────────────────────────┤
│  🔔 Уведомления                        │
│  ⚙️ Настройки                          │
└─────────────────────────────────────────┘
```

## Возможности

### 1. Управление воспроизведением

- **Play/Pause** — запуск и пауза воспроизведения
- **Next** — следующий трек
- **Previous** — предыдущий трек
- **Volume** — регулировка громкости

### 2. Выбор медиа

- **Категории** — выбор по жанрам
- **Поиск** — поиск по названию
- **История** — недавно воспроизведённые

### 3. Уведомления

- Статус плеера
- Изменение трека
- Ошибка воспроизведения

### 4. Настройки темы

- **Тёмная тема** — по умолчанию
- **Светлая тема** — для комфортного просмотра
- **Автоматическая** — зависит от системы

## Установка

### 1. Создание Telegram бота

1. Откройте @BotFather в Telegram
2. Создайте нового бота: `/newbot`
3. Получите токен бота

### 2. Настройка .env файла

Добавьте в `.env`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
```

### 3. Настройка Web App URL

В `core/fastapi/config.json`:

```json
{
  "tg_mini_app": {
    "url": "https://your-domain.com/tgmini",
    "name": "ai-assistant",
    "description": "AI Assistant with media player"
  }
}
```

### 4. Запуск

```bash
python main.py
```

## Использование

### 1. Запуск Mini App

1. Откройте вашего бота в Telegram
2. Нажмите меню (или `/start`)
3. Выберите "ai-assistant"

### 2. Подключение к плееру

1. Убедитесь, что плеер запущен
2. В Mini App нажмите "Подключить плеер"
3. Введите email пользователя (Room ID)

### 3. Управление

- Используйте кнопки на экране
- Можно также использовать чат с ботом

## Telegram Bot commands

### /start

Запуск Mini App

### /help

Список команд

### /status

Статус плеера

```
Status: Playing
Track: Титаник
Position: 00:15:32
Volume: 80%
Room: user@example.com
```

## Настройки

### В Mini App

- Тема оформления
- Звук уведомлений
- Язык интерфейса

### В .env

```env
TELEGRAM_BOT_TOKEN=your_token
JWT_SECRET=your_jwt_secret
```

## Работа с плагинами

Mini App интегрируется с плагинами:

- `media_layer` — управление субтитрами
- `rag` — поиск по медиатеке
- `media_organizer` — управление медиатекой
