# Начало работы для пользователей

## Запуск приложения

Для запуска сервера используйте предоставленные скрипты-лончеры (например, `.\run.ps1` или другие доступные скрипты запуска), после чего откройте в браузере:

```
http://localhost:3000
```

### Выбор интерфейса

1. **Плеер** (`/user`) — основной интерфейс для воспроизведения
2. **Пульт ДУ** (`/rc`) — голосовое управление
3. **Telegram** (`/tgmini`) — удалённое управление через Telegram

## Плеер

Плеер позволяет воспроизводить видео и аудио файлы.

### Как запустить медиа

1. В чате введите запрос: "Найди Титаник"
2. Или выберите файл из списка категорий

### Управление

| Команда | Действие |
|---------|----------|
| Пробел | Пауза/Возобновление |
| Стрелки | Навигация по времени |
| f | Полноэкранный режим |
| m | Отключить/включить звук |

## Пульт дистанционного управления

Пульт позволяет управлять плеером голосом.

### Голосовые команды

```
"Включи Титаник"
"Поставь на паузу"
"Увеличь громкость"
"Следующий файл"
"Предыдущий файл"
```

### Настройки TTS

В настройках пульта можно изменить:
- Голос синтеза речи
- Скорость речи
- Язык

## Telegram Mini App

Интеграция с Telegram позволяет управлять плеером из мессенджера.

### Как подключить

1. Откройте Telegram
2. Найдите вашего бота
3. Нажмите меню → Запустить Mini App

### Возможности

- Запуск/пауза воспроизведения
- Переключение треков
- Управление громкостью
- Получение статуса плеера

## Админ-панель

Для управления медиатекой используйте `/admin`.

### Основные функции

1. **Сканирование** — сканирование дисков для обновления медиатеки
2. **Аудит** — проверка соответствия БД и файловой системы
3. **RAG Build** — построение индекса для поиска
4. **Категории** — управление категориями медиа

## Советы по использованию

1. **Начните с админки** — сначала отсканируйте диски
2. **Используйте RAG** — поиск по названиям работает быстрее
3. **Настройте голосовые команды** — пульт ДУ удобен в использовании
4. **Сохраняйте сессии** — используйте JWT токены для сохранения состояния
