# Голосовое управление (Пульт ДУ)

Пульт дистанционного управления позволяет управлять плеером с помощью голосовых команд.

## Доступ

Откройте пульт в браузере:

```
http://localhost:3000/rc
```

## Голосовые команды

### Управление воспроизведением

| Команда | Действие |
|---------|----------|
| "Включи Титаник" | Запустить воспроизведение |
| "Поставь на паузу" | Пауза |
| "Продолжай" | Возобновить |
| "Выключи" | Остановить |

### Навигация по времени

| Команда | Действие |
|---------|----------|
| "Вперед 10 секунд" | Переход вперёд |
| "Назад 10 секунд" | Переход назад |
| "К 50 минуте" | Перейти к времени |

### Управление громкостью

| Команда | Действие |
|---------|----------|
| "Громкость на 80" | Установить громкость 80% |
| "Громкость максимум" | Максимальная громкость |
| "Тише" | Уменьшить громкость |
| "Громче" | Увеличить громкость |

### Управление плейлистом

| Команда | Действие |
|---------|----------|
| "Следующий файл" | Следующий трек |
| "Предыдущий файл" | Предыдущий трек |
| "Список файлов" | Показать плейлист |

### Поиск медиа

| Команда | Действие |
|---------|----------|
| "Найди Титаник" | Найти и воспроизвести |
| "Фильмы Кристофера Нолана" | Рекомендации |
| "Сериалы про шпионов" | Поиск по жанру |

### Общие команды

| Команда | Действие |
|---------|----------|
| "Помощь" | Показать список команд |
| "Состояние" | Статус плеера |

## Настройки

### Открыть настройки

Нажмите кнопку ⚙️ в правом верхнем углу.

### Доступные настройки

#### Голос (TTS)

| Параметр | Варианты |
|----------|----------|
| Язык | Russian, English |
| Голос | Мужской, Женский |
| Скорость | 0.5x - 2x |
| Высота тона | Низкий, Средний, Высокий |

#### Распознавание речи (STT)

| Параметр | Варианты |
|----------|----------|
| Язык | Russian, English |
| Микрофон | Выбор устройства |
| Таймаут | 5s, 10s, 30s |

### Сохранение настроек

Настройки сохраняются в `localStorage` браузера и не требуют перезагрузки.

## Использование с Telegram

Пульт ДУ можно использовать вместе с Telegram Mini App для синхронного управления.

### Настройка

1. Откройте Telegram Mini App
2. Введите ID комнаты (email пользователя)
3. Используйте голосовую команду на пульте
4. Управление синхронизируется

## Troubleshooting

### Голос не распознаётся

1. Проверьте разрешение на использование микрофона
2. Убедитесь, что микрофон работает
3. Попробуйте другой язык распознавания

### Команды не выполняются

1. Убедитесь, что плеер запущен
2. Проверьте подключение к серверу
3. Попробуйте перезагрузить страницу

### Задержка ответа

1. Проверьте интернет-соединение
2. Уменьшите скорость речи в настройках
3. Попробуйте короткие команды
