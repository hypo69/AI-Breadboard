# Аудит установленного ПО (Software Audit)

Этот документ описывает использование движка аудита программного обеспечения в системе AI-Breadboard.

## Обзор
Движок `SoftwareAuditEngine` представляет собой **гибридное решение (Hybrid Audit Engine)**, которое объединяет данные из реестра Windows (инвентаризация) и артефактов операционной системы (UserAssist, Prefetch) для получения актуальной картины состояния программного обеспечения.

## Возможности
- **Инвентаризация:** Автоматическое обнаружение установленных приложений в ветках `HKLM` и `HKCU` реестра.
- **Анализ активности:** Определение факта и времени последнего запуска приложений на основе артефактов системы.
- **Категоризация:** Автоматическое определение назначения приложений (Браузеры, Разработка, Мультимедиа и др.).
- **Автоматическое логирование:** Каждый запуск аудита автоматически сохраняет сводный отчет в CSV-файл по пути: `%APPDATA%/AI-Assistant/software_audit.csv`.

## Использование через Python
Для получения отчета в коде программы используйте следующий подход:

```python
from apps.windows.core.software_audit import SoftwareAuditEngine

# 1. Инициализация движка
engine = SoftwareAuditEngine()

# 2. Генерация отчета
report = engine.generate_audit_report()

# 3. Доступ к данным
print(f"Всего приложений: {report.total_apps}")
for app in report.apps:
    print(f"- {app.display_name} (версия: {app.version})")
```
