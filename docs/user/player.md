# Управление плеером

Плеер позволяет воспроизводить видео и аудио файлы с синхронизацией между устройствами.

## Интерфейс плеера

```
┌─────────────────────────────────────────────────────┐
│  [Logo]  ai-assistant  [Menu]                 │
├─────────────────────────────────────────────────────┤
│                                                     │
│              ┌───────────────────┐                  │
│              │                   │                  │
│              │   VIDEO PLAYER    │                  │
│              │                   │                  │
│              └───────────────────┘                  │
│                                                     │
│  Playlist                  [Search] [Categories]   │
│                                                     │
├─────────────────────────────────────────────────────┤
│  [Chat Input]  [Send]                               │
└─────────────────────────────────────────────────────┘
```

## Управление воспроизведением

### Через интерфейс

| Кнопка | Действие |
|--------|----------|
| 🎵 | Воспроизведение/Пауза |
| ⏮️ | Назад 10 секунд |
| ⏭️ | Вперёд 10 секунд |
| 🔊 | Громкость |
| 📋 | Плейлист |
| 🖥️ | Полноэкранный режим |

### С клавиатуры

| Клавиша | Действие |
|---------|----------|
| `Space` | Пауза / Возобновление |
| `←` | Назад 5 секунд |
| `→` | Вперёд 5 секунд |
| `↑` | Громкость +
| `↓` | Громкость -
| `f` | Полноэкранный режим |
| `m` | Отключить звук |
| `c` | Включить/выключить субтитры |

## Работа с плейлистом

### Добавление файлов

1. **Через чат**
   ```
   "Найди фильм Титаник"
   "Найди сериал Игр престолов"
   ```

2. **Через категорию**
   - Откройте категорию (например, "Боевики")
   - Выберите фильм/сериал

3. **Через URL**
   - Введите ссылку на файл или magnet-ссылку

### Управление плейлистом

- **Удалить файл**: нажмите 🗑️ рядом с файлом
- **Переместить**: перетащите файл мышью
- **Очистить**: нажмите "Очистить плейлист"

## Чат AI

Чат позволяет находить медиа и получать рекомендации.

### Примеры запросов

```markdown
# Поиск по названию
"Титаник"
"Игры престолов S01E01"

# Поиск по жанру
"Боевики 2020-2025"
"Сериалы про шпионов"

# Рекомендации
"Что посмотреть с семьёй?"
"Лучшие фильмы Кристофера Нолана"

# Управление
"Включи Титаник"
"Поставь на паузу"
"Следующий файл"
```

## Синхронизация

Плеер поддерживает синхронизацию между устройствами через WebSocket.

### Как это работает

1. **Плеер** подключается к серверу
2. **Пульт** или **Telegram** подключается к той же комнате
3. Все команды синхронизируются в реальном времени

### Использование нескольких устройств

```bash
# На плеере
http://localhost:3000/user?room=user1@gmail.com

# На пульте
http://localhost:3000/rc?room=user1@gmail.com
```

## Типы медиа

| Тип | Поддерживаемые форматы |
|-----|------------------------|
| Видео | MP4, MKV, AVI, MOV, WebM |
| Аудио | MP3, WAV, FLAC, OGG, M4A |

## Настройки плеера

### Доступные настройки

1. **Качество видео**
   - Авто
   - 1080p
   - 720p
   - 480p

2. **Субтитры**
   - Включить/выключить
   - Размер шрифта
   - Цвет текста

3. **Звук**
   - Стандартный канал
   - Дублированный канал
   - Оригинальный звук

4. **Поведение**
   - Автовоспроизведение
   - Запоминать позицию
   - Цикл воспроизведения
