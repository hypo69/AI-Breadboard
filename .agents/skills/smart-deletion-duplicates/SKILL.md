# Smart Deletion Duplicates

Этот навык предназначен для безопасного удаления дубликатов медиа-файлов, обеспечивая синхронизацию между файловой системой и базой данных `media.db`.

## ⚠️ Важное предупреждение
Удаление выполняется необратимо. Перед выполнением операции обязательно убедитесь в правильности списка файлов.

## 🛡️ Безопасность и резервное копирование

Перед выполнением ЛЮБЫХ операций по изменению базы данных `media.db` ОБЯЗАТЕЛЬНО создайте её резервную копию.
Имя файла резервной копии должно содержать временную метку в формате: `media.db.MMDD-HHMMSSS`.
Пример: `media.db.0724-1530123`.


## 🚀 Как использовать

1.  **Генерация списка кандидатов:**
    Сначала необходимо создать список файлов для удаления (например, с помощью анализа дубликатов). Список должен содержать полные пути к файлам.
2.  **Выполнение удаления:**
    Используйте скрипт `scripts/delete_media.py` для выполнения удаления.

```bash
python scripts/delete_media.py --file <путь_к_csv_со_списком_файлов> --execute
```

## 🛠️ Скрипты

### `scripts/delete_media.py`
Скрипт выполняет:
1. Проверку существования файла.
2. Удаление файла с диска (`os.remove`).
3. Удаление соответствующей записи из `media.db` по пути (`DELETE FROM media WHERE path = ?`).

## 📂 Структура данных
Скрипт ожидает CSV файл с колонкой `to_delete`, содержащей пути к файлам для удаления.
