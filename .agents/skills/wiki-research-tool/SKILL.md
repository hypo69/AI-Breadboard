# Навык: Wiki Research Tool

## 🎯 Назначение
Навык `wiki-research-tool` обеспечивает взаимодействие с лабораторией исследования Википедии (`apps/wikipedia_research`). Предназначен для выполнения многоязычных поисковых запросов, сравнительного анализа дискурса в Википедии и проведения бенчмарков интерпретации ИИ.

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на получение информации из Википедии, сравнение статей на разных языках или выполнение задач по интерпретации контента.
2. **Взаимодействие**: Навык использует API исследовательской лаборатории (по умолчанию `http://localhost:8110/api/v1/wikipedia-research/*`).
3. **Безопасность**: Навык предоставляет инструменты для анализа публичных данных и не требует особых привилегий.

## 🛠️ Основные команды
- `search_articles`: Поиск статей на заданном языке.
- `compare_discourse`: Сравнительный анализ дискурса Википедии по заданной теме.
- `run_benchmark`: Запуск бенчмарка интерпретации ИИ (Exp B).

## ⚠️ Важное замечание
Навык требует доступа к интернету и запущенного `wikipedia_research`.
