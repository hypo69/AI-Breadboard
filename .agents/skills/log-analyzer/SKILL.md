# 📊 Log Analyzer Skill

Навык для статического и интеллектуального (AI-assisted) анализа системных и прикладных логов проекта AI-Breadboard, выявления первопричин сбоев, кластеризации повторяющихся ошибок и формирования структурированных отчетов.

---

## 🎯 Назначение и Сценарии применения

1. **Диагностика сбоев и ошибок**: Быстрый сбор и группировка `ERROR` и `CRITICAL` записей с вычислением частотности.
2. **AI-ассистированный анализ (Gemini)**: Синтез причин сбоев, выявление неочевидных корреляций и получение готовых шагов по устранению (Remediation steps).
3. **Мониторинг логов в реальном времени**: Потоковое отслеживание логов с фильтрацией по уровням важности.
4. **Анализ периодических отчетов (Master Journal)**: Формирование единого журнала состояния системы для разработчика.

---

## 🚀 Протокол выполнения (Шаги для Агента)

При запросе пользователя проанализировать логи:
1. Запустите скрипт анализа для директории логов или конкретного файла:
   ```powershell
   python .agents/skills/log-analyzer/scripts/analyze.py --level ERROR
   ```
2. Для получения сводки в формате JSON для программной обработки:
   ```powershell
   python .agents/skills/log-analyzer/scripts/analyze.py --json
   ```
3. Для генерации отчета с привлечением AI модели:
   ```powershell
   python .agents/skills/log-analyzer/scripts/analyze.py --ai --save-report
   ```
4. Для интерактивного мониторинга новых сообщений:
   ```powershell
   python .agents/skills/log-analyzer/scripts/watch_logs.py --level WARNING
   ```

## 🛠️ Доступные CLI-параметры `scripts/analyze.py`

| Флаг | Описание |
|---|---|
| `--file`, `-f` | Путь к конкретному `.log` или `.json` файлу |
| `--log-dir`, `-d` | Директория с логами (по умолчанию временная папка `ai-breadboard/logs`) |
| `--level`, `-l` | Фильтрация по уровню (`ERROR`, `WARNING`, `INFO`, `CRITICAL`) |
| `--tail`, `-n` | Анализ последних N строк |
| `--ai` | Подключение AI-диагностики через Gemini API |
| `--json` | Вывод в формате JSON |
| `--output`, `-o` | Сохранение отчета по указанному пути |
| `--save-report`, `-s` | Сохранение отчета в стандартную папку `reports/` |
