# Аудит давно не запускавшихся программ (Dormant Software Auditor)

## 🎯 Назначение (Purpose)
Навык предназначен для углубленного аудита программного обеспечения Windows с целью выявления давно не запускавшихся (dormant), неиспользуемых и устаревших приложений, а также программ без подтвержденных запусков.

## 🚀 Триггеры и применение (When to Use & Triggers)
- Запросы пользователя: «найди давно не запускавшиеся программы», «какие программы не используются», «найди спящее ПО», «аудит приложений», «очистка системы от неиспользуемого софта».
- Экспресс-диагностика и аудит в Test Computer (/tc), веб-интерфейсе и консоли.

## ⚙️ Протокол выполнения (Execution Protocol)
1. **Сбор реестра ПО:** Извлечение списка установленных программ из ветвей HKLM и HKCU (SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Uninstall и SOFTWARE\\WOW6432Node\\...).
2. **Анализ артефактов запусков:**
   - **UserAssist:** Расшифровка ROT13-записей из ветки Software\\Microsoft\\Windows\\CurrentVersion\\Explorer\\UserAssist\\{GUID}\\Count, распаковка FILETIME последнего запуска, количества запусков (run_count) и времени фокуса.
   - **Windows Prefetch:** Сканирование каталога C:\\Windows\\Prefetch\\*.pf для извлечения времени последнего запуска бинарных файлов.
3. **Сопоставление и классификация:**
   - Сопоставление приложений с найденными артефактами по имени .exe, ярлыкам .lnk и путям установки.
   - Выделение категорий:
     - **Давно запускавшиеся (> 60–90 дней):** Программы с зафиксированной датой запуска в прошлом.
     - **Неиспользуемые (Dormant / Never Launched):** Программы без следов запуска пользователем.
     - **Активно используемые:** Программы со свежими метками запусков.
4. **Формирование рекомендаций:** Предоставление структурированной таблицы с указанием даты последнего запуска, источника артефакта, описания назначения и штатных команд безопасной деинсталляции (uninstall_string).
