# Навык: Network Analyzer

## 🎯 Назначение
Навык `network-analyzer` предназначен для взаимодействия с терминалом сети (`apps/network_terminal`). Он позволяет агентам ИИ выполнять захват пакетов, анализировать сетевой трафик, распределение протоколов и обнаруживать аномалии.

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на диагностику сети, анализ подозрительной активности или мониторинг потока данных.
2. **Взаимодействие**: Навык использует API конечных точек терминала сети (по умолчанию `http://localhost:8101/api/v1/network/*`).
3. **Безопасность**: Запуск захвата трафика (TShark) требует прав администратора и явного разрешения пользователя.

## 🛠️ Основные команды
- `start_capture`: Запуск сессии захвата пакетов.
- `analyze_traffic`: Получение статистики по протоколам и потокам.
- `get_anomalies`: Получение списка обнаруженных сетевых аномалий.

## ⚠️ Важное замечание
Навык предназначен для использования внутри контролируемой среды AI Breadboard. Убедитесь, что `network_terminal` запущен.
