# Web Chat CLI

Этот навык предоставляет консольный чат-интерфейс для взаимодействия с системой, аналогичный веб-интерфейсу.

## 🚀 Как использовать
Запустите чат командой:
`python .gemini/skills/web-chat-cli/src/chat.py`

## 🛠️ Функционал
- Интерактивная сессия (цикл вопрос-ответ).
- Управление историей диалога.
- Integration с RAG и инструментами медиатеки.
