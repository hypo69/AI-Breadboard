# GCloud Manager Skill

This skill provides an interface to control the `gcloud_monitor` application within the AI Breadboard ecosystem.

## Features
- Google Cloud Logging query and analysis.
- Cloud Monitoring telemetry aggregation.
- IAM audit and security inspection.
- AI-driven incident root-cause diagnosis.

## Requirements
- `gcloud_monitor` must be running (usually on port 8106).
- Valid Google Cloud Platform credentials.
