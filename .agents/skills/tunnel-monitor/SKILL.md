# Навык: Tunnel Monitor

## 🎯 Назначение
Навык `tunnel-monitor` обеспечивает взаимодействие с супервизором туннелей Cloudflare (`apps/cloudflared_monitor`). Предназначен для мониторинга здоровья туннелей, анализа логов и диагностики доступности публичных эндпоинтов.

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на проверку состояния туннелей, анализ ошибок подключения или диагностику задержек.
2. **Взаимодействие**: Навык использует API супервизора (по умолчанию `http://localhost:8104/api/cloudflared/*`).
3. **Безопасность**: Навык предоставляет данные телеметрии и диагностики, не требуя прав на изменение конфигурации туннелей.

## 🛠️ Основные команды
- `check_tunnel_health`: Проверка статуса и здоровья туннеля.
- `analyze_logs`: Анализ логов туннеля на предмет ошибок.
- `probe_endpoint`: Измерение задержки (latency) до публичного эндпоинта.

## ⚠️ Важное замечание
Навык требует запущенного `cloudflared_monitor` для получения данных в реальном времени.
