# Навык: System Control

## 🎯 Назначение
Навык `system-control` обеспечивает взаимодействие с центром управления системой (`apps/system_control_center`). Предназначен для выполнения задач по настройке после установки, создания снимков состояния системы, обслуживания (DISM/SFC) и управления безопасностью (Defender, Firewall).

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на обслуживание системы, настройку параметров или устранение конфигурационного дрейфа (drift).
2. **Взаимодействие**: Навык использует API центра управления (по умолчанию `http://localhost:8109/api/system-control/*`).
3. **Безопасность**: Административные задачи требуют подтверждения и прав администратора.

## 🛠️ Основные команды
- `take_snapshot`: Создание снимка текущего состояния конфигурации.
- `maintenance_task`: Запуск процедур обслуживания (DISM, SFC, cleanup).
- `run_setup_profile`: Запуск профиля настройки системы.

## ⚠️ Важное замечание
Навык предназначен для выполнения системных операций, требующих прав администратора, и должен использоваться с осторожностью.
