# Навык: Windows Admin Toolkit

## 🎯 Назначение
Навык `windows-admin-toolkit` обеспечивает взаимодействие с приложением системного администратора Windows (`apps/windows_sysadmin`). Предназначен для управления Active Directory, мониторинга сессий пользователей и анализа событий безопасности.

## 🚀 Протокол выполнения
1. **Активация**: Навык активируется при запросах на управление учетными записями, аудит безопасности или настройку системных параметров.
2. **Взаимодействие**: Навык использует API терминала администрирования (по умолчанию `http://localhost:8100/api/v1/windows-admin/*`).
3. **Безопасность**: Все административные действия (изменение прав, блокировка пользователей) требуют подтверждения пользователя.

## 🛠️ Основные команды
- `manage_user_sessions`: Мониторинг и завершение сессий пользователей.
- `audit_security_events`: Получение сводки событий безопасности.
- `ad_operations`: Выполнение базовых операций в Active Directory.

## ⚠️ Важное замечание
Навык требует прав администратора для работы с компонентами Windows и должен использоваться внутри доверенной среды.
