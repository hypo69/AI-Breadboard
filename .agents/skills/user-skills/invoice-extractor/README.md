# Invoice Extractor

## Overview
Extracts structured invoice and receipt metadata from images and PDF documents, and synchronizes the results into Google Sheets.

## Localization (i18n)
- **English**: Extracts structured invoice and receipt metadata from images and PDF documents, and synchronizes the results into Google Sheets.
- **Russian**: Извлекает структурированные данные из счетов и квитанций (PDF и изображения) с помощью OCR и ИИ, и сохраняет их в Google Таблицы.
