# Аудит USB устройств (USB Device Auditor)

## 🎯 Назначение (Purpose)
Проверка полного списка активных и зарегистрированных USB контроллеров, накопителей и периферии в Windows.

## 🚀 Триггеры и применение (When to Use & Triggers)
Используется при запросах пользователя о системном оборудовании, истории подключений и экспресс-диагностике в интерфейсе Test Computer (/tc) и консоли.

## ⚙️ Протокол выполнения (Execution Protocol)
1. Выполнить опрос PnP с фильтром по InstanceId 'USB*' и классу USB.
2. Разделить на активные и исторические.
3. Определить вендоров по VID.
