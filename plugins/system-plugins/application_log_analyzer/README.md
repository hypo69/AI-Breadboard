# Application Log Analyzer Plugin

## Обзор
Плагин `application_log_analyzer` расширяет панель администрирования AI Breadboard инструментами диагностики логов нашего приложения, кластеризации ошибок и ИИ-анализа первопричин с помощью Google Gemini.

## Возможности
- **Интеграция с админ-панелью**: автоматически отображается в `/api/admin/plugins` с элементами управления действиями и формой конфигурации.
- **Доступные действия**:
  - **Full Analysis**: сканирует и подсчитывает все события в активных логах приложения.
  - **Error Filter**: выделяет и группирует только события уровней `ERROR` и `CRITICAL`.
  - **AI Diagnostics**: проводит ИИ-синтез ошибок через Google Gemini и формирует план исправления.
  - **Rotate & Clean Logs**: ротация и очистка устаревших или переполненных файлов логов.
- **Настройки**: фильтр уровней, лимит чтения строк, автоматическое сохранение отчётов и переключатель ИИ.
- **Инструменты LLM (Function Calling)**: экспортирует инструмент `analyze_application_logs`.

## Пример конфигурации
```json
{
  "enabled": true,
  "log_level": "ALL",
  "tail_lines": 500,
  "enable_ai_synthesis": true,
  "auto_save_report": true
}
```
