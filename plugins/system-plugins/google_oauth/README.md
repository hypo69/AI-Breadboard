# Google OAuth System Plugin

Системный плагин платформы AI-Breadboard для централизованного управления авторизацией Google OAuth 2.0 и Service Account ключами.

## Возможности
- Пул аккаунтов Google Workspace
- Автоматический refresh токенов
- Безопасное хранение в `src/secrets/`
- Административный API (`/api/admin/google-accounts`)
