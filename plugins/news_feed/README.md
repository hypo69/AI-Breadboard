# Smart News Feed Plugin

## Overview
The `news_feed` plugin provides intelligent, personalized news aggregation, continuous user interest profile learning, AI summarization, and interactive digest generation for AI Breadboard.

## Key Features
- **Adaptive Personalization**: Learns user preferences dynamically through explicit signals (likes, dislikes, bookmarks, hides).
- **Multi-Source RSS Aggregator**: Built-in support for tech, science, AI, and global news feeds, with customizable user feeds.
- **LLM Function Calling**: Exposes `get_smart_news` and `generate_news_digest` tools for autonomous agents.
- **AI TL;DR Generation**: Crisp 2-sentence takeaways generated on-demand.
