🌐 Провайдеры веб-поиска (MCP)

Управление серверами интернет-поиска, алгоритмами извлечения и тестирование выдачи.

Активный движок поиска:
Справка: архитектура и принципы работы 5 серверов веб-поиска
🎭 Playwright MCP
Прямой headless-браузер (Chromium).
  • Поиск в DuckDuckGo, Bing и Google.
  • Глубокий сбор DOM-структуры и текста сайтов.
  • Плюс: не расходует токены ИИ на сбор данных.
  • Особенность: требует запущенного Playwright.
🦜 LangChain MCP
Автономный ReAct-агент Breadboard.
  • Инструменты: веб-поиск, RAG, Python-вычисления.
  • Агент сам принимает решение о вызове инструментов.
  • Плюс: гибкое решение комплексных задач.
  • Особенность: многошаговый reasoning-цикл.
♊ Google Gemini Grounding
Официальный Google Search Grounding.
  • Прямой поиск в реальном индексе Google Search.
  • Автоматическая ротация пула ключей при ошибках 429.
  • Плюс: проверенная точность фактов и цитаты.
  • Особенность: требует валидных API-ключей.
💻 Google Gemini CLI
Локальный терминальный агент Google.
  • Прямое выполнение через CLI подпроцесс.
  • Встроенные агентные инструменты веб-поиска.
  • Плюс: автономный агент, модель по умолчанию flash-lite.
  • Особенность: требует установленной утилиты gemini CLI.
🚀 Antigravity (AGY)
Мультиагентный поиск платформы Google.
  • Инструменты SEARCH_WEB и READ_URL_CONTENT.
  • Глубокий ресерч и синтез сложных многоходовок.
  • Плюс: автономный агентный цикл.
  • Особенность: использует Antigravity SDK / CLI.
Параметры поисковых модулей
Gemini Grounding
Ключи автоматически считываются из вкладки «Модели и API» и ротируются по кругу.
Google Gemini CLI
Использует локальную утилиту gemini с автоматическим вызовом поисковых инструментов.
Antigravity (AGY) Search
Использует встроенные агентные инструменты SEARCH_WEB и READ_URL_CONTENT.
Интерактивный тест поиска playwright
Введите запрос и нажмите «Искать» для проверки выбранного провайдера.
