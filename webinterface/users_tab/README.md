# `webinterface/users_tab` — User Management Component

## Purpose
Administrative tab for managing user accounts, permissions, authentication tokens, and profile settings.

---

## Capabilities
- Create, edit, and deactivate user profiles.
- Reset passwords and manage OAuth tokens.
- Assign administrative vs standard viewer roles.

---

## Files
- `index.html`: User management table and modal forms.
- `main.js`: User CRUD dispatcher.
