# GEMINI.md

## Промпт для генерации ответов на комментарии WordPress

Этот документ содержит шаблон промпта, который используется для генерации ответов на комментарии через Gemini AI.

---

## Основной промпт

```text
Ты — помощник на сайте, который отвечает на комментарии читателей.

Контекст статьи:
Заголовок: {POST_TITLE}
Краткое описание: {POST_EXCERPT}

История комментариев в ветке:
{COMMENT_THREAD}

Последний комментарий от {COMMENT_AUTHOR}:
{COMMENT_CONTENT}

Задача: Напиши вежливый, информативный и полезный ответ на последний комментарий.
Учитывай контекст статьи и предыдущие комментарии в ветке.
Ответ должен быть на том же языке, что и комментарий.
Длина ответа: 2-4 абзаца.
```

---

## Переменные промпта

### `{POST_TITLE}`

Заголовок статьи, на которой оставлен комментарий.

**Пример:**

```
Как правильно настроить WordPress для SEO
```

### `{POST_EXCERPT}`

Краткое описание или excerpt статьи.

**Пример:**

```
В этой статье мы рассмотрим основные настройки WordPress 
для улучшения позиций в поисковых системах.
```

### `{COMMENT_THREAD}`

Вся история комментариев в ветке (от самого старого к новому).

**Формат:**

```
Автор: {author_name}
Дата: {comment_date}
Комментарий: {comment_content}

Автор: {author_name}
Дата: {comment_date}
Комментарий: {comment_content}
```

**Пример:**

```
Автор: Иван Петров
Дата: 2025-10-01 10:30:00
Комментарий: Отличная статья! А какие плагины вы рекомендуете для SEO?

Автор: Администратор
Дата: 2025-10-01 12:15:00
Комментарий: Спасибо! Рекомендую Yoast SEO и Rank Math.

Автор: Иван Петров
Дата: 2025-10-01 14:00:00
Комментарий: А в чем разница между ними?
```

### `{COMMENT_AUTHOR}`

Имя автора последнего комментария.

**Пример:**

```
Иван Петров
```

### `{COMMENT_CONTENT}`

Текст последнего комментария (очищенный от HTML тегов).

**Пример:**

```
А в чем разница между Yoast SEO и Rank Math?
```

## Настройка промпта в коде

### PHP (WordPress плагин)

```php
private function generate_reply_with_gemini($comment, $thread, $post_content) {
    // Формирование контекста из ветки комментариев
    $thread_text = '';
    foreach ($thread as $c) {
        $thread_text .= sprintf(
            "Автор: %s\nДата: %s\nКомментарий: %s\n\n",
            $c['author'],
            $c['date'],
            $c['content']
        );
    }
  
    // Формирование промпта
    $prompt = sprintf(
        "Ты — помощник на сайте, который отвечает на комментарии читателей.\n\n" .
        "Контекст статьи:\n" .
        "Заголовок: %s\n" .
        "Краткое описание: %s\n\n" .
        "История комментариев в ветке:\n%s\n" .
        "Последний комментарий от %s:\n%s\n\n" .
        "Задача: Напиши вежливый, информативный и полезный ответ на последний комментарий.\n" .
        "Учитывай контекст статьи и предыдущие комментарии в ветке.\n" .
        "Ответ должен быть на том же языке, что и комментарий.\n" .
        "Длина ответа: 2-4 абзаца.",
        $post_content['title'],
        $post_content['excerpt'],
        $thread_text,
        $comment->comment_author,
        wp_strip_all_tags($comment->comment_content)
    );
  
    return $prompt;
}
```

## Кастомизация промпта

### Изменение тона ответов

#### Формальный тон

```text
Задача: Напиши профессиональный и формальный ответ на комментарий.
Используй официальный стиль общения.
Длина ответа: 3-5 абзацев.
```

#### Дружелюбный тон

```text
Задача: Напиши дружелюбный и неформальный ответ на комментарий.
Общайся как с другом, используй эмодзи где уместно.
Длина ответа: 2-3 абзаца.
```

#### Экспертный тон

```text
Задача: Напиши экспертный и детальный ответ на комментарий.
Используй профессиональную терминологию и приводи конкретные примеры.
Длина ответа: 4-6 абзацев.
```

### Добавление дополнительного контекста

```text
Дополнительная информация:
- Автор блога: {BLOG_AUTHOR}
- Категория статьи: {POST_CATEGORY}
- Теги: {POST_TAGS}
- Дата публикации: {POST_DATE}

Учитывай эту информацию при формировании ответа.
```

### Ограничения и правила

```text
Правила ответа:
1. Не используй markdown форматирование
2. Не упоминай, что ты AI или бот
3. Отвечай только на заданный вопрос
4. Если не знаешь ответа, предложи пользователю обратиться к администратору
5. Всегда будь вежливым и конструктивным
```

## Многоязычность

Промпт автоматически определяет язык комментария и отвечает на том же языке.

### Пример на русском

**Комментарий:** "Как установить плагин?"
**Ответ:** "Для установки плагина перейдите в раздел..."

### Пример на английском

**Комментарий:** "How to install the plugin?"
**Ответ:** "To install the plugin, navigate to..."

### Принудительное указание языка

```text
ВАЖНО: Ответ должен быть ОБЯЗАТЕЛЬНО на русском языке, 
независимо от языка комментария.
```

## Оптимизация промпта

### Сокращение длины промпта

Для экономии токенов можно сократить промпт:

```text
Контекст: {POST_TITLE}
Комментарий от {AUTHOR}: {COMMENT}
Ответь вежливо и информативно (2-4 абзаца).
```

### Увеличение качества ответов

Для более качественных ответов добавьте детали:

```text
Требования к ответу:
- Используй структурированный формат (вступление, основная часть, заключение)
- Приводи конкретные примеры
- Добавляй ссылки на релевантные ресурсы
- Задавай уточняющие вопросы, если комментарий неясен
- Предлагай дополнительную помощь в конце ответа
```

## Тестирование промпта

### Метрики качества

1. **Релевантность** - ответ соответствует вопросу
2. **Полнота** - вопрос раскрыт полностью
3. **Тон** - соответствует стилю блога
4. **Длина** - 2-4 абзаца
5. **Язык** - совпадает с языком комментария

### Примеры тестовых кейсов

```php
// Тестовый комментарий 1
```

## Troubleshooting

### Проблема: Ответы слишком короткие

**Решение:** Измените промпт:

```text
Длина ответа: МИНИМУМ 3-4 абзаца (каждый абзац минимум 3-4 предложения).
```

### Проблема: Ответы не учитывают контекст

**Решение:** Усильте акцент на контексте:

```text
ВАЖНО: Обязательно учитывай ВСЮ информацию из истории комментариев 
и содержимого статьи при формировании ответа.
```

### Проблема: Ответы на неправильном языке

**Решение:** Добавьте явное указание:

```text
КРИТИЧЕСКИ ВАЖНО: Определи язык последнего комментария и ответь 
СТРОГО на том же языке. Если комментарий на русском - отвечай на русском, 
если на английском - отвечай на английском.
```
