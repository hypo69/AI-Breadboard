# Installation & Setup Guide: AI Responder

This guide explains how to install the **AI Responder** plugin on your WordPress website (`davidka.net`), create a dedicated bot user, and connect it to your central **AI-Breadboard** (`kino.davidka.net`).

---

## 1. Create a Dedicated WordPress User for the AI Bot

1. Log in to your WordPress Admin Dashboard (`https://davidka.net/wp-admin`).
2. Navigate to **Users → Add New**.
3. Fill in user details:
   - **Username:** `davidka-ai` (or `ai-assistant`)
   - **Email:** `ai@davidka.net` (or any valid email)
   - **First Name / Nickname:** `AI Assistant`
   - **Display name publicly as:** `AI Assistant` (or `Davidka Bot`)
   - **Role:** `Author` or `Subscriber`
4. Set an avatar via Gravatar or a local avatar plugin (e.g. upload a nice robot or assistant avatar).
5. Note the **User ID** of this newly created user.

---

## 2. Install / Deploy the Plugin

### Method A: Direct Upload via FTP / SSH
1. Copy the folder `wp/wp-content/plugins/ai-responder` into your server's WordPress installation under `/wp-content/plugins/ai-responder`.
2. In WordPress Admin, navigate to **Plugins → Installed Plugins**.
3. Locate **AI Responder for davidka.net** and click **Activate**.

### Method B: As a ZIP archive
1. Compress the `ai-responder` folder into `ai-responder.zip`.
2. Go to **Plugins → Add New → Upload Plugin**, choose the ZIP file, and click **Install Now**.
3. Activate the plugin.

---

## 3. Configure the Plugin

1. In WordPress Admin, go to **Settings → AI Responder**.
2. Configure the following fields:
   - **Status:** Check ✅ **Enable AI Auto-Replies**.
   - **AI Backend Endpoint:** `https://kino.davidka.net/api/chat/comment-responder`
   - **Model Name:** `gemini-2.5-flash` (or your preferred model on Breadboard).
   - **Provider:** `Google Gemini` (or `Microsoft Foundry Local`, `Ollama`, etc.).
   - **Bot User Account:** Select your newly created dedicated user (`AI Assistant`).
   - **Reply Delay:** `10` to `20` seconds.
   - **System Prompt:** Adjust persona or guidelines as desired.
3. Click **Save Settings**.

---

## 4. Verify & Test Connection

1. On the **Settings → AI Responder** page, scroll to **5. Test Connection to AI-Breadboard**.
2. Click **▶️ Test Connection**.
3. You should see a green confirmation badge with the response generated by AI-Breadboard.
4. Leave a test comment on any blog post to verify end-to-end automatic asynchronous replying.
