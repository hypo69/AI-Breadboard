# 🔍 PixelRAG: FAISS-Based Visual Search Provider\n\n## Overview\n\nThe `PixelRAG` class is the search provider that ties together the renderer and embedder components. It:\n\n- **Indexes** images using FAISS\n- **Searches** using semantic similarity\n- **Maintains** metadata and deduplication\n- **Exports** indices for deployment\n- **Compatible** with DocumentRAGManager interface\n\n---\n\n## Architecture\n\n### Pipeline Flow\n\n```\nRendered Tiles (from Renderer)\n        ↓\n[PixelRAG.add_documents()]\n        ↓\nPixelEmbedder (batch encode)\n        ↓\nFAISS Index (FlatL2)\n        ↓\n[PixelRAG.search()]\n        ↓\nSimilarity Results\n```\n\n### FAISS Index Structure\n\n```\nPixelRAG Index\n├── index.faiss              # Binary FAISS index\n├── metadata.json            # Embedding metadata\n├── chunks.jsonl             # Document chunks (one per line)\n└── info.json                # Index statistics\n\nStorage Layout:\n  documents[0] → vector[0] ──┐\n  documents[1] → vector[1] ──┤\n  documents[2] → vector[2] ──┼─→ FAISS Index\n  documents[3] → vector[3] ──┤   (Efficient search)\n  documents[N] → vector[N] ──┘\n```\n\n### Key Interfaces\n\n**DocumentRAGManager Compatible:**\n```python\n# Standard interface used by DocumentRAGManager\nawait pixel_rag.add_documents(docs)      # Index documents\nresults = await pixel_rag.search(query)  # Semantic search\nstats = pixel_rag.get_index_stats()      # Get metadata\n```\n\n---\n\n## Usage Examples\n\n### Example 1: Basic Indexing and Path(\"data/rag_index/pixel_rag\"),\n    embedder: Optional[PixelEmbedder] = None,\n    index_type: str = \"FlatL2\"\n)\n```\n\n**Parameters:**\n- `index_dir`: Directory for storing index files\n- `embedder`: Custom embedder (creates new if None)\n- `index_type`: \"FlatL2\" (default) or \"IVF\" (for large datasets)\n\n---\n\n### add_documents(documents) → int\n\n**Index documents with images.**\n\n**Parameters:**\n- `documents`: List of document dicts with `id`, `text`, `meta` fields\n\n**Returns:**\n- Number of documents indexed\n\n**Example:**\n```python\ncount = await pixel_rag.add_documents([\n    {'id': 'doc1', 'text': 'image.png', 'meta': {...}}\n])\n```\n\n---\n\n### search(query, top_k, threshold) → List[Dict]\n\n**Semantic search for images matching text query.**\n\n**Parameters:**\n- `query`: Text query (e.g., \"Where is the save button?\")\n- `top_k`: Number of results (default: 5)\n- `threshold`: Min similarity (unused for L2 distance)\n\n**Returns:**\n- List of results with `id`, `text`, `score`, `meta`\n\n**Example:**\n```python\nresults = await pixel_rag.search(\n    query=\"Configuration settings\",\n    top_k=5\n)\n```\n\n---\n\n### search_image(image_source, top_k) → List[Dict]\n\n**Find similar images (image-to-image search).**\n\n**Parameters:**\n- `image_source`: Path to query image\n- `top_k`: Number of results\n\n**Returns:**\n- List of similar images with scores\n\n**Example:**\n```python\nresults = await pixel_rag.search_image(\n    image_source='reference.png',\n    top_k=5\n)\n```\n\n---\n\n### get_index_stats() → Dict\n\n**Get index statistics.**\n\n**Returns:**\n```python\n{\n    'total_vectors': 1000,\n    'total_chunks': 1000,\n    'index_type': 'FlatL2',\n    'dimension': 512,\n    'memory_mb': 2.0,\n    'model': 'sentence-transformers/clip-ViT-B-32'\n}\n```\n\n---\n\n### delete_documents(source_ids) → int\n\n**Mark documents as deleted.**\n\n**Parameters:**\n- `source_ids`: List of source IDs to delete\n\n**Returns:**\n- Number of documents marked for deletion\n\n**Note:** Call `rebuild_index()` to physically remove.\n\n---\n\n### rebuild_index() → None\n\n**Rebuild index (remove deleted documents).**\n\n**Example:**\n```python\nawait pixel_rag.delete_documents(['doc1'])\nawait pixel_rag.rebuild_index()  # Actually removes\n```\n\n---\n\n### export_index(export_path) → None\n\n**Export index for deployment.**\n\n**Example:**\n```python\nawait pixel_rag.export_index(Path('dist/index'))\n```\n\n---\n\n### cleanup() → None\n\n**Save and cleanup resources.**\n\n**Example:**\n```python\nawait pixel_rag.cleanup()\n```\n\n---\n\n## Performance Characteristics\n\n### Indexing Speed\n\n```\n┌──────────────────────────────┐\n│ Batch Size │ Time per Image │\n├────────────┼────────────────┤\n│ 1 image    │ 0.9 sec        │\n│ 4 images   │ 0.8 sec        │\n│ 10 images  │ 0.85 sec       │\n└──────────────────────────────┘\n```\n\n### Search Speed (FAISS FlatL2)\n\n```\n┌────────────────────────────┐\n│ Index Size │ Query Time    │\n├────────────┼───────────────┤\n│ 100 docs   │ <1 ms         │\n│ 1000 docs  │ 5 ms          │\n│ 10000 docs │ 50 ms         │\n│ 100000 docs│ 500 ms        │\n└────────────────────────────┘\n```\n\n### Memory Usage\n\n```\nPer document: ~2 KB (metadata)\nPer vector: ~2 KB (512 dims × 4 bytes)\nTotal: 4 KB per indexed image\n\nExample:\n- 1000 images: ~4 MB vectors + 2 MB metadata = 6 MB\n- 10000 images: ~40 MB vectors + 20 MB metadata = 60 MB\n```\n\n---\n\n## File Structure\n\n### Index Directory Layout\n\n```\ndata/rag_index/pixel_rag/\n├── index.faiss           # FAISS binary index\n├── metadata.json         # Embedding metadata (dict)\n├── chunks.jsonl          # Chunks (one JSON per line)\n├── info.json             # Index statistics\n└── models/\n    └── vision/\n        └── clip-ViT-B-32/  # Model cache\n            ├── config.json\n            ├── pytorch_model.bin\n            └── ...\n```\n\n### Chunk Format (JSONL)\n\n```json\n{\n  \"chunk_id\": \"doc_123_page_5\",\n  \"source_id\": \"doc_123\",\n  \"source_path\": \"/path/to/image.png\",\n  \"source_type\": \"pixel\",\n  \"embedding_id\": \"img_abc123def456\",\n  \"index_position\": 0,\n  \"vector_index\": 0,\n  \"timestamp\": 1695384000.0,\n  \"meta\": {\n    \"page_number\": 5,\n    \"image_size\": [1024, 768],\n    \"source\": \"pdf\"\n  }\n}\n```\n\n---\n\n## Integration Points\n\n### With DocumentRAGManager (Task 6)\n\n```python\n#
