# 🧠 PixelEmbedder: Visual Embedding Engine\n\n## Overview\n\nThe `PixelEmbedder` class implements semantic embedding generation for images using **CLIP ViT-B/32**. It provides:\n\n- ✅ **Cross-modal embeddings** — Same 512-dimensional space for images and text\n- ✅ **CPU-optimized** — Designed for Windows laptop inference\n- ✅ **Batch processing** — Memory-efficient processing of multiple images\n- ✅ **Caching** — Avoid re-computing identical embeddings\n- ✅ **Similarity search** — Fast cosine similarity matching\n- ✅ **Async/await** — Non-blocking operations\n\n---\n\n## Architecture\n\n### Data Structures\n\n#### EmbeddingMetadata\n\n```python\n@dataclass\nclass EmbeddingMetadata:\n    embedding_id: str           # Unique ID\n    source_type: str            # 'image' or 'text'\n    source_content: str         # File path or text\n    model_name: str             # Model used\n    embedding_dim: int          # 512 for CLIP\n    timestamp: float            # Creation time\n    content_hash: str           # For deduplication\n    cached: bool                # From cache?\n    meta: Dict[str, Any]        # Custom metadata\n```\n\n#### ImageEmbedding\n\n```python\n@dataclass\nclass ImageEmbedding:\n    embedding_id: str           # Unique ID\n    vector: np.ndarray          # (512,) float32 normalized\n    metadata: EmbeddingMetadata # Associated metadata\n```\n\n### Processing Pipeline\n\n```\nInput Image\n    ↓\n[Load PIL Image]\n    ↓\n[Compute Content Hash]\n    ↓\n[Check Cache] ──[HIT]──→ Return cached embedding\n    │\n  [MISS]\n    │\n    ↓\n[CLIP ViT-B/32 Encoding]\n    ↓\n[L2 Normalization]\n    ↓\n[Cache Result]\n    ↓\nReturn (512,) float32 vector\n```\n\n---\n\n## Usage Examples\n\n### embedding\n3. **Lazy Caching**: Results cached after first computation\n4. **Persistent Cache**: Metadata saved to disk between sessions\n\n### Cache Files\n\n```\nmodels/vision/\n├── clip-ViT-B-32/          # Downloaded model\n│   ├── config.json\n│   ├── pytorch_model.bin\n│   └── ...\n├── embeddings_metadata.json # Cached metadata\n└── embeddings_cache.json    # Cached vectors (optional)\n```\n\n### Cache Statistics\n\n```python\nstats = embedder.get_cache_stats()\nprint(stats)\n# Output:\n# {\n#     'cached_embeddings': 142,\n#     'memory_usage_mb': 0.28,\n# PixelEmbedder Methods\n\n#### `embed_image(image, embedding_id=None, use_cache=True) → ImageEmbedding`\n\nGenerate embedding for single image.\n\n**Parameters:**\n- `image`: PIL Image, file path, or path string\n- `embedding_id`: Optional custom ID\n- `use_cache`: Use cached result if available\n\n**Returns:**\n- `ImageEmbedding`: Complete embedding with metadata\n\n**Example:**\n```python\nemb = await embedder.embed_image('photo.jpg')\n```\n\n---\n\n#### `embed_text(text, embedding_id=None, use_cache=True) → np.ndarray`\n\nGenerate embedding for text query.\n\n**Parameters:**\n- `text`: Text string to embed\n- `embedding_id`: Optional custom ID\n- `use_cache`: Use cached result if available\n\n**Returns:**\n- `np.ndarray`: (512,) normalized vector\n\n**Example:**\n```python\nvec = await embedder.embed_text(\"Where is the save button?\")\n```\n\n---\n\n#### `embed_batch(images, batch_size=None, use_cache=True) → List[ImageEmbedding]`\n\nGenerate embeddings for multiple images efficiently.\n\n**Parameters:**\n- `images`: List of PIL Images or file paths\n- `batch_size`: Override default batch size\n- `use_cache`: Use cache\n\n**Returns:**\n- `List[ImageEmbedding]`: All embeddings\n\n**Example:**\n```python\nembs = await embedder.embed_batch(image_paths)\n```\n\n---\n\n#### `similarity_search(query_vector, candidates, top_k=5) → List[(int, float)]`\n\nFind most similar embeddings using cosine similarity.\n\n**Parameters:**\n- `query_vector`: Query embedding (512,)\n- `candidates`: Candidate embeddings (N, 512)\n- `top_k`: Number of results\n\n**Returns:**\n- `List[(index, score)]`: Top-k results with similarity scores\n\n**Example:**\n```python\nresults = embedder.similarity_search(query_vec, candidates, top_k=5)\n```\n\n---\n\n#### `get_cache_stats() → Dict`\n\nGet cache statistics.\n\n**Returns:**\n- `Dict`: Cache and model stats\n\n**Example:**\n```python\nstats = embedder.get_cache_stats()\nprint(f\"Cached: {stats['cached_embeddings']}\")\n```\n\n---\n\n#### `clear_cache() → None`\n\nClear in-memory cache.\n\n**Example:**\n```python\nembedder.clear_cache()\n```\n\n---\n\n#### `cleanup() → None`\n\nSave cache and cleanup resources (async).\n\n**Example:**\n```python\nawait embedder.cleanup()\n```\n\n---\n\n## Troubleshooting\n\n### Issue: \"sentence-transformers not available\"\n\n```bash\npip
