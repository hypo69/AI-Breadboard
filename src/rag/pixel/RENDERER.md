# 🎨 TileRenderer: Image Extraction Component for PixelRAG\n\n## Overview\n\nThe `renderer.py` module provides a unified interface for extracting image tiles from multiple document sources:\n\n- **PDF Files** → Pages rendered as images\n- **Web URLs** → Full-page screenshots\n- **Local Images** → Processed and resized\n\n---\n\n## Architecture\n\n### Class Hierarchy\n\n```\nTileRenderer (Abstract Base Class)\n├── PDFTileRenderer\n│   └── pdf2image (external dependency)\n├── WebScreenshotRenderer\n│   └── playwright (async browser)\n└── LocalImageRenderer\n    └── PIL (built-in)\n\nRendererFactory (Factory Pattern)\n└── Auto-detects source type and creates appropriate renderer\n```\n\n### Data Structures\n\n#### RenderedTile\n\n```python\n@dataclass\nclass RenderedTile:\n    tile_id: str                      # Unique identifier\n    source_type: str                  # 'pdf', 'web', 'local_image'\n    source_path: str                  # Original file path or URL\n    page_number: Optional[int]        # For PDF pages\n    image: Optional[Image.Image]      # PIL Image (in-memory)\n    image_size: Tuple[int, int]       # (width, height)\n    timestamp: float                  # Creation time\n    error: Optional[str]              # Error message if failed\n```\n\n---\n\n## Renderers\n\n### 1. PDFTileRenderer\n\n**Purpose:** Extract PDF pages as image tiles\n\n**Dependencies:**\n```bash\npip install pdf2image pillow\n# Also requires: poppler (system package)\n```\n\n**Features:**\n- ✅ Text and scanned PDFs\n- ✅ Custom DPI for quality control\n- ✅ Page range selection\n- ✅ Automatic error handling\n- ⚠️ Requires Poppler system dependency\n\n**Usage:**\n\n```python\nimport asyncio\nfrom pathlib import Path\nfrom src.rag.pixel.renderer import PDFTileRenderer\n\n# Initialize\nrenderer = PDFTileRenderer(\n    tile_size=(1024, 1024),\n    dpi=150,              # Higher DPI = better quality, slower\n    max_pages=None        # Process all pages\n)\n\n# Render\ntiles = await renderer.render(Path('document.pdf'))\n\n# Access tiles\nfor tile in tiles:\n    print(f\"Tile: {tile.tile_id}\")\n    print(f\"  Page: {tile.page_number}\")\n    print(f\"  Size: {tile.image_size}\")\n    print(f\"  Type: {tile.source_type}\")\n    \n    # Save tile to disk if needed\n    tile.image.save(f\"tiles/{tile.tile_id}.png\")\n```\n\n**Performance:**\n- Speed: 0.5-1.5 sec per page (depends on DPI and content)\n- Memory: ~200 MB per batch of 4 pages\n- Quality: Higher DPI = larger file sizes\n\n**System Requirements:**\n\n```bash\n# macOS\nbrew install poppler\n\n# Ubuntu/Debian\napt-get install poppler-utils\n\n# Windows\nchoco install poppler\n# Or download from: https://github.com/oschwartz10612/poppler-windows/releases/\n```\n\n---\n\n### 2. WebScreenshotRenderer\n\n**Purpose:** Render web URLs to full-page screenshots\n\n**Dependencies:**\n```bash\npip install playwright\nplaywright install chromium\n```\n\n**Features:**\n- ✅ Full-page screenshots (handles scrolling)\n- ✅ JavaScript rendering\n- ✅ Network wait conditions\n- ✅ Async/await support\n- ✅ Timeout handling\n\n**Usage:**\n\n```python\nimport asyncio\nfrom src.rag.pixel.renderer import WebScreenshotRenderer\n\nasync def render_website():\n    renderer = WebScreenshotRenderer(\n        tile_size=(1024, 1024),\n        timeout_sec=30,\n        wait_until=\"networkidle\"  # Wait for network to idle\n    )\n    \n    tiles = await renderer.render('https://example.com/docs')\n    \n    for tile in tiles:\n        print(f\"Screenshot: {tile.tile_id}\")\n        print(f\"  URL: {tile.source_path}\")\n        print(f\"  Size: {tile.image_size}\")\n        tile.image.save(f\"screenshots/{tile.tile_id}.png\")\n\n# Run async\nasyncio.run(render_website())\n```\n\n**Performance:**\n- Speed: 5-15 sec per URL (browser startup + render)\n- Memory: ~500 MB for Chromium + page\n- Quality: Native browser rendering\n\n**Wait Conditions:**\n\n| Condition | Meaning | Use Case |\n|-----------|---------|----------|\n| `load` | Page `load` event | Fast pages |\n| `domcontentloaded` | DOM ready | Interactive content |\n| `networkidle` | No network activity | Fully loaded pages |\n\n---\n\n### 3. LocalImageRenderer\n\n**Purpose:** Process local image files\n\n**Supported Formats:**\n- PNG, JPEG, GIF, WebP, BMP, TIFF\n\n**Features:**\n- ✅ EXIF rotation correction\n- ✅ Format auto-detection\n- ✅ Batch processing\n- ✅ Fast (single-threaded)\n\n**Usage:**\n\n```python\nimport asyncio\nfrom pathlib import Path\nfrom src.rag.pixel.renderer import LocalImageRenderer\n\n# Single image\nrenderer = LocalImageRenderer(\n    tile_size=(1024, 1024),\n    auto_rotate=True  # Fix EXIF rotation\n)\n\ntile = await renderer.render(Path('screenshot.png'))\n\n# Batch processing\ntiles = await renderer.render_batch(\n    Path('images/'),\n    recursive=True  # Include subdirectories\n)\n\nprint(f\"Processed {len(tiles)} images\")\n```\n\n**Performance:**\n- Speed: <0.1 sec per image (very fast)\n- Memory: Minimal (streaming)\n- Quality: Lossless (PNG) or configurable (JPEG)\n\n---\n\n## RendererFactory\n\n**Automatic Renderer Selection**\n\n```python\nfrom src.rag.pixel.renderer import RendererFactory\n\n# Auto-detect source type\ntiles = await RendererFactory.render('document.pdf')\ntiles = await RendererFactory.render('https://example.com')\ntiles = await RendererFactory.render('screenshot.png')\n\n# Or get renderer manually\nrenderer = RendererFactory.get_renderer('document.pdf')\nif renderer:\n    tiles = await renderer.render('document.pdf')\n```\n\n---\n\n## Common Workflows\n\n### Workflow 1: Index a Documentation PDF\n\n```python\nimport asyncio\nfrom pathlib import Path\nfrom src.rag.pixel.renderer import PDFTileRenderer\nimport numpy as np\nfrom PIL import Image\n\nasync def index_pdf_documentation():\n    # Filter successful tiles\n        valid_tiles = [t for t in tiles if t.error is None]\n        failed_tiles = [t for t in tiles if t.error is not None]\n        \n        if failed_tiles:\n            print(f\"\\nFailed {len(failed_tiles)} tiles:\")\n            for tile in failed_tiles:\n                print(f\"  - {tile.tile_id}: {tile.error}\")\n        \n        return valid_tiles\n        \n    except FileNotFoundError:\n        print(f\"Source not found: {source}\")\n        return []\n    except Exception as e:\n        print(f\"Rendering error: {e}\")\n        return []\n\n# Usage\ntiles = asyncio.run(safe_render('missing_file.pdf'))\nprint(f\"Valid tiles: {len(tiles)}\")\n```\n\n---\n\n## Performance Optimization\n\n### 1. Parallel Processing\n\n```python\nimport asyncio\nfrom pathlib import Path\nfrom src.rag.pixel.renderer import LocalImageRenderer\n\nasync def parallel_image_processing(image_dir: Path):\n    renderer = LocalImageRenderer()\n    \n    # Get all images\n    images = list(image_dir.glob('*.png'))\n    \n    # Process in parallel (limit concurrency)\n    semaphore = asyncio.Semaphore(4)  # Max 4 concurrent\n    \n    async def limited_render(image_path):\n        async with semaphore:\n            return await renderer.render(image_path)\n    \n    tasks = [limited_render(img) for img in images]\n    results = await asyncio.gather(*tasks)\n    \n    # Flatten results\n    all_tiles = [tile for result in results for tile in result]\n    return all_tiles\n```\n\n### 3.
