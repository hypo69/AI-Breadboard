# Вкладка «О Системе» (About System Tab)

Интерактивная панель подробной спецификации оборудования и операционного окружения хоста Windows.

## Возможности

- **Сводные KPI-карточки**: Отображение ключевых параметров ОС, версии Python, разрядности архитектуры, модели процессора, материнской платы, BIOS, объема и типа оперативной памяти, видеоадаптера и VRAM.
- **Иерархическое AIDA64-дерево оборудования**: Полноценная категоризация компонентов хоста с подробным списком параметров для каждого узла.
- **Интерактивный поиск и фильтрация**: Мгновенный поиск по названиям категорий, компонентов и значениям свойств.
- **Управление раскрытием**: Быстрое сворачивание и разворачивание всех узлов дерева спецификации.

## API эндпоинты

- `GET /api/v1/system/hardware` — получение иерархического дерева узлов оборудования (`List[HardwareNode]`).
- `GET /api/v1/system/summary` — получение текущей сводки по хосту, процессору, памяти и GPU.
