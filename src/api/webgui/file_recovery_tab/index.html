Восстановление данных с накопителей

R-Studio Technician — мощный комплекс для восстановления удалённых, повреждённых и отформатированных файлов с локальных и сетевых дисков, RAID-массивов, флеш-накопителей и виртуальных дисков.

Поддерживаемые файловые системы: NTFS, NTFS5, ReFS, FAT12/16/32, exFAT, HFS/HFS+, APFS, Ext2/Ext3/Ext4 FS, UFS.
Сценарии восстановления: Случайное удаление (Shift+Del), форматирование разделов, повреждение MBR/GPT, сбои питания, вирусные атаки, сбойные сектора.
Режим работы: Portable (не требует установки, запускается напрямую из \bin\R-Studio_Technician_9.5.191810_Portable\R-Studio_9.5.exe).
