# 🗂️ Вкладка «Восстановить удаленные файлы» (R-Studio Technician Portable)

## Описание
Вкладка для быстрого запуска и управления профессиональным комплексом восстановления данных **R-Studio Technician Portable** из локального каталога `\bin\R-Studio_Technician_9.5.191810_Portable\R-Studio_9.5.exe`.

## Функциональность
- **Проверка доступности бинарного файла:** Отображение наличия, версии и размера исполняемого файла R-Studio.
- **Запуск утилиты:** Прямой вызов исполняемого файла в среде Windows через FastAPI REST API (`/api/recovery/launch`).
- **Интеграция с навигацией:** Поддержка единой системы меню (`tc_menu_config.json`), горячих клавиш и жизненного цикла вкладок (`tab-core.js`).

## Структура файлов
- `index.html` — Разметка карточек, информации о файле и кнопки запуска.
- `main.js` — Клиентская логика взаимодействия с `/api/recovery/status` и `/api/recovery/launch`.
- `README.md` — Документация компонента.
