# Window Management Control Plane Web Tab

Интерактивный веб-интерфейс панели управления окнами и оболочкой Windows (**Window Management Control Plane**).

## 📋 Описание

Вкладка предоставляет веб-интерфейс для управления каталогом из **295 системных настроек OS-уровня** Windows, распределённых по 15 категориям.

### 🌟 Основные возможности:
1. **Единый каталог параметров (295 настроек)**:
   - Полная фильтрация по 15 категориям, уровням риска (Safe, Caution, Critical), типу бэкенда (Win32 SPI, Registry, DWM, Display, Policy) и области действия (User, Machine, Session).
   - Быстрый поиск в реальном времени по названию, ID, разделу реестра и SPI-константам.
2. **Два режима отображения**:
   - **Карточки (Cards View)** с контекстными виджетами для каждого типа данных (переключатели `bool`, спиннеры/слайдеры `int` с единицами измерения, выпадающие списки `enum`, цветовые палитры `color_rgb`).
   - **Таблица (Table View)** для плотного просмотра и пакетной работы.
3. **Безопасное применение и SafeOps**:
   - **Dry-Run (Предпросмотр)**: детальная симуляция изменений с отображением целевого вызова/ключа реестра до фактического применения.
   - **Пакетное применение (Batch Apply)**: сохранение группы параметров с возможностью автоматического создания точки восстановления Windows.
   - **Журнал изменений и откат (Rollback Audit)**: полная история транзакций с возможностью отката любого действия в 1 клик.
4. **Интеграция с восстановлением**:
   - Быстрое создание точек восстановления Windows через `WindowsSystemRestoreManager`.

## 📡 Поддерживаемые REST API эндпоинты

- `GET /api/v1/window-management/summary` — сводные метрики и счетчики.
- `GET /api/v1/window-management/catalog` — каталог 295 настроек с live-значениями.
- `GET /api/v1/window-management/settings/{id}` — получение текущего значения настройки.
- `POST /api/v1/window-management/settings/{id}/preview` — предпросмотр (dry-run).
- `POST /api/v1/window-management/settings/{id}/apply` — применение настройки.
- `POST /api/v1/window-management/batch-apply` — пакетное применение настроек.
- `GET /api/v1/window-management/history` — журнал аудита.
- `POST /api/v1/window-management/rollback/{change_id}` — откат изменения.
