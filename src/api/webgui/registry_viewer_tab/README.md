# 🗝️ Вкладка просмотра реестра (Registry Viewer Tab)

## Назначение
Интерактивный графический обозреватель системного реестра Windows для безопасного аудита параметров, конфигурации служб, автозагрузки, программного обеспечения и групповых политик.

## Возможности
- Навигация по всем основным корневым веткам:
  - `HKEY_LOCAL_MACHINE` (HKLM)
  - `HKEY_CURRENT_USER` (HKCU)
  - `HKEY_CLASSES_ROOT` (HKCR)
  - `HKEY_USERS` (HKU)
  - `HKEY_CURRENT_CONFIG` (HKCC)
- Быстрые системные закладки (Автозагрузка Run/RunOnce, Установленные программы x64/x86, Службы, Переменные среды, История UserAssist, Политики).
- Просмотр подразделов (Subkeys) и параметров с типами данных (`REG_SZ`, `REG_DWORD`, `REG_EXPAND_SZ`, `REG_MULTI_SZ`, `REG_BINARY`, `REG_QWORD`).
- Фильтрация параметров и значений в реальном времени.
- Быстрое копирование полного пути ключа в буфер обмена.

## API Эндпоинты
- `GET /api/registry/bookmarks` — список быстрых системных закладок.
- `GET /api/registry/key?hive=...&path=...` — чтение подразделов и параметров ключа.
- `GET /api/registry/search?hive=...&path=...&query=...` — поиск по реестру.
