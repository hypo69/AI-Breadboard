# Вкладка «Потребление ресурсов» (System & Hardware Inspector)

Интерактивная панель мониторинга аппаратной телеметрии, аппаратных сенсоров LibreHardwareMonitor, потока процессов хоста и AI-диагностики производительности.

## Структура интерфейса

- **Верхняя полоса KPI**: Загрузка CPU (%), оперативная память RAM (GB), видеоускоритель GPU, скорость дискового ввода-вывода Disk I/O (MB/s).
- **Левая панель**: **Сенсоры LibreHardwareMonitor** — температуры (°C с цветовой градацией), нагрузка, частоты (MHz), скорости вентиляторов (RPM / %) и вольтаж, с поддержкой фильтрации по категориям и текстового поиска.
- **Правая верхняя панель**: Живой поток процессов хоста (Live Stream) с возможностью сортировки, поиска и просмотра детальной AI-информации по каждому процессу.
- **Правая нижняя панель**: **AI Copilot** — эвристический и нейросетевой анализ аномалий и узких мест производительности системы.

> [!NOTE]
> Спецификация оборудования (характеристики процессора, материнской платы, BIOS, памяти и ОС) вынесена в отдельную специализированную вкладку **«О Системе»** (`about_system_tab`).

## API эндпоинты

- `GET /api/v1/system/summary` — текущий снимок телеметрии хоста.
- `GET /api/v1/system/processes` — список активных процессов с метриками CPU/RAM.
- `GET /api/v1/lhm/metrics` — список нормализованных метрик сенсоров LibreHardwareMonitor.
- `GET /api/v1/lhm/status` — статус доступности Web API LHM.
- `POST /api/v1/lhm/launch` — запуск процесса LibreHardwareMonitor.
- `GET /api/windows/hardware/sensors` / `GET /api/v1/system/sensors` — сбор сенсоров через fallback WMI / NVIDIA-SMI.
- `POST /api/v1/system/diagnose` — глубокий AI-аудит производительности.
- `WS /api/v1/system/stream` — WebSocket поток телеметрии в реальном времени.
