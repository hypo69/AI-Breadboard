**Status:** ✅ Active  
**Language:** English  
**Authors:** hypo69  

---

## 📋 Overview

The `system_inspector_tab` module integrates the standalone **System Inspector** application (`/apps/system_inspector`) into the administrative web interface. It provides comprehensive real-time telemetry streaming, an AIDA64-style collapsible hardware specification tree, a Wireshark-style host process monitor with search filters, and an AI-assisted bottleneck diagnostics copilot.

---

## 🚀 Key Features

- **Live Telemetry Stream:** WebSocket stream over `/api/v1/system/stream` updating CPU, RAM, GPU, and Disk I/O metrics.
- **Hardware Specification Tree:** Multi-category hardware tree generated by `/api/v1/system/hardware`.
- **Host Process Inspection:** Live list of top active processes with memory, CPU utilization, thread count, and user ownership.
- **AI Telemetry Copilot:** Automated bottleneck detection and system health scoring via `/api/v1/system/diagnose`.
