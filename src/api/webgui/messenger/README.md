# Messenger Web Interface & PWA Client

This directory contains the responsive web application, progressive web app (PWA), and embeddable widget for the AI Breadboard Messenger.

---

## 📁 Files

- `index.html`: Responsive Telegram/WhatsApp layout with chat streams, voice recorder, and WebRTC video meeting overlay.
- `style.css`: Modern glassmorphic styles with responsive breakpoints for desktop and mobile devices.
- `app.js`: Real-time WebSocket connection client, WebRTC peer connection manager, voice recorder, and UI renderers.
- `widget.js`: Zero-dependency floating widget launcher for external websites and WordPress.
- `manifest.json` & `sw.js`: PWA configuration enabling app installation and offline caching.
