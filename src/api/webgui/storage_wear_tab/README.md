# 💽 Storage & Battery Wear Tab (Износ дисков и батареи)

Вкладка оценки физического ресурса, здоровья и деградации аппаратных накопителей и батарей в Windows.

## 📋 Возможности
- **SSD/NVMe SMART & Wear**: Расчет процента износа и остаточного ресурса дисков, контроль файловых систем.
- **Battery Degradation Radar**: Сравнение заводской емкости (Design Capacity) и текущей (Full Charge Capacity) с расчетом процента деградации.
- **Power Source Identification**: Детекция типа питания (сеть AC Mains / батарея).
