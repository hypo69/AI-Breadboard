# 🔬 Вкладка: Исследования Телеметрии (Telemetry Research Tab)

Пользовательский интерфейс для аналитического исследования данных телеметрии системы и оборудования в составе платформы AI-Breadboard.

---

## 📌 Функциональность

- **Анализ временных рядов**: интерактивная визуализация графиков CPU, RAM, GPU, дискового I/O и температур.
- **Проверка системных гипотез**: карточки гипотез (термостресс, давление на память, флаппинг устройств).
- **Матрица корреляций**: расчет коэффициентов корреляции Пирсона между всеми парами системных метрик.
- **Детекция аномалий**: выявление критических всплесков нагрузки и сбоев устройств.
- **Интерактивные таблицы**: пагинированный просмотр и поиск по сырым записям телеметрии.
- **Экспорт отчетов**: скачивание отчетов в JSON или открытие автономного HTML-дашборда.

---

## 🚀 Файлы компонента

- `index.html` — разметка вкладки и элементов управления.
- `main.js` — модуль логики взаимодействия с бэкендом `/apps/telemetry_research` и рендеринга графиков Chart.js.
- `README.md` — данная документация.
