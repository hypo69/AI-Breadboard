# 🔍 Process Leaks Tab (Утечки ресурсов и микрофризы)

Вкладка глубокой системной диагностики скрытых утечек дескрипторов Win32 API, объектов интерфейса и деградации процессов.

## 📋 Возможности
- **Leak Hunter**: Аудит дескрипторов (Handles > 1500), GUI GDI/USER объектов (лимит OS 10 000) и Hard Page Faults.
- **Классификация рисков**: Автоматическое определение подозрительных процессов (норма / внимание / критический).
- **Фильтрация и поиск**: Мгновенная фильтрация по PID, имени процесса и порогам расхода ресурсов.
