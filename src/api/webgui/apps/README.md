# Веб-интерфейс центра приложений (`/apps`)

## Обзор
Центр приложений (`/apps`) предоставляет выделенный автономный веб-интерфейс для микросервисов и приложений AI Breadboard, расположенных в директории `/apps`.

## Включенные приложения
1. **Чат (`#tab-chat`)**: Интерактивный AI-диалог и чат-ассистент.
2. **Сетевой терминал (`#tab-network`)**: Анализ сетевых пакетов, телеметрия трафика и инспекция соединений.
3. **Системный инспектор (`#tab-system-inspector`)**: Метрики хоста, диагностика CPU/RAM/дисков, телеметрия GPU и анализ процессов.
4. **Windows Sysadmin (`#tab-windows-admin`)**: Управление сервисами Windows, запланированные задачи и системная диагностика.
5. **System Control (`#tab-system-control`)**: Панель быстрого управления системными службами и процессами.
6. **System Logs (`#tab-system-logs`)**: Просмотр системных журналов и логов приложений.
7. **Helpdesk (`#tab-helpdesk`)**: Поддержка и справочный центр.

## Основные возможности
- Модульная подгрузка шаблонов и скриптов жизненного цикла вкладок.
- Поддержка тем оформления (тёмная, светлая, системная) через `src/api/webgui/js/theme.js`.
- Интернационализация (русский, английский, иврит) через `src/api/webgui/js/i18n.js`.
- Прямая хэш-навигация (`/apps#tab-network`, `/apps#tab-windows-admin` и др.).
