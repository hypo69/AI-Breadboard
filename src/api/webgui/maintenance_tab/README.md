# Maintenance & Recovery Tab (Обслуживание и восстановление)

Модуль веб-интерфейса для регулярного технического обслуживания, очистки кэша, проверки целостности системных файлов Windows и управления точками восстановления системы.

## Назначение

Данная вкладка предоставляет единый центр управления для следующих административных задач:
- **Очистка диска и кэша (`Disk & Cache Cleanup`)**: Безопасный расчет объёма чистки и удаление временных файлов, логов установки и кэша обновлений Windows.
- **Проверка системных файлов (`SFC integrity scan`)**: Вызов проверки целостности защищенных файлов системы (`sfc /verifyonly`).
- **Проверка хранилища компонентов (`DISM Health Check`)**: Проверка состояния хранилища компонентов Windows через `DISM /CheckHealth`.
- **Точки восстановления Windows (`System Restore Points`)**: Просмотр списка точек восстановления, ручное создание новых точек, анализ метаданных в интерактивном модальном окне и управление политикой хранения дисковой квоты и автоматической ротации.

## Архитектура

- `index.html` — HTML-шаблон панели с адаптивными карточками быстрых действий и таблицей точек восстановления.
- `main.js` — Клиентский контроллер, взаимодействующий с эндпоинтами REST API `/api/system-control/...`.

## Интеграция API

- `GET /api/system-control/status` — Получение статуса оценки очищаемых гигабайт и общего состояния.
- `GET /api/system-control/restore-points` — Получение списка точек восстановления.
- `POST /api/system-control/restore-points` — Создание новой точки восстановления.
- `GET /api/system-control/restore-points/config` — Загрузка конфигурации квот и расписания.
- `POST /api/system-control/restore-points/config` — Сохранение настроек политики хранения.
- `POST /api/system-control/restore-points/prune` — Принудительная ротация точек восстановления.
- `POST /api/system-control/maintenance/cleanup` — Запуск очистки диска и временных файлов.
- `POST /api/system-control/maintenance/sfc` — Запуск проверки SFC.
- `POST /api/system-control/maintenance/dism` — Запуск проверки DISM.
