# Вкладка бенчмарка производительности дисков (DiskSpd / CrystalDiskMark)

## Описание
Интерактивный модуль измерения скорости чтения и записи дисковой подсистемы (NVMe SSD, SATA SSD, HDD, флеш-накопители) с использованием официального консольного инструмента **Microsoft DiskSpd**.

## Архитектура
1. **Frontend**: Вкладка `/tc#tab-disk-speed` (`index.html`, `main.js`).
2. **Backend**: Сервис `StorageBenchmarkService` (`apps/windows/modules/storage_manager/core/benchmark.py`) и роутер `/api/v1/storage/benchmark/*`.
3. **Движок**: `diskspd.exe` (располагается в `bin/diskspd/diskspd.exe` или загружается автоматически).
4. **Безопасность**: Запись и чтение производятся исключительно на изолированном временном файле `diskspd-test.dat` в безопасной директории `AI-Breadboard-benchmark` или `data/benchmark`, с автоматической очисткой после теста.
5. **История**: Результаты измерений фиксируются в локальной SQLite базе данных (`data/storage_benchmarks.db`).

## Поддерживаемые профили
- `SEQ1M Q8T1`: Последовательный доступ, блок 1 MiB, очередь 8, поток 1.
- `SEQ1M Q1T1`: Последовательный доступ, блок 1 MiB, очередь 1, поток 1.
- `RND4K Q32T16`: Случайный доступ, блок 4 KiB, глубина очереди 32.
- `RND4K Q1T1`: Случайный доступ, блок 4 KiB, глубина очереди 1.
