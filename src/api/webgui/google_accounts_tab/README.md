# Google Accounts Management Tab (`google_accounts_tab`)

## Overview
Web interface component for managing the Google Workspace account pool (OAuth 2.0 and Service Accounts) in the AI Breadboard administrator panel.

## Features
- Overview of all configured Google accounts (name, type, email, token status, quota status, default indicator).
- Add new accounts via `credentials.json` / `service_account.json` upload or direct JSON specification.
- Switch the default fallback account for automated Google Workspace tools.
- Real-time OAuth and Service Account authorization tests and scope diagnostics.
- Quota exhaustion reset and account removal.
