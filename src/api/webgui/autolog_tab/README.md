# Веб-компонент вкладки управления автологгированием (`autolog_tab`)

Модуль пользовательского интерфейса для управления периодическим автологгированием телеметрии и метрик приложений платформы **AI Breadboard** в режиме **Test Computer** (`/tc`) и общем центре приложений (`/apps`).

---

## 📋 Возможности

- **Мониторинг движка (`AutoLogEngine`)**:
  - Отображение текущего состояния активности (активен / остановлен), количества активных фоновых воркеров, времени последних опросов.
  - Управление запуском и остановкой движка в один клик.
  - Мастер-кнопка немедленного опроса всех логгеров ("Опросить все сейчас").
- **Управление периодичностью логгеров**:
  - Включение / выключение индивидуальных логгеров (`system_inspector`, `hardware_monitor`, `librehardwaremonitor`, `website_monitor`, `gcloud_monitor`, `cloudflared_monitor`, `windows_sysadmin`, `windows_defender`, `windows_startup_auditor`, `windows_backup_manager`, `trading_terminal`, `user_assistant`, `helpdesk`, `registry_viewer`, `software_audit`).
  - Выбор частоты опроса из удобного списка пресетов (5 сек, 10 сек, 30 сек, 1 мин, 5 мин, 10 мин, 30 мин, 1 час, 6 часов, 1 день, 7 дней) либо ручной ввод произвольного интервала.
  - Сохранение настроек в активный конфигурационный файл с мгновенным перезапуском фоновых воркеров без перезагрузки сервера.
- **Сенсоры оборудования и телеметрия**:
  - Графическая настройка сенсоров оборудования (CPU, GPU, RAM, Disk, Network, S.M.A.R.T. и др.) и выбор отслеживаемых метрик.
  - Управление глобальными параметрами инвентаризации и мониторинга.

---

## 🔗 Связанные эндпоинты API

- `GET /api/autolog/status` — Диагностический статус и счетчики движка.
- `GET /api/autolog/config` — Получение настроек интервалов всех логгеров.
- `POST /api/autolog/config` — Сохранение настроек в активный JSON-файл и динамический перезапуск.
- `POST /api/autolog/start` — Запуск движка.
- `POST /api/autolog/stop` — Остановка движка.
- `POST /api/autolog/poll-all` — Разовый опрос всех логгеров.
- `POST /api/autolog/poll/{app_name}` — Разовый опрос конкретного приложения.
- `GET /api/autolog/files` — Список файлов CSV в каталоге логов.
- `GET /api/autolog/file/{filename}` — Чтение и парсинг строк конкретного CSV-файла.
- `DELETE /api/autolog/file/{filename}` — Удаление CSV-файла лога.
- `GET /api/autolog/download/{filename}` — Скачивание CSV-файла.
