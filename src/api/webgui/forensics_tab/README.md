# ⏱️ Behavioral Forensics Tab (Поведенческая форензика активности)

Вкладка анализа активности пользователя и форензики запущенных приложений в операционной системе Windows.

## 📋 Возможности
- **Foreground Window**: Определение активного окна в фокусе и процесса в реальном времени.
- **User Idle Time**: Мониторинг времени бездействия пользователя (GetLastInputInfo).
- **Privacy Radar**: Обнаружение обращений приложений к камере и микрофону (Windows ConsentStore).
- **UserAssist Forensic History**: Извлечение статистики запусков программ и времени удержания фокуса из реестра Windows.
