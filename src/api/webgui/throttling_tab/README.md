# ⚡ Kernel Quality & Throttling Tab (Качество ядра и Троттлинг)

Вкладка диагностики аппаратной стабильности, троттлинга процессора, латентности драйверов ядра и журналов аварий Windows.

## 📋 Возможности
- **DPC / ISR Latency**: Оценка задержек отложенных вызовов процедур и прерываний устройств (микрофризы звука/видео).
- **Аппаратный троттлинг**: Детекция термического сброса тактовых частот CPU (PROCHOT) и ограничений энергопотребления (Power Limit PL1/PL2).
- **GPU PCIe Prober**: Проверка соответствия скорости и ширины линий шины PCI Express графического адаптера.
- **Журнал Minidump**: Мониторинг аварийных дампов падения ядра Windows (BSOD).
