# Стили WebGUI (CSS Architecture)

Директория содержит модульную систему стилей для веб-интерфейса AI Breadboard.

## Архитектура стилей

Таблица стилей разделена на специализированные модули в соответствии с принципом единственной ответственности и лимитом размера файлов:

| Файл | Описание |
|---|---|
| [`main.css`](main.css) | Мастер-манифест, объединяющий все модули через `@import` |
| [`variables.css`](variables.css) | Дизайн-токены и CSS-переменные для светлой (`:root`, `[data-theme="light"]`) и тёмной (`[data-theme="dark"]`) тем |
| [`base.css`](base.css) | Базовые стили страницы, скроллбары (`::-webkit-scrollbar`) и контейнеры вкладок (`.tab-content`, `.tab-pane`) |
| [`nav.css`](nav.css) | Панель навигации, вкладки (`.nav-tabs`), выпадающие меню, языковые переключатели и кнопки тем |
| [`components.css`](components.css) | Общие UI-компоненты: карточки (`.card`), инпуты (`.form-control`), кнопки (`.btn`), модальные окна (`.modal-*`), таблицы, алерты, бейджи, чипы |
| [`chat.css`](chat.css) | Компоненты чата: сайдбар истории диалогов (`.chat-sidebar`), окно сообщений (`.chat-window`), тулбар дебаггера |
| [`torrents.css`](torrents.css) | Стили управления торрентами: таблица статусов, карточки поиска, бейджи трекеров, лог медиатеки |
| [`overrides.css`](overrides.css) | Адаптивные переопределения и согласование классов Bootstrap с темой оформления |

## Подключение

HTML-документы подключают мастер-файл:
```html
<link href="/html/css/main.css" rel="stylesheet">
```

При необходимости отдельный изолированный компонент может импортировать только нужные модули (например, `variables.css` и `components.css`).
