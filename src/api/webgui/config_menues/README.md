# Конфигурации Меню (Menu Configurations)

Директория содержит централизованные конфигурации меню веб-интерфейса для различных роутов и сценариев (`/tc`, `/su` и т.д.).

## Структура файлов

- `tc_menu_config.json` — конфигурация меню для сценария Test Computer (`/tc`, `/apps`).
- `su_menu_config.json` — конфигурация меню для сценария User Assistant (`/su`).

## Назначение параметров

- `topButtons` — кнопки верхней навигационной панели.
- `sidebarItems` — элементы выдвижного бокового меню (Offcanvas).
- `settings` — параметры по умолчанию (активная вкладка `defaultTab`, отображение панелей).
