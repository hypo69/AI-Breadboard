# `webinterface/tts_tab` — Text-to-Speech Settings & Playground

## Purpose
Configuration tab and testing playground for speech synthesis engines (Edge-TTS, gTTS, Silero).

---

## Capabilities
- Preview and audition available voices across different languages.
- Adjust speech rate, pitch, and volume parameters.
- Test live synthesis of custom text snippets.

---

## Files
- `index.html`: Voice selector, audio controls, and preview player.
- `main.js`: Speech synthesis request handler.
