# `webinterface/user` — User Portal (Telegram Mini App)

## Purpose
Lightweight, mobile-first user portal designed for everyday media browsing, streaming, and conversational AI assistance.

---

## Views
1. **Media Player**: Browse library, watch movies/series, and stream directly in-browser.
2. **AI Chat**: Natural language assistant that searches media and automatically triggers player navigation upon recommendation.

---

## Files
- `index.html`: Mobile-responsive portal shell.
- `main.js`: Portal navigation, authentication state, and chat integration.
- `style.css`: Sleek mobile-friendly dark theme.
