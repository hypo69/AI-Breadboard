# Helpdesk Tab Module

## Overview
The `helpdesk_tab` module provides an integrated multi-tool Helpdesk & Support Workbench directly inside the AI Breadboard administrative suite (`/admin`).

## Features
- **Real-Time WebSocket Sync:** Immediate push notifications on new user tickets and live incoming chat replies.
- **Support Toolkit:**
  - Ticket stream filtering (New, In Progress, Resolved, Closed).
  - One-click priority & status actions.
  - Canned response templates (greeting, resolved, request details).
  - AI Draft Generator (`/api/chat` integration).
  - Private operator internal notes.
  - Modal ticket creator.
