Как получить и загрузить Credentials JSON

Используется для работы от имени вашего личного или рабочего аккаунта Google (чтение/отправка почты в Gmail, доступ к Google Drive, редактирование Google Sheets/Docs).

  1. Перейдите в консоль управления Google:
    Google Cloud Console ➜ Credentials
  2. Если проект еще не создан, выберите существующий или создайте новый проект (кнопка в верхней панели).
  3. В разделе OAuth consent screen (Экран согласия OAuth):
    • Выберите тип: External (Внешний) или Internal.
    • Укажите название приложения (например, AI Breadboard) и ваш контактный email.
    • В разделе Test users добавьте ваш Google email (если статус приложения Testing).
  4. В разделе Credentials нажмите + CREATE CREDENTIALS ➜ выберите OAuth client ID.
  5. В поле Application type выберите Desktop app (Приложение для ПК) и задайте имя (например Breadboard-Desktop), затем нажмите Create.
  6. В появившемся окне нажмите DOWNLOAD JSON (или скачайте файл в таблице OAuth 2.0 Client IDs).
  7. Включите необходимые API в Enabled APIs & Services :
    Gmail API Google Drive API Google Sheets API Google Docs API
  8. В этой карточке выберите Загрузить файл и укажите скачанный credentials.json (или вставьте его содержимое во вкладку Вставить JSON), введите ID аккаунта и нажмите Сохранить Google аккаунт.

Используется для серверных / автономных фоновых задач без необходимости интерактивного логина в браузере.

  1. Перейдите в раздел сервисных аккаунтов:
    Google Cloud Console ➜ Service Accounts
  2. Нажмите + CREATE SERVICE ACCOUNT, введите имя (например ai-agent-sa) и нажмите Done.
  3. Кликните по созданному сервисному аккаунту и перейдите во вкладку Keys (Ключи).
  4. Нажмите ADD KEY ➜ Create new key ➜ выберите тип JSON ➜ нажмите Create.
  5. Файл ключа (project-id-*.json) скачается на ваш компьютер.
  6. В форме выберите тип Service Account Key, загрузите JSON файл и сохраните аккаунт.
