# Research and Statistic Application

Приложение для проведения исследований данных и статистического анализа с элементами ИИ-диагностики.

## Функционал
- **Статистический анализ**: Базовый анализ данных (описательная статистика).
- **ИИ-диагностика**: Автоматическое обнаружение аномалий (выбросы, пропуски) и формирование рекомендаций с использованием ИИ.
- **Визуализация**: Генерация корреляционных матриц и других графиков.

## Использование
Приложение предоставляет API для проведения исследований:
- `POST /apps/research-statistic/run-research`: Запускает полный цикл анализа (эвристики + ИИ-интерпретация).
  Требует JSON с путем к файлу: `{"file_path": "/path/to/data.csv"}`

## Запуск
Используйте `manage_tools.py` для взаимодействия с приложением или обращайтесь к API напрямую.
