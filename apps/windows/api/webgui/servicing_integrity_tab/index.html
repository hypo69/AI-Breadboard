Справочная информация

DISM (Deployment Image Servicing and Management) обслуживает компоненты Windows и исправит ошибки хранилища манифестов.

SFC (System File Checker) сверяет контрольные суммы системных dll и exe файлов с резервными копиями в WinSxS.

Журнал выполнения обслуживания 
Готов к диагностике компонентов.
