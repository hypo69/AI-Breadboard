# 🎯 Focus & Attention Management Web Tab

## 📋 Описание

Интерактивная панель веб-интерфейса для управления сессиями фокусировки Windows 11 (Focus Sessions), режимом «Не беспокоить» (Do Not Disturb / Quiet Hours), подавлением бейджей уведомлений и мигания панели задач, а также интеграцией с системным приложением «Часы».

---

## 🎛️ Функционал

1. **Сессии фокусировки (Focus Sessions):** Запуск и остановка сессий без отвлекающих факторов с настраиваемой продолжительностью (от 5 до 240 минут) и живым таймером обратного отсчета.
2. **Таймер приложения «Часы»:** Интеграция с нативным интерфейсом фокусировки Windows Clock (`ms-clock:focus`).
3. **Блокировка бейджей (Taskbar Badges):** Временное или постоянное отключение счетчиков непрочитанных сообщений на значках панели задач (`TaskbarBadges`).
4. **Подавление мигания (Taskbar Flashing):** Отключение оранжевого мигания кнопок окон на панели задач (`TaskbarFlashing` / `ForegroundFlashCount`).
5. **Режим «Не беспокоить» (Do Not Disturb):** Включение системного подавления всплывающих push/toast уведомлений на время сессии (`NOC_GLOBAL_SETTING_TOASTS_ENABLED` / `ms-settings:quiethours`).
6. **Быстрый доступ к Windows Settings:** Прямой запуск панели параметров Windows для тонкой настройки списков приоритетов.
