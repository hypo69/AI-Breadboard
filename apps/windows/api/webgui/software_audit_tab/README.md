# 📊 Вкладка аудита программного обеспечения (Software Audit Tab)

## Назначение
Интерактивный интерфейс инвентаризации установленных программ Windows, анализа артефактов активности и назначения программного обеспечения.

## Возможности
- Сбор данных из веток системного реестра `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` (x64 и 32-бит Wow6432Node), а также профиля `HKCU`.
- Извлечение реальной истории и частоты запусков на основе криптографических артефактов **UserAssist (ROT13)** и системных файлов **Prefetch (`*.pf`)**.
- Автоматическая классификация приложений по категориям (*Браузеры, Разработка, Офис, Мультимедиа, Утилиты, Безопасность, Драйверы, Системные*).
- Выявление неиспользуемых программ (кандидатов на удаление без запусков более 90 дней).
- Модальное окно детального просмотра с путями реестра и строками деинсталляции (`UninstallString`).
- Экспорт сводного отчета в JSON.

## API Эндпоинты
- `GET /api/windows/software` — список установленных приложений с метаданными.
- `GET /api/windows/software/audit` — сводный аналитический отчет.
