# 📈 Вкладка визуализации истории телеметрии (Telemetry History Tab)

Модульный пользовательский интерфейс для глубокого анализа, профилирования и построения интерактивных графиков из логов телеметрии Windows и сенсоров оборудования.

---

## 📌 Возможности

1. **Интерактивные графики (Chart.js)**:
   - Мониторинг утилизации ресурсов: CPU Load, RAM, GPU.
   - Температурный профиль оборудования (°C).
   - Дисковый ввод-вывод (Read/Write MB/s).
   - Распределение событий устройств и отказов (Doughnut).

2. **Таблицы логов**:
   - Таблица всех записей телеметрии с пагинацией, полнотекстовым поиском и деталями атрибутов.
   - Журнал аномалий и пороговых выбросов (Critical / Warning).
   - Менеджер обнаруженных файлов логов в хранилище.

3. **Сводные показатели**:
   - Расчет интегрального индекса здоровья системы (Health Score).
   - Объем выборки и временной диапазон.
   - Автоматические выводы и рекомендации аналитического движка.

4. **Экспорт и отчеты**:
   - Открытие автономного адаптивного HTML-дашборда в отдельной вкладке.
   - Экспорт структурированного JSON-отчета.
