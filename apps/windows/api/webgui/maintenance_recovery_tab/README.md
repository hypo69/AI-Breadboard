# Вкладка Maintenance & Recovery (Обслуживание и восстановление)

**Путь:** `apps/windows/api/webgui/maintenance_recovery_tab/`

## Описание
Вкладка **Maintenance & Recovery** предоставляет централизованную панель обслуживания дисков, проверки целостности системы и управления точками восстановления Windows (System Restore Points).

## Основные возможности
- Быстрая безопасная очистка кэшей и временных файлов.
- Сканирование целостности системных файлов (SFC) и хранилища компонентов (DISM).
- Полное управление точками восстановления Windows с интерактивным просмотром метаданных.
- Настройка квот дискового пространства теневого хранилища (VSS) и автоматических расписаний создания/ротации.
