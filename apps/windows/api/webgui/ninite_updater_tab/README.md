# ⚡ Вкладка «Установить Ninite» (Ninite Auto-Updater)

## Назначение
Модуль интерфейса для автоматического развёртывания и управления регулярным обновлением программного обеспечения через [Ninite](https://ninite.com) и службу расписания Windows Task Scheduler.

## Функциональные возможности
- **Загрузка и переименование инсталлятора**: Пользователь выбирает сгенерированный на сайте Ninite файл установщика, система переименовывает его в `ninite.exe` и размещает в каталоге `C:\Program Files\Ninite\`.
- **Настройка интервала**: Выбор частоты обновления (по умолчанию **2 недели**, доступны варианты 1 неделя, 2 недели, 3 недели, 1 месяц).
- **Настройка времени**: Указание точного времени фонового запуска (по умолчанию **20:00**).
- **Интеграция с Windows Task Scheduler**: Автоматическая регистрация регламентной задачи `NiniteAutoUpdate` с флагом тихой работы `/silent` и наивысшим уровнем привилегий.
- **Мониторинг и статус**: Отображение статуса файла, текущего состояния службы расписания, даты следующего запуска и просмотр журнала.
- **Принудительный запуск**: Кнопка «Запустить обновление сейчас» для немедленного фонового выполнения задачи.

## Структура файлов
- `index.html` — Вёрстка формы загрузки, селекторов интервала/времени и карточек мониторинга статуса.
- `main.js` — Клиентская логика отправки файлов (`multipart/form-data`), взаимодействия с `/api/ninite/*` и обновления UI.
- `README.md` — Документация модуля.

## Бэкенд роутер
Обработчики реализованы в `src/api/router_ninite.py`:
- `GET /api/ninite/status`
- `POST /api/ninite/upload`
- `POST /api/ninite/schedule`
- `POST /api/ninite/run-now`
