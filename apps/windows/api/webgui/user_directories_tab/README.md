# Вкладка «Пользовательские директории и хранилище» (User Directories & Storage)

## Назначение
Модуль пользовательского веб-интерфейса для мониторинга, аудита, поиска и управления персональными изолированными хранилищами пользователей платформы **AI Breadboard** (`data/users/<user_id>/`).

## Возможности
1. 🔍 **Поиск и фильтрация**:
   - Мгновенный поиск по имени пользователя, email и именам файлов в хранилище.
   - Фильтрация по расширениям файлов (`.pdf`, `.txt`, `.json`, `.csv`, `.png` и др.).
2. 📁 **Интерактивный файловый проводник**:
   - Двухпанельный интерфейс: список пользователей с дисковыми квотами слева, дерево и таблица файлов справа.
   - Детализация каждого файла: размер, дата изменения, расширение, путь и подпапка (`files`, `rag`, `profile`, `temp`).
3. 📊 **Статистика и аналитика**:
   - Общий объем данных хранилища на диске.
   - Прогресс-бары использования квот для каждого пользователя.
   - Распределение файлов по типам и разделам.
4. 🛠️ **Действия с файлами**:
   - Встроенный безопасный предпросмотр текстовых файлов, кода, JSON и изображений.
   - Скачивание файлов напрямую через браузер.
   - Удаление файлов и каталогов.
   - Автоматическое обнаружение и пакетная очистка осиротевших (мертвых) директорий.

## Файловая структура
- `index.html` — разметка вкладки и модальных окон предпросмотра и очистки.
- `main.js` — JavaScript контроллер вкладки (`initUserDirectoriesTab()`).
- `README.md` — описание модуля на русском языке.

## API Эндпоинты
- `GET /api/admin/user-directories/summary` — общая сводка хранилища.
- `GET /api/admin/user-directories/users` — список пользователей со статистикой диска.
- `GET /api/admin/user-directories/users/{user_id}/tree` — файловое дерево пользователя.
- `GET /api/admin/user-directories/users/{user_id}/file/preview` — предпросмотр файла.
- `GET /api/admin/user-directories/users/{user_id}/file/download` — скачивание файла.
- `DELETE /api/admin/user-directories/users/{user_id}/file` — удаление файла/папки.
- `GET /api/admin/user-directories/orphaned` — список осиротевших папок.
- `POST /api/admin/user-directories/orphaned/clean` — очистка осиротевших папок.
