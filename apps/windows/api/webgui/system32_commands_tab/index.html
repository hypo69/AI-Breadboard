🏛️ 1. Слои Windows Control Plane

Каждая операция в Windows может выполняться не только через System32/*.exe, но и через соответствующие эквиваленты: PowerShell Cmdlets, WMI/CIM классы, COM интерфейсы, прямые вызовы Win32 API в системных DLL, события ETW и каналы Windows Event Log.

🎯 2. Градация AITelemetry Tiers
  • 🟢 OBSERVE: Безопасное считывание телеметрии (systeminfo, tasklist, netstat, fsutil usn, logman query, whoami).
  • 🟡 DIAGNOSE: Трассировка, диагностика задержек, сетевые снифферы (ping, tracert, pathping, pktmon, sxstrace).
  • 🟠 CONTROL: Управление службами, расписанием, некритичными параметрами (sc start/stop, schtasks /run, tzutil).
  • 🔴 ADMIN: Изменение конфигурации системы, брандмауэра, политик безопасности (reg add, sc config, netsh advfirewall, dism).
  • 🔴🔴 DESTRUCTIVE: Деструктивные операции (diskpart clean/format, format.com, bcdedit /delete).
  • 🛡️ RECOVERY: Среда восстановления и ремонт ОС (reagentc, bcdboot, bootrec, wbadmin, sfc).
⏱️ 3. Сквозной конвейер ETW

Sensors → ETW / Performance Counters (logman, pktmon, typeperf) → AITelemetry Pipeline → SQLite (telemetry.db)

📜 4. Наблюдение через NTFS USN Journal

Команда fsutil usn queryjournal C: позволяет отслеживать изменения файлов в реальном времени без ресурсоемкого сканирования всего диска.
