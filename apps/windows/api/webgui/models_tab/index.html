Настройки Google Antigravity (AGY)
Что такое Antigravity (AGY)?

Google Antigravity — передовая агентная платформа для автономных AI-воркфлоу, мультиагентных пайплайнов и глубокого веб-исследования.

  • Включает встроенные агентные инструменты BuiltinTools.SEARCH_WEB и READ_URL_CONTENT.
  • Поддерживает автономный вызов через Python SDK (google.antigravity) и утилиту agy CLI.
  • Если отдельный ключ AGY_API_KEY не задан, провайдер автоматически использует ключи из пула Gemini.
Сохраняется в защищенном файле .env.
Учетные записи Google Workspace
Пул аккаунтов Google (OAuth 2.0 & Service Account)

Интеграция с сервисами Google: Gmail (чтение, черновики), Google Drive (поиск файлов, чтение), Google Sheets (чтение/запись таблиц) и Google Docs.

  • При вызове инструментов ассистент использует аккаунт account_name или аккаунт по умолчанию ( Default).
  • Файлы ключей и токенов безопасно сохраняются в src/secrets/ и изолированы от публичной конфигурации.

Настройки Microsoft Foundry
Где взять модели Foundry?

Microsoft Foundry (как и LM Studio) работает локально. Чтобы список моделей был не пустым, вам необходимо предварительно загрузить нужные GGUF или ONNX модели через интерфейс самого Foundry или CLI.

Настройки Ollama (Local)
Как добавить новые модели в Ollama?

Откройте терминал на сервере, где установлен Ollama, и выполните команду:
ollama pull llama3.1
После загрузки модель автоматически появится в выпадающем списке.

Настройки Microsoft ONNX Runtime & Olive
Аппаратное ускорение и оптимизация Olive

Microsoft ONNX Runtime использует аппаратные ускорители Windows (DirectML GPU, Qualcomm QNN NPU, CUDA). Microsoft Olive выполняет автоматическое квантование (INT4/INT8) и оптимизацию графов для максимальной скорости локального инференса.
