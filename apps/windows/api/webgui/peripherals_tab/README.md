# 🔌 Peripherals & Network Tab (Сеть и периферия)

Вкладка радиочастотной телеметрии Wi-Fi, аудио устройств и Plug & Play USB периферии.

## 📋 Возможности
- **Wi-Fi RF & BSSID**: Мониторинг SSID, BSSID точки доступа, уровня сигнала RSSI в dBm, радиоканала и шифрования безопасности.
- **Audio Endpoints**: Список активных и назначенных по умолчанию аудиоустройств ввода/вывода.
- **PnP USB Device Tree**: Таблица подключенных USB устройств, VID/PID идентификаторов и статуса исправности.
