# Accounts & Identity WebGUI Tab (AI Breadboard)

## Описание
Вкладка **Управление пользователями и Windows Identity** для веб-интерфейса `tc.ps1` (Test Computer / Apps Hub).

## Функциональные возможности
1. **Текущий контекст безопасности**: отображение токена, целостности (Integrity Level) и UAC Elevation.
2. **Управление локальными учетными записями SAM**: просмотр, поиск, создание пользователя, блокировка и удаление.
3. **Группы безопасности и вложенность**: просмотр групп, прав [ADMIN], участников и путей наследования.
4. **Быстрый аудит прав и LSA**:
   - `Who is Admin?` — выявление всех администраторов с путями вложенных групп.
   - `Logon as Service` — аккаунты с правом `SeServiceLogonRight`.
   - `Remote Desktop (RDP)` — аккаунты с правом `SeRemoteInteractiveLogonRight`.
   - `Orphaned SIDs / Profiles` — поиск осиротевших идентификаторов и каталогов.
   - Сводка политики сложности паролей SAM.
5. **Инспектор процесса (PID)**: моментальный разбор безопасности процесса (PID → Token → SID → Account → Groups → Integrity → Elevation → Session).
6. **Каталог операций**: интерактивный справочник всех ~180 операций OS-level каталога с уровнями риска.
