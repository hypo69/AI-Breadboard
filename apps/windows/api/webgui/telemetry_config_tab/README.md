# Вкладка редактора конфигурации телеметрии (Telemetry Config Tab)

**Назначение:** Интерактивный веб-интерфейс для настройки, валидации и сохранения файла конфигурации модуля сбора телеметрии Windows (`%APPDATA%\AI-Breadboard\apps\windows\telemetry\config.json`).

## Возможности

1. **Два режима редактирования**:
   - **Визуальный конфигуратор**: Управление интервалами, лимитами процессов, режимами (`minimal`, `hybrid`, `full`), параметрами SQLite БД, тяжелыми коллекторами и индивидуальными сенсорами с удобными переключателями.
   - **Редактор исходного JSON**: Прямое редактирование с подсветкой, live-валидацией синтаксиса, форматированием и копированием в буфер.
2. **Мгновенное применение на лету (Hot Reload)**:
   - Сохраненные изменения сразу же подхватываются процессом телеметрии на следующем тике без перезапуска сервиса.
3. **Безопасность и сброс**:
   - Откат к исходному шаблону настроек по умолчанию одной кнопкой.
   - Защита от повреждения файла при некорректном синтаксисе JSON.
