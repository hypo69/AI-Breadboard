# 🎬 Вкладка «Сценарии» (Test Computer Scenarios & AI Skills Assistant)

## Назначение
Вкладка **«Сценарии»** является главным стартовым хабом интерфейса Test Computer (`/tc` и `/apps`) для автоматизированной экспресс-диагностики, прогона смоук-тестов и интеллектуального взаимодействия с операционной системой.

## Ключевые возможности
1. **Быстрая проверка (Smoke Test):**
   - Комплексная экспресс-проверка серверного окружения, Python, доступности AI-провайдеров, свободного места на дисках и состояния логов.
   - Рекомендуется запускать сразу после установки или перезапуска сервера.

2. **Аудит логов:**
   - Сканирование файлов журналов (`info.log`, `errors.log`, `fastapi.log`) и журналов Windows EventLog на наличие критических ошибок и предупреждений с выдачей практических рекомендаций.

3. **Диагностика оборудования и системы:**
   - Срез телеметрии: загрузка ядер процессора, температура, оперативная память, дисковые накопители и ресурсоёмкие процессы.

4. **Аудит автозапуска и служб Windows:**
   - Проверка реестра автозагрузки (Run / RunOnce) и системных служб.

5. **Проверка сетевой доступности:**
   - Тестирование локальных серверных портов (8000), DNS и связи с внешними API.

6. **Интеллектуальный Мини-чат & Автогенератор навыков:**
   - Позволяет задавать произвольные вопросы о системе (например: *«Какие мыши были подключены к этому компьютеру?»*).
   - Если прямой команды нет, система опрашивает оборудование, запрашивает LLM-модель, выводит подробный структурированный ответ и **автоматически сохраняет новый навык** в `.skills/<skill-name>/SKILL.md`.

## Архитектура и интерфейс
- **HTML Шаблон:** `index.html` (Центрированный интерфейс чата с выдвижной панелью Bootstrap Offcanvas справа для сценариев)
- **Клиентский модуль:** `main.js` (экспортирует функцию `window.initScenariosTab`)
- **Конфигурация подсказок:** `questions.json` (внешний список вопросов и быстрых кнопок)
- **Бэкенд API:** `/api/v1/scenarios` (`src/api/router_scenarios.py`)
  - `GET /api/v1/scenarios` — перечень сценариев
  - `POST /api/v1/scenarios/run` — выполнение сценария
  - `POST /api/v1/scenarios/chat` — мини-чат и автогенерация навыков
  - `GET /api/v1/scenarios/questions` — пул вопросов и кнопок из внешнего файла `questions.json`

## Особенности интерфейса
- **Чат по центру:** Основной рабочий экран сфокусирован на интеллектуальном ассистенте с историей диалога, быстрым выбором подсказок и элементами управления генерацией навыков.
- **Выдвижная панель справа (Offcanvas):** Список категорий, карточки экспресс-тестов и интерактивная консоль выполнения сценариев открываются по кнопке «Сценарии» либо автоматически при запуске сценария.
