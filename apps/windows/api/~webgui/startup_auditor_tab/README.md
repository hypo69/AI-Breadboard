# 🚀 Startup Auditor Web GUI Tab

Веб-компонент вкладки аудитора автозапуска Windows для интерфейса `/apps`.

## Файлы
- `index.html` — разметка дашборда (метрики, фильтры, таблица автозапуска, кнопки экспорта)
- `main.js` — логика взаимодействия с REST API `/api/v1/startup-auditor/*`, фильтрация и управление состоянием
