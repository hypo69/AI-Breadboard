# 🔍 File History AI Search Tab

Пользовательский веб-интерфейс вкладки для поиска по истории файлов Windows с использованием RAG-векторизации и семантического анализа.

---

## 📌 Описание

Интерфейс предоставляет пользователю удобную панель для:
- Запуска визуального семантического поиска по истории файлов в системе Windows.
- Просмотра статуса проиндексированных документов в FAISS векторизаторе.
- Управления фоновым автообновлением RAG-индекса (запуск/остановка планировщика).
- Инспекции и копирования путей обнаруженных файлов.

---

## 📁 Структура веб-вкладки

- `index.html` — Карточки метрик, панель поиска, таблица телеметрии и индикаторы статуса.
- `main.js` — Клиентская логика взаимодействия с REST API `/api/windows/file-history/*`.
- `README.md` — Описание компонента.

---

## 🔗 Подключение

Вкладка зарегистрирована в `src/api/webgui/apps/modules/tabs-config.js` под ID `file_history_ai_search`.
