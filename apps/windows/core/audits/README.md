# Коллектор производительности (Performance Collector)

Этот модуль реализует **гибридный движок аудита производительности**, который собирает данные о состоянии CPU, RAM, времени работы системы и анализирует точки автозагрузки Windows.

## Архитектура
Модуль интегрирован в централизованную систему телеметрии `AI-Breadboard` через интерфейс `TelemetryProvider`.

## Возможности
- **Мониторинг ресурсов:** Сбор метрик загрузки CPU, RAM и файла подкачки.
- **Анализ автозагрузки:** Инвентаризация записей `Run` и `RunOnce` в реестре Windows.
- **Диагностика:** Выявление потенциальных проблем производительности (высокая загрузка CPU/RAM, наличие процессов-кандидатов на утечку памяти).
- **Телеметрия:** Автоматическая регистрация метрик как сенсоров для централизованной системы логирования.

## Использование через Python
```python
from apps.windows.core.modules.performance_collector import PerformanceCollector

# 1. Инициализация коллектора
collector = PerformanceCollector()

# 2. Сбор данных
result = collector.collect()
print(f"Статус аудита: {result.status}")

# 3. Доступ к сенсорам телеметрии
sensors = collector.get_sensors()
for s in sensors:
    print(f"Сенсор: {s.name} = {s.value} {s.unit}")
```
