# 🔬 Исследование телеметрии Windows (Telemetry Research & Web GUI)

Модуль глубокого аналитического исследования, визуализации и мониторинга логов системной телеметрии платформы AI-Breadboard. Позволяет исследовать долговременные срезы телеметрии (CPU, GPU, RAM, дисковый ввод-вывод, сеть, процессы, изменения в файлах и сбои оборудования).

---

## 📌 Основные возможности

1. **Автономный FastAPI Web GUI**:
   - Интерактивные графики Chart.js (утилизация ресурсов, температуры, дисковый I/O, сеть).
   - Индекс здоровья системы (Health Score 0-100) и сводные аналитические выводы.
   - Автоматическая проверка системных гипотез (термостресс CPU, нехватка RAM, нестабильность устройств, перегрев GPU).
   - Матрица корреляций Пирсона между ключевыми системными метриками.
   - Инспекция сырых записей и логов телеметрии с пагинацией и поиском.

2. **Аналитический движок (`TelemetryResearcher`)**:
   - Расчет перцентилей (Avg, p95, Max, StDev) и статистических профилей (EDA).
   - Детекция кратковременных всплесков (Spikes) и аномалий.
   - Поддержка чтения как из базы данных SQLite (`telemetry.db`), так и из файлов JSON/JSONL.

3. **Экспорт и отчеты**:
   - Генерация автономных HTML-отчетов (`--format html`).
   - Экспорт в структурированный JSON (`--format json`) и векторные SVG графики (`--format svg`).

---

## 🚀 Запуск Web GUI

Для запуска автономного веб-интерфейса выполните:

```powershell
# Запуск через Python
py apps/windows/telemetry_research/main.py --port 8090

# Или как модуль
py -m apps.windows.telemetry_research.main --port 8090
```

После запуска веб-интерфейс доступен по адресу:
👉 `http://127.0.0.1:8090`

---

## 💻 Использование через CLI

Сформировать HTML-дашборд из консоли:
```powershell
py apps/windows/telemetry_research/cli.py --output report.html --format html
```

Вывести текстовое резюме и результаты проверки гипотез:
```powershell
py apps/windows/telemetry_research/cli.py --format summary
```
