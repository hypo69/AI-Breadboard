# Roadmap-2: План развития Web-GUI и интеграции скрытых функций бэкенда

## 1. Введение и цели
Настоящий документ (**Roadmap-2**) определяет план развития пользовательского веб-интерфейса (`web-gui.pdf`) и устранения разрыва между низкоуровневым ядром системы (`windows_modules.pdf`) и графической панелью управления.

Основные цели:
1. **Вывести в UI невидимый функционал бэкенда:** Создать интерфейсные панели для уже написанных модулей ядра ("код есть, а интерфейса нет").
2. **Оптимизировать навигацию и структуру:** Устранить дублирование элементов, реструктурировать выпадающие меню и консолидировать журналы.
3. **Визуализировать новые метрики телеметрии:** Подготовить клиентские компоненты для приема новых данных из `roadmap.md` (привилегии токенов, FQDN DNS, RDP, Root CA).

## 3. Раздел II: Реструктуризация и оптимизация навигации Web-GUI

### 2.1. Устранение дублирования элементов навигации
* **Проблема:** Вкладка «О системе» (`tab-about-system`) содержит суб-вкладки (*Process Leaks*, *Forensics*, *Throttling*, *Storage Wear*, *Peripherals*), которые одновременно продублированы как отдельные приложения в меню `/apps`.
* **Решение:** 
  - Сохранить суб-вкладки внутри дашборда «О системе» как единого аналитического центра.
  - В меню `/apps` оставить только самостоятельные инструменты управления (*Defender*, *Windows Backup*, *Startup Auditor*, *System Control*), сгруппировав их по категориям (Система, Безопасность, Сеть).

### 2.2. Консолидация работы с журналами
* **Проблема:** Журналы разнесены по трем разным вкладкам (`tab-system-logs`, `tab-logs`, `tab-autolog`).
* **Решение:** Объединить их в единый **«Центр журналов и аудита»** с фильтрацией по источникам:
  - Журналы событий Windows (EventLog / WevtAPI).
  - Логи сервиса телеметрии (CSV / SQLite loggers).
  - Системные логи FastAPI/Uvicorn сервера.

## 4. Раздел III: Визуализация новых данных телеметрии (Интеграция с Roadmap-1)

1. **Мониторинг привилегий процессов:**
   - Добавление колонок `Integrity Level` (Medium, High, System) и `Elevation` (UAC) в таблицу `tab-process-leaks`.
   - Подсветка процессов с опасными привилегиями (`SeDebugPrivilege`, `SeImpersonatePrivilege`).
2. **Сетевой FQDN-резолвер:**
   - Отображение доменного имени (FQDN) рядом с IP-адресами сокетов во вкладке `tab-network` на основе локального DNS-кэша.
3. **Панель RDP и сессий пользователей:**
   - Индикатор активных и фоновых RDP-подключений с IP-адресами клиентов.
4. **Аудит доверенных сертификатов:**
   - Вкладка проверки системного хранилища `Root CA` на появление сторонних корневых сертификатов.
