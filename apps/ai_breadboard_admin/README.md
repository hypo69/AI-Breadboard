# AI Breadboard Admin (`apps/ai_breadboard_admin`)

Центральное микроприложение для управления конфигурациями, системными инструкциями, источниками данных и пользователями платформы AI Breadboard.

---

## 🎯 Назначение

Приложение `ai_breadboard_admin` консолидирует административные сервисы и функции управления системой в соответствии с модульной архитектурой платформы:
- **Управление конфигурациями**: режимы RAG (`rag+model`, `rag`, `model`), параметры веб-поиска, настройки моделей и конфигурационные файлы приложений `/apps`.
- **Версионирование инструкций**: управление системными промптами чата и стилями диктора, сохранение версий в `prompts/chat/versions/` и `prompts/narrator/versions/`, быстрая активация версий.
- **Управление источниками данных**: просмотр, валидация и редактирование `sources.json`.
- **Администрирование пользователей**: управление ролями (`admin`/`user`), активностью, правами, сброс паролей и очистка осиротевших каталогов.
- **Интерактивный TUI**: мониторинг состояния системы и параметров в терминале.

## 🚀 Запуск и использование

### Запуск интерактивного TUI
```powershell
python -m apps.ai_breadboard_admin --mode tui
```

### Запуск автономного сервера API
```powershell
python -m apps.ai_breadboard_admin --mode server --port 8110
```

### Вывод краткого системного статуса в JSON
```powershell
python -m apps.ai_breadboard_admin --mode status
```

## 🔌 API Эндпоинты

Базовый префикс: `/api/v1/ai_breadboard_admin`

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/status` | Агрегированный статус настроек и пользователей |
| `GET` / `POST` | `/config/rag` | Получение и установка режима RAG |
| `GET` / `POST` | `/config/web-search` | Настройки поискового сервера |
| `GET` / `POST` | `/config/apps/{app_name}` | Чтение и запись конфигурации микроприложения |
| `GET` | `/instructions` | Чтение активной системной инструкции |
| `POST` | `/instructions/save` | Сохранение новой версии инструкции |
| `GET` | `/instructions/versions` | Список сохраненных версий инструкций |
| `POST` | `/instructions/activate` | Активация выбранной версии инструкции |
| `GET` / `POST` | `/sources/raw` | Чтение и сохранение `sources.json` |
| `GET` / `POST` | `/users` | Список пользователей и создание нового пользователя |
| `GET` / `PUT` / `DELETE` | `/users/{user_id}` | Детали, обновление и удаление пользователя |
| `POST` | `/users/{user_id}/password` | Сброс / установка пароля пользователя |
| `POST` | `/users/{user_id}/toggle-active` | Блокировка / разблокировка пользователя |
| `POST` | `/users/{user_id}/toggle-role` | Переключение роли `admin` <-> `user` |
| `GET` / `POST` | `/users/orphaned/dirs` | Просмотр и очистка осиротевших каталогов |
