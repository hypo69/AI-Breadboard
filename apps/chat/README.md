## 📋 Обзор

Приложение **AI Chat** (`apps/chat`) предоставляет полноценный диалоговый интерфейс и REST API для взаимодействия с языковыми моделями (Gemini, Ollama, Foundry, ONNX, OpenAI):
- 💬 **Диалоговый движок:** Многосессионный чат с сохранением истории и контекста сообщений в SQLite (`chat_sessions.db`).
- 🧠 **RAG-интеграция:** Подключение базы знаний с настраиваемыми порогами сходства (`MIN_SCORE`) и количеством релевантных фрагментов (`TOP_K`).
- 🔊 **Мультимодальность:** Поддержка текстового и голосового вывода ответов.
- ⚙️ **Гибкая конфигурация:** Поддержка как общего режима (shared route через `src/app/__init__.py`), так и автономного микросервиса.

## 🌐 FastAPI REST Endpoints (`/api/v1/apps/chat`)

| Эндпоинт | Метод | Описание |
|---|---|---|
| `/api/v1/apps/chat/status` | `GET` | Получение текущего статуса сервиса чата и количества сессий |
| `/api/v1/apps/chat/config` | `GET` | Получение конфигурации приложения чата |
| `/api/v1/apps/chat/sessions` | `GET` | Список сохраненных сессий диалогов |
| `/api/v1/apps/chat/sessions` | `POST` | Сохранение или обновление диалоговой сессии |
| `/api/v1/apps/chat/sessions/{id}` | `GET` | Получение данных конкретной сессии |
| `/api/v1/apps/chat/sessions/{id}` | `DELETE` | Удаление сессии диалога |
| `/api/v1/apps/chat/sessions` | `DELETE` | Очистка всех диалоговых сессий |
